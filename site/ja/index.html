ネイティブのデスクトップコンパニオン

Herdrセッションをデスクトップで確認。ローカルエージェントに返信。

Rubeliaの吹き出しで観測されたセッション状態を確認し、選択したローカルエージェントにメッセージを送信できます。受理されたメッセージは、タスクの完了を意味しません。

Herdrに接続 ↗実際のアプリ画面を見る ↗

Herdrなしでキャラクターだけ使いたい場合は、単独起動の方法をご覧ください。

Appleシリコン搭載Mac · macOS 13以降 · Rubeliaを同梱

01 / アプリ画面

イラストから、
あなたのデスクトップへ。

隔離されたオフライン環境でmacOSネイティブアプリv0.3.2を撮影しました。画面に接続中のセッションはありません。

02 / 主な機能

セッションを確認。
ローカルで返信。キャラクターと交流。

観測されたHerdrワークスペースとデスクトップキャラクターの3つの使い方。

01 / 状態確認◉

推測ではなく観測された状態を表示

吹き出しのセッションカードには、待機中・実行中・入力待ち・状態不明を表示します。エージェントの作業結果は推測しません。

02 / 返信↗

ローカルセッションにメッセージを送信

選択したローカルエージェントのカードから送信できます。Herdrによる受理は作業完了を意味せず、リモートのカードは閲覧専用です。

03 / 交流✳

触れると反応するRubelia

頭や体をタップしたり、頭をなでたりすると反応します。ドラッグで移動し、大きさも調整できます。

03 / はじめに

1つのアプリ、2つの始め方。

Appleシリコン搭載Mac、macOS 13以降が必要です。どちらもHomebrewで同じネイティブアプリとCLIをインストールします。Herdrへの接続にプラグインは不要です。

01 / HERDRに接続ローカルセッション

Herdrセッションに接続

このMacで実行中のHerdrサーバーにネイティブアプリを手動で接続します（ローカルセッションの観測にはHerdr 0.9.0以降が必要）。サーバーを先に起動し、インストール、バージョン確認、アプリ起動、状態確認の順に進めてください。

Herdr接続用のHomebrewコマンド
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status

CLIのバージョンに加え、実行中アプリのstatusに表示されるバージョンと実行ファイルも確認してください。サーバーの実際のソケットが環境変数や既定のパスと異なる場合は、正しいバックエンドソケットを調べ、herdr-desktop-pet start --socket PATHのPATHをそのパスに置き換えてください。--socketはHerdrバックエンドを指定するもので、アプリの制御ソケットではありません。カードからの返信にはローカルサーバーによるagent.promptのサポートが必要です。受理通知（ACK）はエージェントの作業完了を意味しません。

02 / 単独起動Herdr不要

キャラクターだけを起動

Herdrサーバーなしで同じネイティブアプリを実行できます。初回起動前に、新規設定の「サーバー切断時に終了」を無効にし、保存された設定を確認してください。接続がない状態ではセッションカードや返信は使用できません。

単独起動用のHomebrewコマンド
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet settings set exit_with_herdr off
herdr-desktop-pet settings get
herdr-desktop-pet start
herdr-desktop-pet status

吹き出しを非表示にしてキャラクターだけを表示するには、起動後に必要に応じてherdr-desktop-pet hide_bubbleを実行してください。アプリは引き続き動作します。登録済みのローカルエンドポイントがすべて明示的に無効化・リンク解除された場合、exit_with_herdr offでも終了を防げません。

高度なオプション：Herdrプラグインで起動を管理

上記のネイティブ接続と単独起動にプラグインは不要です。実行中のHerdrホストにプラグインをインストールし、その起動アクションを呼び出す場合にのみ使用してください。固定されたビルド済み配布物を取得できない場合、標準のプラグインインストールがソースビルドに切り替わることがあり、Rust/Cargo、Bun、Node.js/npm、Xcode Command Line Toolsが必要です。

herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet

クライアント接続時の自動起動は別機能です。公式Herdr 0.9.3のソースにclient.attachedパッチを適用してビルドしたホスト、またはこのフックへの対応を明記したホストのリリースが必要です。標準の0.9.0/0.9.3にはフックがありませんが、上記のネイティブアプリの手動起動には不要です。

公開安定版はv0.3.5。arm64アーカイブとチェックサムは公開済みで、個人用tapもv0.3.5を指しています。インストール前にリリース一覧とtapのバージョンを確認してください。既存のインストールを更新する前に、実行中のデーモンを停止してください。アプリはad-hoc署名で、公証は受けていません。

画面写真と公開版は異なります。上記の実際のアプリ画面は隔離されたオフライン環境で撮影したv0.3.2であり、接続中のv0.3.5の画面ではありません。ソースのチェックアウトに記載された目標バージョンは公開状況の証明になりません。ソースビルド、更新、プラグインの要件は日本語READMEをご覧ください。現在のソースにある多言語対応が公開済みバイナリにも含まれるとは限りません。

詳しい操作方法は日本語の利用ガイドをご覧ください。

05 / ご利用前に

よくある質問

使い始める前に知っておきたいこと。

Intel Mac、Windows、Linuxでも動作しますか？

いいえ。ネイティブ版の配布対象はmacOS 13以降を搭載したAppleシリコンMacです。

メッセージの送信成功はエージェントの作業完了を意味しますか？

いいえ。選択したローカルセッションのサーバーがagent.promptに対応している場合にメッセージを送信できます。成功はHerdrが受理したことを示すだけで、エージェントが処理または完了したことは示しません。リモートセッションは閲覧専用です。

標準のHerdrではクライアント接続時に自動起動しますか？

いいえ。自動起動にはclient.attachedフックに対応したホストが必要です。公式Herdr 0.9.3のソースに提供されたパッチを適用するか、このフックへの対応を明記したホストのリリースを使用してください。標準の0.9.0と0.9.3は対応していません。

ほかのキャラクターも同梱されていますか？

いいえ。同梱されるのはRubeliaだけです。追加パックと利用条件は別の公式キャラクターリポジトリをご覧ください。
