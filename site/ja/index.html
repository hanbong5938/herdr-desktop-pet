公開状態

独立アプリ v0.4.0・bridge v0.3.7・formula・連携タグの実際の公開はここでは未確認です。以下は公開後のコマンドです。文書やタグだけで導入可能と判断しないでください。

brew install hanbong5938/tap/desktop-pet
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
# Optional Tern integration:
tern plugin install https://github.com/hanbong5938/tern-desktop-pet

必要な連携だけを選んでください。Herdr は薄い consumer、Tern はアプリを導入・自動起動しません。プラグインの更新・削除は共通アプリ・プロファイル・キャラクターを変更しません。

任意の Herdr attach 自動起動は実際の hook 対応ホストまたは公式 0.9.3 パッチが必要です。プラグイン導入はホストをパッチしません。既存の config/state 両パスを移動・統合せず保持してください。

Tern はアプリを別途導入・起動後、実際の実行ファイル/config/state を Configure → Connect で選びます。実際の Tern 再接続・OMP モデル配送の検証を主張しません。 Tern Connect / Configure.
