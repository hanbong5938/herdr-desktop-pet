과거 v0.3.8 한계: 원래 공개 A는 성공했지만 B preflight는 생성 앱 untracked 파일 68개로 B 동의·Stop 전에 거절됐습니다. 원래 10개 파일/no-ignore 태그를 성공으로 바꾸지 않습니다. 공개 v0.3.9는 /dist/HerdrDesktopPet.app/만 선언하고 실제 CI native /tmp·Git gate가 통과했습니다. 사용자 script/root/기타 dist 변경은 dirty이며 clean/reset·수동 ignore·Unknown 재실행은 금지합니다.

독립 과거 증거: f7 working metadata의 확정 retirement 실패·새 동의 same-plan resume과 이전 실제3.9/4.4 A/B는 당시 증거로 보존하며 새 조합의 성공으로 바꾸지 않습니다. 실제 public3.9 beta 경로는 live/직접 bridge를 거절하고 원본 동결3.6 matched pair를 자동 시작 없이 설치한 뒤 명시적 Start·helper/소스/프로필 보존을 검증했습니다. 나중 beta 경로 실행을 주장하지 않습니다. 새 게시 뒤 기존 공개 권위10개·동결3.6/beta formula 해시는 불변입니다. 실제 버전별 게시·런타임 증거.

Unknown manager와 원래 helper/journal/프로필·사용자 캐릭터를 보존하고 clear/replay·clean/reset하지 마세요. 관측 H1/T0는 실제 Tern provider/account·두 호스트/양쪽 순서의 증거가 아닙니다.

필요한 연동만 선택하세요. Herdr는 얇은 consumer이며 Tern은 앱을 설치하거나 자동 시작하지 않습니다. 플러그인 갱신·제거는 공용 앱·프로필·캐릭터를 바꾸지 않습니다.

Herdr 선택형 attach 자동 시작에는 실제 훅 지원 호스트 또는 공식 0.9.3 패치가 필요합니다. 플러그인 설치는 호스트를 패치하지 않습니다. 기존 두 프로필 경로를 보존하고 이동·병합하지 마세요.

Tern은 앱을 별도로 설치·시작한 후 Configure → Save → Connect로 실제 실행 파일/config/state 경로를 선택합니다. 실제 Tern keychain-provider와 OMP 모델 SDK는 사용할 수 없으며 실제 재연결·모델 전달이나 가짜 receipt·transcript를 주장하지 않습니다. Tern Connect / Configure.
