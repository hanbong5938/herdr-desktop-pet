02 / WHAT IT DOES

작은 움직임부터
세션의 흐름까지.

책상 한편의 캐릭터와 Herdr 작업 상태가 만나는 세 가지 방식.

01 / INTERACT✳

터치에 반응하는 루벨리아

머리와 몸통을 탭하고, 머리를 쓰다듬어 보세요. 캐릭터를 드래그해 옮기거나 크기를 조절할 수 있습니다.

02 / OBSERVE◉

관측된 상태만 보여주기

말풍선의 세션 카드에 유휴·실행 중·입력 대기·상태 불명을 표시합니다. 에이전트의 결과를 추측하지 않습니다.

03 / REPLY↗

로컬 세션에 메시지 제출

선택한 로컬 에이전트 카드에서 메시지를 보낼 수 있습니다. Herdr의 접수는 작업 완료를 뜻하지 않으며 원격 카드는 읽기 전용입니다.

03 / GET STARTED

설치는 원하는 경로로.

Apple Silicon Mac · macOS 13 이상. 아래 명령을 확인하고 사용 중인 환경에 맞는 방법을 선택하세요.

OPTION 01 / HERDR플러그인

Herdr 플러그인

Herdr 플러그인 저장소에서 설치하고, 실행 중인 호스트에서 시작 액션을 호출합니다.

Herdr 플러그인 터미널 명령
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
OPTION 02 / HOMEBREW앱 + CLI

Homebrew

개인 tap의 포뮬러로 네이티브 앱과 CLI를 설치해 직접 시작합니다.

Homebrew 터미널 명령
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet start

v0.3.3 공개 빌드. arm64 압축 파일과 체크섬이 공개되어 있으며 개인 tap 포뮬러도 v0.3.3을 가리킵니다. 설치 전에는 Release 목록과 포뮬러 버전을 확인하세요. 고정된 사전 빌드를 사용할 수 없으면 플러그인 기본 설치는 소스 빌드로 전환할 수 있으며 이때 Rust/Cargo, Bun, Node.js/npm, Xcode Command Line Tools가 필요합니다. 앱은 ad-hoc 서명·미공증입니다.

자동 시작은 호스트에 따라 다릅니다. 클라이언트 attach를 통한 자동 시작에는 공식 Herdr 0.9.3 소스에 제공된 패치를 적용한 호스트 또는 실제로 이 훅을 지원한다고 명시한 호스트 릴리스가 필요합니다. 순정 0.9.0/0.9.3에는 이 훅이 없습니다.

소스 빌드·업그레이드·플러그인 요구 사항은 한국어 README에서 자세히 확인하세요.

05 / GOOD TO KNOW

자주 묻는 질문

시작하기 전 알아둘 점을 모았습니다.

Intel Mac이나 Windows, Linux에서도 사용할 수 있나요?

아니요. 네이티브 배포 대상은 Apple Silicon Mac, macOS 13 이상입니다.

메시지 전송 성공은 에이전트 작업 완료를 뜻하나요?

아니요. 선택한 로컬 세션의 서버가 agent.prompt를 지원할 때 메시지를 제출할 수 있습니다. 성공은 Herdr가 접수했다는 뜻이며 에이전트가 처리하거나 완료했다는 뜻은 아닙니다. 원격 세션은 읽기 전용입니다.

순정 Herdr에서 클라이언트 연결 시 자동으로 시작되나요?

아니요. 자동 시작에는 client.attached 훅을 지원하는 호스트가 필요합니다. 공식 Herdr 0.9.3 소스에 제공된 패치를 적용하거나 해당 훅을 명시적으로 지원하는 호스트 릴리스를 사용하세요. 순정 0.9.0과 0.9.3은 지원하지 않습니다.

다른 캐릭터도 기본 제공되나요?

아니요. 루벨리아만 기본 제공됩니다. 별도 공식 캐릭터 저장소에서 선택형 팩과 사용 조건을 확인하세요.
