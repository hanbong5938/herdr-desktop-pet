현재 실제 공개: Core v0.4.7, 소스 52514da5115f09aac22de5429c08f7acdd993258, Release 413584934, 중립4/2/API1입니다. 진짜 bridge v0.3.11는 같은 Core 소스로 빌드됐으며 metadata ingress fa56caa32ea06d86932c5b4cc3eb230010c6dd9c, Release 413623057, legacy3/1/API1입니다. 공개 자산·엄격 서명·68파일 closure를 검증했고 stable tap 6693cd9db26e6dba9a257bbe76acaf78cb502c2f가 두 버전을 제공합니다. 현재 얇은 consumer의 metadata/evidence 8개는 실제 공개 Core4.7에서 materialize됐으며 installer/status는 같은 검증된 Standalone4.7 프로세스·프로필을 설치·시작·Herdr 재설치 없이 재사용했습니다. Herdr 관리 소스의 retirement는 assetless v0.4.1 6d2ac04/Release412252863 그대로입니다. 새 native build·연동 버전·태그는 없으며 Tern0.2.0·기존 태그/본문/자산/beta도 불변입니다.

실제 공개 앱 이전: 공개 Brew3.10의 일반3.11 A′는 원래 서명 helper로 terminal/quiescent 정착했고, 별도 source review·최종 native 동의 B로 Core4.7 readiness/Commit·실제 소유 Brew retirement까지 완료했습니다. 원래 설정·상태 바이트, 가져온 캐릭터·대사·이력과 무관 프로필을 보존했으며 같은 Core 인스턴스를 현재 consumer가 재사용하고 최종 native Check도 통과했습니다. 4개 언어 review/Cancel, rollback, early/late Stop, ManagerUnknown 보존, 확정 정리 실패 후 독립 동의 same-plan Resume를 실제 검증했습니다. 선택 사용자 Mac은 별도 native 승인 경로입니다. 구3.6 compatibility A와 beta2→동결3.6 matched pair는 공개3.10 A′와 구분합니다.

과거4.5/3.10 증거 — 새 버전의 증거가 아님: managed3.6→공개3.10 A20cca와 독립4.5 B 6ee850aa5577314c6d9cf6ebc7eae981, Brew3594·Herdr3648·Hidden default1971·A87/state239 보존 결과는 당시 버전에만 속합니다. 이전3.6→3.7→Core4.2 성공과 managed3.7의 installed/applied false Unknown도 과거 이력이며 재실행·재분류하지 않습니다. 별도 manual3.11 candidate→공개4.7 B·취소·rollback·early Stop 관측은 소유 Brew retirement의 증거가 아닙니다. 변하는 현재 수용 상태와 정확한 증거는 v0.4.7 canonical ledger를 확인하세요.

과거 v0.3.8 한계: 원래 공개 A는 성공했지만 B preflight는 생성 앱 untracked 파일 68개로 B 동의·Stop 전에 거절됐습니다. 원래 10개 파일/no-ignore 태그를 성공으로 바꾸지 않습니다. 공개 v0.3.9는 /dist/HerdrDesktopPet.app/만 선언하고 실제 CI native /tmp·Git gate가 통과했습니다. 사용자 script/root/기타 dist 변경은 dirty이며 clean/reset·수동 ignore·Unknown 재실행은 금지합니다.

독립 과거 증거: f7 working metadata의 확정 retirement 실패·새 동의 same-plan resume과 이전 실제3.9/4.4 A/B는 당시 증거로 보존하며 새 조합의 성공으로 바꾸지 않습니다. 실제 public3.9 beta 경로는 live/직접 bridge를 거절하고 원본 동결3.6 matched pair를 자동 시작 없이 설치한 뒤 명시적 Start·helper/소스/프로필 보존을 검증했습니다. 나중 beta 경로 실행을 주장하지 않습니다. 새 게시 뒤 기존 공개 권위10개·동결3.6/beta formula 해시는 불변입니다. 실제 버전별 게시·런타임 증거.

실제 사용자 Mac 적용과 main/Pages 배포 관측은 정본 수락 원장을 따릅니다. Core Wiki job 116329481248은 렌더 후 전용 WIKI_PUBLISH_TOKEN 부재로 실패했으며 broad token 대체·binary 재게시는 없습니다. Unknown manager와 원래 helper/journal/프로필·사용자 캐릭터를 보존하고 clear/replay·clean/reset하지 마세요. 관측 H1/T0는 실제 Tern provider/account·두 호스트/양쪽 순서의 증거가 아닙니다.

brew install hanbong5938/tap/desktop-pet
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
# Optional Tern integration:
tern plugin install https://github.com/hanbong5938/tern-desktop-pet

필요한 연동만 선택하세요. Herdr는 얇은 consumer이며 Tern은 앱을 설치하거나 자동 시작하지 않습니다. 플러그인 갱신·제거는 공용 앱·프로필·캐릭터를 바꾸지 않습니다.

Herdr 선택형 attach 자동 시작에는 실제 훅 지원 호스트 또는 공식 0.9.3 패치가 필요합니다. 플러그인 설치는 호스트를 패치하지 않습니다. 기존 두 프로필 경로를 보존하고 이동·병합하지 마세요.

Tern은 앱을 별도로 설치·시작한 후 Configure → Save → Connect로 실제 실행 파일/config/state 경로를 선택합니다. 실제 Tern keychain-provider와 OMP 모델 SDK는 사용할 수 없으며 실제 재연결·모델 전달이나 가짜 receipt·transcript를 주장하지 않습니다. Tern Connect / Configure.
