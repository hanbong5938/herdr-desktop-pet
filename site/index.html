현재 게시 경계

Core v0.4.2는 실제 공개됐습니다. 소스 cb10ce2c3cc65402cbb914d60301f7627d5546d5, Release 412241744, capability 4/2/1입니다. 현재 메타데이터·증거는 익명으로 작성·검토한 실제 v0.4.2이며 v0.4.1은 과거 기록만입니다. Herdr v0.4.0의 생성 네이티브 dist 오류와 불변 공개 태그·본문·자산은 보존합니다. 수정 Herdr v0.4.1은 source·TypeScript·adapter 105개 게이트를 통과했지만 태그·릴리스가 없고 새 ID·최종 SHA도 모릅니다. Bridge v0.3.7은 미공개이며 실제 Core·수정 Herdr pin이 필요합니다. Tern v0.2.0은 과거 호환 Core v0.4.1 pin 그대로입니다. 이전·두 호스트 전체 검증 완료를 주장하지 않습니다.

중립 v0.4.2 포뮬러는 공개됐고 소유한 실제 v0.4.1 → v0.4.2 Brew 업그레이드는 동일/default 프로필 Auto UI/control readiness(PID 6863, 호스트 0개)에 도달했습니다. standalone native-update나 두 호스트·SDK 증거가 아닙니다. 아래 선택형 Herdr 명령은 공개 저장소 연동을 설치하며 미공개 수정 후보를 설치하지 않습니다.

Core Pages는 실제 cb10ce2를 배포했지만 이 Herdr thin-site 후보는 아직 미배포(공개 소스 f65f123)입니다. Core Release는 성공했고 후속 Wiki 작업은 전용 WIKI_PUBLISH_TOKEN 부재로 실패했습니다. 전체 catalog 렌더링은 Wiki 게시가 아닙니다. 정확한 installer/checksum/API·패키지 증거.

brew install hanbong5938/tap/desktop-pet
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
# Optional Tern integration:
tern plugin install https://github.com/hanbong5938/tern-desktop-pet

필요한 연동만 선택하세요. Herdr는 얇은 consumer이며 Tern은 앱을 설치하거나 자동 시작하지 않습니다. 플러그인 갱신·제거는 공용 앱·프로필·캐릭터를 바꾸지 않습니다.

Herdr 선택형 attach 자동 시작에는 실제 훅 지원 호스트 또는 공식 0.9.3 패치가 필요합니다. 플러그인 설치는 호스트를 패치하지 않습니다. 기존 두 프로필 경로를 보존하고 이동·병합하지 마세요.

Tern은 앱을 별도로 설치·시작한 후 Configure → Connect로 실제 실행 파일/config/state 경로를 선택합니다. 실제 Tern keychain-provider와 OMP 모델 SDK는 사용할 수 없으며 실제 재연결·모델 전달이나 가짜 receipt·transcript를 주장하지 않습니다. Tern Connect / Configure.
