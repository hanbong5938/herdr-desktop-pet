NATIVE DESKTOP COMPANION

Herdr 세션을 데스크톱에서 확인하고 로컬 에이전트에 답장하세요.

루벨리아의 말풍선에서 관측된 세션 상태를 보고 선택한 로컬 에이전트에 메시지를 제출할 수 있습니다. 접수 확인은 작업 완료가 아닙니다.

Herdr 연결 방법 ↗실제 앱 화면 ↗

같은 네이티브 앱을 별도 Tern 프로필로 연결하거나 Herdr 없이 캐릭터만 독립 실행할 수 있습니다.

Apple Silicon Mac · macOS 13+ · 기본 캐릭터 루벨리아 1종

연결된 Herdr 세션의 관측 정보와 데스크톱 캐릭터의 세 가지 사용법.

03 / GET STARTED

하나의 앱, 연결 방식 선택.

Apple Silicon Mac · macOS 13 이상. Herdr·Tern·독립 실행 모두 같은 공개 v0.3.6 Homebrew 네이티브 앱과 CLI를 사용합니다. 설치와 시작은 명시적으로 진행하며 Herdr 연결은 플러그인 없이, Tern은 별도 연결 플러그인과 프로필로 사용합니다.

01 / CONNECT HERDR로컬 세션

Herdr 세션 연결

이 Mac에서 실행 중인 Herdr 서버(로컬 세션 관찰은 Herdr 0.9.0 이상)에 네이티브 앱을 수동으로 연결합니다. 서버를 먼저 실행한 뒤 설치·버전 확인·시작·상태 확인 순서로 진행하세요.

Herdr 연결용 Homebrew 명령
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status

CLI 버전과 실행 중인 앱의 status 버전·실행 파일을 함께 확인하세요. Herdr 서버의 실제 소켓이 환경 변수나 기본 경로와 다르면 실제 백엔드 소켓 경로를 확인해 herdr-desktop-pet start --socket PATH의 PATH를 교체해 실행하세요. --socket은 Herdr 백엔드용이며 앱의 제어 소켓이 아닙니다. 카드 답장은 해당 로컬 서버가 agent.prompt를 지원할 때만 가능하고, 접수 ACK는 에이전트 완료가 아닙니다.

02 / INDEPENDENT PETHerdr 불필요

캐릭터만 독립 실행

Herdr 서버 없이 같은 네이티브 앱을 실행합니다. 새 설정의 서버 연결 종료 정책을 첫 시작 전에 끄고 저장 상태를 확인하세요. 세션 카드·답장은 연결 없이 사용할 수 없습니다.

독립 실행용 Homebrew 명령
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet settings set exit_with_herdr off
herdr-desktop-pet settings get
herdr-desktop-pet start
herdr-desktop-pet status

말풍선 없이 캐릭터만 보고 싶다면 시작한 뒤 herdr-desktop-pet hide_bubble을 선택적으로 실행하세요. 앱은 계속 실행됩니다. exit_with_herdr off는 이미 등록된 모든 로컬 endpoint의 명시적 플러그인 비활성화·연결 해제에 따른 종료를 막지는 않습니다.

고급 선택 사항: Herdr 플러그인으로 실행 관리

위 네이티브 연결이나 독립 실행에 플러그인은 필요하지 않습니다. 실행 중인 Herdr 호스트에서 플러그인을 설치하고 시작 액션을 호출하려는 경우에만 사용하세요. 기본 설치가 고정 사전 빌드를 사용할 수 없으면 소스 빌드로 전환될 수 있으며 Rust/Cargo, Bun, Node.js/npm, Xcode Command Line Tools가 필요합니다.

herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet

클라이언트 attach 시 자동 시작은 별도 기능입니다. 공식 Herdr 0.9.3 소스에 client.attached 패치를 적용한 호스트나 실제 훅 지원을 명시한 호스트 릴리스가 필요합니다. 순정 0.9.0/0.9.3에는 해당 훅이 없지만 위 수동 네이티브 시작에는 필요하지 않습니다.

Tern 연결 — 공개 v0.3.6

네이티브 앱과 stable Homebrew 포뮬러가 게시되었습니다. 앱을 먼저 설치한 뒤 Tern 연결 플러그인을 명시적으로 설치하고 별도 Tern 프로필을 수동으로 시작하세요. 이 사전 빌드 경로에는 Rust가 필요하지 않습니다.

brew install hanbong5938/tap/herdr-desktop-pet
tern plugin install https://github.com/hanbong5938/tern-desktop-pet
PET="$(command -v herdr-desktop-pet)"
PET_CONFIG="$HOME/.config/herdr/plugins/config/desktop-pet-tern"
PET_STATE="$HOME/.local/state/herdr/plugins/desktop-pet-tern"
"$PET" --version
"$PET" --host tern --config-dir "$PET_CONFIG" --state-dir "$PET_STATE" start
"$PET" --host tern --config-dir "$PET_CONFIG" --state-dir "$PET_STATE" status

플러그인은 앱을 몰래 다운로드·빌드·실행하지 않습니다. 같은 네이티브 앱의 기본 호스트는 Herdr이며 명시적 --host tern은 Herdr 서버·소켓·플러그인이 필요하지 않습니다. 설정 및 상태를 Herdr와 분리합니다. 실제 Tern 창에서 Configure desktop pet connection을 선택해 위 절대 실행 파일·정확한 설정/상태 경로를 실제 값으로 입력한 뒤 Connect to desktop pet을 선택하세요. 창 연결과 같은 프로필의 네이티브 status를 확인하며 플러그인 설치만으로 연결이나 자동 시작을 가정하지 마세요. 실행 파일이나 모드를 바꾸기 전 같은 프로필을 종료하세요. 자세한 내용은 사용 안내를 참고하세요.

공개 안정판 v0.3.6. 비초안·비프리릴리스 정확한 Release가 GitHub의 관측된 latest입니다. 앱 전용 arm64 압축 파일·.sha256·SHA256SUMS·별도 rig 출처 사이드카 4개를 익명 대조했고 배포 바이트 식별 68개도 모두 일치했습니다. 정확한 압축 파일 다운로드 SHA-256: 5d40f6ada23f7d91d967a98331b28ea767202f5d01b7cd7732b2d9e543fdaafa. stable tap c7be4b5는 이 URL/해시를 사용하며 베타 포뮬러와 이전 v0.3.5-beta.1은 변경하지 않았고 새 v0.3.6 베타가 아닙니다. 업그레이드 전 기존 데몬을 종료하세요. 앱은 ad-hoc 서명·미공증입니다.

증거의 범위를 구분합니다. 실제 Homebrew 업그레이드와 Cargo/Bun/Node/npm 없는 고정 사전 빌드 설치로 네이티브 Tern 전용 시작·유효한 빈 snapshot 교환을 확인했습니다. 공개 Tern 플러그인 CLI 설치도 성공했지만 GUI 창 연결이나 실제 에이전트 전달 주장은 아닙니다. 위 앱 화면은 격리된 오프라인 v0.3.2 촬영이며 v0.3.6 연결 화면이 아닙니다. 게시·소비자 증거·동결 정본 노트·한국어 README를 참고하세요.

05 / GOOD TO KNOW

자주 묻는 질문

시작하기 전 알아둘 점을 모았습니다.

Intel Mac이나 Windows, Linux에서도 사용할 수 있나요?

아니요. 네이티브 배포 대상은 Apple Silicon Mac, macOS 13 이상입니다.

메시지 전송 성공은 에이전트 작업 완료를 뜻하나요?

아니요. 선택한 로컬 세션의 서버가 agent.prompt를 지원할 때 메시지를 제출할 수 있습니다. 성공은 Herdr가 접수했다는 뜻이며 에이전트가 처리하거나 완료했다는 뜻은 아닙니다. 원격 세션은 읽기 전용입니다.

순정 Herdr에서 클라이언트 연결 시 자동으로 시작되나요?

아니요. 자동 시작에는 client.attached 훅을 지원하는 호스트가 필요합니다. 공식 Herdr 0.9.3 소스에 제공된 패치를 적용하거나 해당 훅을 명시적으로 지원하는 호스트 릴리스를 사용하세요. 순정 0.9.0과 0.9.3은 지원하지 않습니다.

다른 캐릭터도 기본 제공되나요?

아니요. 루벨리아만 기본 제공됩니다. 별도 공식 캐릭터 저장소에서 선택형 팩과 사용 조건을 확인하세요.
