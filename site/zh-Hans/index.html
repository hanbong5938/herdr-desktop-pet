brew install hanbong5938/tap/desktop-pet
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
# Optional Tern integration:
tern plugin install https://github.com/hanbong5938/tern-desktop-pet

仅安装所需集成。Herdr 是轻量 consumer；Tern 不安装或自动启动应用。插件更新与移除不会改变共享应用、配置档或角色。

可选 Herdr attach 自动启动需实际支持 hook 的宿主或官方 0.9.3 补丁。安装插件不会为宿主打补丁。保留原 config/state 双路径，不移动或合并。

Tern 需单独安装并启动应用，再通过 Configure → Connect 选择实际执行文件/config/state 三元组。真实 Tern keychain-provider 与 OMP 模型 SDK 前提条件不可用；不声称真实重连／模型传递，也不伪造 receipt/transcript。 Tern Connect / Configure.
