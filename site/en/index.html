Three ways a desktop character connects with your Herdr workspace.

01 / INTERACT✳

Rubelia responds to touch

Tap her head or body, or pet her head for a reaction. Drag her around your desktop and adjust her size.

02 / OBSERVE◉

Observed states, not guesses

The bubble’s session cards show idle, running, waiting, or unknown status. They do not infer an agent’s outcome.

03 / REPLY↗

Submit to a local session

Send a message from a selected local agent card. Herdr accepting it does not mean the work is complete; remote cards are read-only.

03 / GET STARTED

Choose your way in.

Apple Silicon Mac · macOS 13 or later. Pick the installation path that fits your setup.

OPTION 01 / HERDRPlugin

Herdr plugin

Install from the plugin repository, then invoke the start action on a running host.

Herdr plugin terminal commands
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
OPTION 02 / HOMEBREWApp + CLI

Homebrew

Install the native app and CLI from the personal tap, then start it directly.

Homebrew terminal commands
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet start

Public v0.3.3 build. The arm64 archive and checksums are published, and the personal tap formula points to v0.3.3. Check the Release catalog and tap formula version before installing. If the pinned prebuilt cannot be used, default plugin installation may build from source and needs Rust/Cargo, Bun, Node.js/npm, and Xcode Command Line Tools. The app is ad-hoc signed and not notarized.

Auto-start depends on your host. Starting on client attach requires a host built from official Herdr 0.9.3 with the supplied patch, or an actual host release advertising the hook. Stock Herdr 0.9.0 and 0.9.3 do not have it.

For source builds, upgrades, and plugin requirements, read the English README.

05 / GOOD TO KNOW

Frequently asked

A few things to know before you begin.

Does it run on Intel Mac, Windows, or Linux?

No. The native distribution targets Apple Silicon Mac with macOS 13 or later.

Does a successful message mean the agent finished?

No. You can submit a message when the server for your selected local session supports agent.prompt. Success means Herdr accepted it, not that the agent processed or completed it. Remote sessions are read-only.

Will it auto-start on client attach with stock Herdr?

No. Client-attach auto-start requires a host supporting the client.attached hook: apply the supplied patch to official Herdr 0.9.3 source, or use a host release explicitly supporting it. Stock 0.9.0 and 0.9.3 lack this hook.

Are other characters included?

No. Only Rubelia is bundled. Explore optional packs and their terms in the separate official character repository.
