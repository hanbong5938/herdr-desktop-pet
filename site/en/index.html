Publication boundary

Actual publication of independent app v0.4.0, bridge v0.3.7, formula and integration tags has not yet been established here. These are post-publication commands; documentation or tags alone do not prove installability.

brew install hanbong5938/tap/desktop-pet
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
# Optional Tern integration:
tern plugin install https://github.com/hanbong5938/tern-desktop-pet

Install only the integrations you want. Herdr is a thin consumer; Tern never installs or auto-starts the app. Plugin updates/removal do not change the shared app, profile or characters.

Optional Herdr attach auto-start requires a real hook-capable host or the official 0.9.3 patch. Installing the plugin never patches the host. Preserve both existing profile paths without moving or merging them.

For Tern, install/start the app separately, then Configure → Connect using the actual executable/config/state triple. Real Tern reconnect and OMP model delivery are not asserted here. Tern Connect / Configure.
