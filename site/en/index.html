02 / WHAT IT DOES

Three ways to use the observed Herdr workspace and desktop character.

01 / OBSERVE◉

Observed states, not guesses

The bubble’s session cards show idle, running, waiting, or unknown status. They do not infer an agent’s outcome.

Send a message from a selected local agent card. Herdr accepting it does not mean the work is complete; remote cards are read-only.

03 / GET STARTED

One app. Two reasons to start.

Apple Silicon Mac · macOS 13 or later. Both routes install the same native app and CLI via Homebrew. Connecting to Herdr does not require the plugin.

01 / CONNECT HERDRLocal sessions

Connect to Herdr sessions

Manually connect the native app to a running Herdr server on this Mac (Herdr 0.9.0 or later for local session observation). Start the server first, then install, check the version, start the pet and inspect its status.

Homebrew commands for Herdr connection
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status

Check the CLI version and the running app’s status version and executable. If the server’s actual socket differs from the environment/default path, identify its real backend socket and run herdr-desktop-pet start --socket PATH with PATH replaced by that path. --socket selects the Herdr backend, not the app’s control socket. Card replies require that local server to support agent.prompt; an accepted submission does not mean agent completion.

02 / INDEPENDENT PETNo Herdr needed

Run just the character

Run the same native app without a Herdr server. Turn off the new profile’s server-disconnect exit policy before the first start and inspect the saved setting. Session cards and replies need a connection.

Homebrew commands for independent operation
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet settings set exit_with_herdr off
herdr-desktop-pet settings get
herdr-desktop-pet start
herdr-desktop-pet status

For the character without its bubble, optionally run herdr-desktop-pet hide_bubble after starting. The app keeps running. exit_with_herdr off does not prevent shutdown if all registered local endpoints are explicitly disabled or unlinked.

Advanced option: manage startup with a Herdr plugin

Neither native connection nor independent operation above requires the plugin. Use this only to install the plugin and invoke its start action on a running Herdr host. If its pinned prebuilt is unavailable, default plugin installation can fall back to building from source, requiring Rust/Cargo, Bun, Node.js/npm and Xcode Command Line Tools.

herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet

Auto-start on client attach is a separate feature: it requires a host built from official Herdr 0.9.3 source with the client.attached patch, or a host release explicitly supporting that hook. Stock 0.9.0/0.9.3 lack it; manual native startup above does not need it.

Public stable v0.3.5. The arm64 archive and checksums are published and the personal tap points to v0.3.5. Check the Release catalog and tap version before installing. Stop an existing running daemon before upgrading. The app is ad-hoc signed and not notarized.

The capture and release differ. The actual app shots above were captured offline with an isolated v0.3.2 profile, not from a connected v0.3.5 session. A source checkout’s target version does not establish public availability. See the English README for source builds, upgrades and plugin requirements.

05 / GOOD TO KNOW

Frequently asked

A few things to know before you begin.

Does it run on Intel Mac, Windows, or Linux?

No. The native distribution targets Apple Silicon Mac with macOS 13 or later.

Does a successful message mean the agent finished?

No. You can submit a message when the server for your selected local session supports agent.prompt. Success means Herdr accepted it, not that the agent processed or completed it. Remote sessions are read-only.

Will it auto-start on client attach with stock Herdr?

No. Client-attach auto-start requires a host supporting the client.attached hook: apply the supplied patch to official Herdr 0.9.3 source, or use a host release explicitly supporting it. Stock 0.9.0 and 0.9.3 lack this hook.

Are other characters included?

No. Only Rubelia is bundled. Explore optional packs and their terms in the separate official character repository.
