Herdr native rig decoder third-party notices

Native port attribution
-----------------------
This native decoder is a Herdr worker-facing port of the browser ag-psd PSD
loader and the vendored Anime2.5DRig/DAEMONLET loader.  The native TypeScript
entry point is native/rig/decoder.ts.  It uses ag-psd's published browser
bundle (29.0.0) through the explicit web/rig dependency alias; it does not use
ag-psd's Node entry point.  Native validation, bounded packing, and worker
transport are Herdr additions.  No HTML, WebGL host, browser UI, or browser
worker host is part of the native decoder output.

The native build retains strict TypeScript checking and emits the trusted
decoder.js together with this notice and the notice resources under vendor/.
The build intentionally does not copy web/rig/index.html,
web/rig/dist/index.js, web/rig/dist/worker.js, or any WebGL host resource.

Worker runtime signing
-----------------------
Debug and release builds ad-hoc sign only rig-decode-worker with
com.apple.security.cs.allow-jit=true from RigDecodeWorker.entitlements.plist.
This lets JavaScriptCore compile the trusted decoder bundle instead of falling
back to interpreted execution. The main app and native rig library receive no
JIT entitlement; worker isolation, input validation, and resource caps remain
unchanged. App packaging reuses the same plist and verifies effective worker
entitlements and strict signatures after signing the outer app.

Published-browser-bundle closure
--------------------------------
The published ag-psd/dist/bundle.js was audited as an artifact.  It embeds a
browser Buffer shim, ieee754, a JPEG decoder derived from jpeg-js, and a
Browserify util/process closure in addition to ag-psd, base64-js, and pako.
The embedded package versions/source commits for those additional modules are
not recorded in the published artifact and are intentionally reported as
unknown.  Their primary source links, module evidence, attributions, and full
license terms are copied under vendor/licenses/:

  AG-PSD-BROWSER-CLOSURE.txt
  BUFFER-MIT.txt
  IEEE754-BSD-3-CLAUSE.txt
  JPEG-DECODER-APACHE-2.0.txt
  BROWSERIFY-UTILITY-CLOSURE.txt
  PAKO-ZLIB-LICENSE.txt

The JPEG decoder source header specifically carries Apache License 2.0 and
Copyright 2011 notmasteryet; the current jpeg-js repository license is not
substituted for that embedded notice.
