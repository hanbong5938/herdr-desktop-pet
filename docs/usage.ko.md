# Herdr Desktop Pet 사용법

[English](usage.md) · **한국어** · [설치 및 요구 사항](../readme.ko.md) · [CLI 계약](cli.md#한국어)

이 안내는 v0.3.5 **안정판 소스 체크아웃·기본/사전 빌드 대상**을 설명합니다. v0.3.4의 눈 소유권·ABI 일치·출처 기록, v0.3.3의 공식 브라우저/카드·원격 초상화·작업 중 → 유휴 관리 수정과 v0.3.2의 검색·말풍선 크기·대사 초안·네이티브 자동화·protocol-2 업데이트를 유지합니다. v0.3.5는 포인터 캡처 복구·부착 말풍선 배치·IME 답장 표시를 개선하며 캐릭터 선택은 바꾸지 않습니다. 소스와 이 문서만으로 **공개 바이너리나 설치기/포뮬러 게시가 증명되지 않습니다**. 사전 빌드 사용 전 비초안 [GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 arm64 압축 파일·체크섬·별도 rig 출처 사이드카와 설치기/포뮬러 갱신을 확인하세요([한영 노트](releases/v0.3.5.md#한국어), [업그레이드](releases/0.3.md#한국어--v03-계열)). 이전 바이너리는 문서 변경으로 새 기능을 얻지 않으며 프로그램 확인만으로 물리 GUI·IME·접근성을 인증하지 않습니다.

## 조작

| 말풍선 배경 드래그 | 부착 상태에서는 캐릭터 이동, 단독 상태에서는 말풍선만 이동. |
| 말풍선 본문 변·모서리 드래그(Option 포함) | 변은 한 축, 모서리는 두 축의 크기 변경. 캐릭터 배율·글자 크기와 독립. |
| 말풍선 배경·카드 헤더 우클릭/Control-click | **대화창 닫기**는 말풍선만 숨기고 **자동 크기로 복원**은 접힌·펼친 모드의 사용자 크기를 모두 해제. 텍스트 복사/붙여넣기 메뉴와 다른 컨트롤의 기본 동작은 유지. |
| 전체 창 / 투명 영역 클릭 통과 | 전체 창 모드는 캐릭터·말풍선 모두 클릭이 통과되어 조작 불가; 투명 영역 모드는 캐릭터 그림의 투명 부분만 통과하여 말풍선 조작 가능. |

**이 소스 체크아웃:** 좌버튼을 놓았는데 놓기 콜백이 유실된 경우 포인터 캡처를 조용히 복구하며 가짜 탭 반응을 만들지 않습니다. 새로운 누르기는 새 드래그 시작점을 사용하고, 중복·오래된 이벤트는 이를 바꾸거나 다른 창의 조작을 끝낼 수 없습니다. Control-left의 놓기는 이전 탭을 확정하지 않습니다. 정상 탭·Option-드래그·크기 조절점의 동작은 유지합니다. 유효한 말풍선 크기 조절에서 놓기 콜백이 유실되면 아래의 기존 추적·IME 종료 조건에 따라 미리보기를 한 번 확정합니다. 이 변경을 사용하려면 체크아웃을 다시 빌드·설치해야 하며 이미 설치된 공개 바이너리는 바뀌지 않습니다.

접힌·펼친 말풍선 크기 요청은 각각 저장하며 부착·단독 상태에서 공유합니다. 시작한 화면에서 반대 변·모서리는 미리보기와 조작 종료까지 고정되고, 이후 일반적인 부착 배치는 캐릭터를 따릅니다. 변의 요청은 한 축만 바꾸지만 새 줄바꿈으로 다른 축의 표시 최소 크기가 커질 수 있습니다. 높이는 실제 화면·앵커 제한 너비에서 측정하고 저장에 쓰는 고유 최소 너비는 낮추지 않습니다. 변의 비활성 축으로만 움직이거나 활성 변위를 0으로 되돌리면 이전 요청을 유지하고 최신 자동/수동 최소 크기로 다시 배치합니다. 펼친 메시지·카드는 한 높이 예산을 공유하며 카드·답장 최소 공간과 메시지 한 줄을 확보한 뒤 나머지를 나눕니다. 자동 크기에는 전체 높이 제한이 있지만 수동 요청에는 그 자동 제한을 적용하지 않습니다. 실제 영역에 모두 들어가면 스크롤바가 숨겨지고 넘치면 스크롤할 수 있습니다. 작은 화면에서는 표시 크기만 제한하고 요청 크기는 보존합니다.

캐릭터에 연결된 말풍선은 머리 앵커만 피하는 대신 본문 전체를 캐릭터의 안정적인 외곽 경계 밖에 배치합니다. **자동**은 현재 방향에 답장·컨트롤의 최소 공간이 남아 있는 동안 그 방향을 유지하며, 작업 목록 펼치기·답장 열기·실시간 내용 갱신마다 방향 검색을 다시 시작하지 않습니다. 해당 방향의 여유 공간에 맞춰 표시 크기를 제한하더라도 저장한 요청 크기는 덮어쓰지 않습니다. 연결 상태의 크기 조절은 시작 시 잡은 방향의 안전 영역 안에서 미리보기와 종료를 처리하고 반대쪽 변을 고정합니다. 어느 방향에도 최소 공간이 없으면 화면 안에서 겹침이 가장 적은 꼬리 없는 말풍선을 캐릭터 창보다 앞에 표시하며, 공간 확보를 위해 캐릭터를 움직이거나 저장 크기를 바꾸지 않습니다.

답장을 열 때는 부착된 상태의 배치를 먼저 측정한 뒤 포커스를 주고, 선택한 카드·입력칸·커서가 보이도록 스크롤합니다. 재배치는 네이티브 편집기·초안·선택 범위를 보존합니다. IME 조합 중에는 편집기를 재부착하거나 크기를 바꾸지 않도록 내용·배치 변경을 미룹니다. 화면 또는 캐릭터 경계가 바뀌어 현재 창이 안전하지 않게 된 경우에만, 조합 종료 전에 안전한 창 위치로 이동하는 복구를 허용합니다.

캡처된 제스처 외에는 실제 포인터 대상이 말풍선일 때만 크기 커서를 갱신합니다. 텍스트·컨트롤은 네이티브 커서를 사용하며 다른 창·캐릭터 위 커서를 배치 변경으로 초기화하지 않습니다. 크기 변위가 0이어도 실제 단독 위치가 바뀌면 기존 크기 요청과 저장하고, 요청과 배치가 모두 같으면 파일을 쓰지 않습니다. 답장 IME 조합 중에는 크기 조절과 **자동 크기로 복원**을 시작할 수 없습니다. 누른 뒤 조합이 시작되면 미리보기를 멈춥니다. 손을 놓거나 취소하면 추적은 해제하지만 조합과 추적이 모두 끝나 안전할 때까지 저장·보류 갱신을 미루며 카드·초안은 유지합니다. 최종 후보는 최신 내용·언어·배치·화면 제한을 반영하고 한 번만 저장합니다. 실패하면 이전 크기 요청·단독 실제 위치·대기 상태로 복구하고 유령 저장은 하지 않지만 새 내용의 최소 표시 크기는 달라질 수 있습니다. 자동 크기로 복원해도 위치·표시·현재 모드·초안은 유지하며 위치/색상 초기화는 사용자 크기를 지우지 않습니다. 답장에 IME 미확정 문자가 있으면 메뉴 막대 아이콘에서 설정을 바로 열 수 없습니다. 조합을 마치세요. Escape/패널 밖 클릭으로 설정을 닫는 동작은 그대로입니다.

## 세션 검색과 정렬

카드 이름은 관측한 터미널 제목, 이름이 있는 탭, 작업 공간·디렉터리 문맥 순서로 선택합니다. 이름이 없으면 대체 이름을, 중복이면 눈에 보이는 구분자를 붙입니다. 마우스를 올리면 전체 제목·작업 경로·내부 ID가 보입니다. 제목이 바뀌어도 선택·스크롤을 유지하며 단절된 카드는 마지막 제목과 **오프라인** 상태를 표시합니다.

**검색**은 앞뒤 공백을 제거하고 제목·탭/작업 공간·에이전트·관찰 대상 표시 이름·전체 작업 디렉터리·대체 이름의 일부를 대소문자 구별 없이 찾습니다. ID와 소켓 경로는 검색하지 않습니다. **상태** 필터와 검색은 교집합이며 전체 관찰 상태 요약과 반응을 바꾸지 않습니다. **정렬**에는 **기본순**(원래 순서)·**이름순**·**출처순**이 있고 구분선 뒤에 독립적인 **실행 중 우선**이 있습니다. 실행 중 카드를 모든 포함 출처에서 먼저 묶고 각 묶음에 선택한 정렬을 적용합니다. 닫힌 메뉴 제목·접근성 값에도 두 선택을 표시합니다. 모든 상태별 정렬은 아닙니다. GUI는 필터·정렬 후 최대 **128개** 카드를 표시하고 생략 수를 알립니다. CLI `sessions list --limit`는 총 행 한도가 아니라 **페이지 크기**입니다([CLI](cli.md#세션과-에이전트-프롬프트)).

초기값은 빈 검색어·**전체**·**기본순**·실행 중 우선 꺼짐입니다. 정렬/실행 중 우선은 저장에 성공해야 재실행 후 유지되고 실패하면 이전 조작 상태로 되돌립니다. 검색과 상태 필터는 메모리 전용입니다. 필터로 선택한 답장 카드가 숨겨지면 답장칸만 접고 해당 세션 초안은 메모리에 남으며 검색을 지워도 자동으로 다시 열지 않습니다. 검색창에 포커스가 있으면 Enter/Command+Enter가 답장을 보내지 않습니다. Escape는 검색 IME 조합을 먼저 취소하고, 다음에는 검색어를 지우고, 빈 칸에서는 말풍선을 접지 않고 포커스만 끝냅니다. 검색과 답장 조합은 각각 목록 구조 변경을 조합 종료까지 미루지만 실시간 상태는 갱신됩니다.

## 인라인 답장과 메시지 전달

인라인 답장은 v0.1.6부터 배포되었고 안정판 v0.2.0은 답장 글자 잘림 및 Command-A/C/X/V 클립보드 연결을 수정했습니다. 펼친 말풍선의 카드에는 처음에 답장칸이 없으며 **전체** 보기에서도 같습니다. 로컬 에이전트 카드를 누르면 그 아래 한 줄 답장칸을 열고, 다른 카드는 이전 칸을 접고 새 칸을 엽니다. 원격 카드에는 보내기 버튼/답장칸 대신 읽기 전용 안내가 나옵니다. 타이핑·붙여넣기·가져오기로 **확정된** 줄바꿈은 공백으로 바꾸고 IME 미확정 조합은 확정 전까지 그대로 둡니다. **Enter**·**Command+Enter**·**보내기**로 제출하지만 조합 중에는 제출하지 않습니다. Escape는 조합을 먼저 취소하고 아니면 답장칸만 접습니다. 말풍선 밖 클릭도 조합 중이 아닐 때만 답장칸을 접고, 안쪽의 다른 곳을 누르는 것만으로는 접지 않습니다. 어느 동작도 말풍선을 접지 않습니다. 초안은 세션별로 답장칸/말풍선을 접어도 실행 중 메모리에 남지만 재시작 후 복원되지 않습니다. 성공 시 현재 답장과 **일치하는** 입력만 지우고 접습니다. 전송 중 수정이나 선택 변경으로 생긴 새 초안·열린 답장칸은 유지합니다. 실패/전달 불명도 초안과 칸을 보존합니다.

조합 중에는 카드 선택·필터 변경·행 교체를 문자 손실 없이 미룹니다. 조합 종료 후 마지막 필터와 여전히 표시되는 유효한 세션 선택만 적용하며 확정 텍스트는 원래 세션·연결 세대의 초안에 남습니다. 그사이 상태와 전송 가능 여부는 갱신됩니다. 답장칸은 테두리와 팔레트 기반 불투명 배경을 사용하며 작은 네이티브 보내기 버튼은 전송 가능 상태를 따릅니다. 실시간 테마 변경에도 초안과 미확정 입력은 유지됩니다.

메시지는 선택한 **로컬** Herdr 출처의 `agent.prompt` API로만 전달합니다. 전역 CLI·셸·SSH·패널 직접 입력으로 대체하지 않습니다. 로컬 관찰 제외, 출처 오프라인, 오래되거나 준비되지 않은 세션, 서버 메서드 미지원에는 보낼 수 없습니다. `unsupported_method`를 보고하고 우회하지 않습니다. 마지막 관측 카드가 남은 원격 출처도 읽기 전용입니다. 승인/질문 UI는 실제 터미널에서 처리하세요. 이 API는 Herdr 0.9.2에서 확인됐지만 로컬 관찰 최소 버전 0.9.0만으로 실행 중 서버의 지원을 보장하지 않습니다. 제출 **ACK는 에이전트 완료가 아닙니다**. 자동 재전송하지 않으며 불명확한 전달은 수동 재전송 전에 확인하세요. API는 원자적인 예상 세션 보호 없이 패널의 현재 에이전트를 대상으로 하므로 제출 순간 에이전트·세션 교체 경합은 배제할 수 없습니다. 자동화에서는 [CLI 세션 식별·전달 계약](cli.md#세션과-에이전트-프롬프트)을 참고하되 이를 GUI의 우회 전달 수단으로 사용하지 마세요.

## 독립 표시와 메뉴 막대 복구

캐릭터 `show`/`hide`/`toggle`과 **말풍선 → 말풍선 표시 여부**의 `show_bubble`/`hide_bubble`은 독립적입니다. 둘 다 표시하면 말풍선이 붙고, 캐릭터만 켜면 캐릭터만 보이며, 말풍선만 켜면 카드·답장을 쓸 수 있는 꼬리 없는 단독 말풍선이 됩니다. 둘 다 숨겨도 앱과 Herdr 세션은 계속 실행합니다. **대화창 닫기**는 저장된 말풍선 표시만 변경하고 세션·실행 중 메모리의 초안을 삭제하지 않습니다. 문맥 메뉴 취소는 선택·초안을 보존합니다. **설정…**·**대화창 닫기**는 답장 IME 조합 중 비활성화하고 선택 시 다시 검사합니다. 조합 종료 후 메뉴를 다시 여세요. 캐릭터/단독 말풍선의 문맥 설정 또는 표시된 메뉴 막대 아이콘에서 **말풍선 → 말풍선 표시 여부**를 켜 다시 열 수 있습니다. 단독 말풍선 메뉴에는 **캐릭터 표시**도 있습니다.

캐릭터를 숨겨도 말풍선 표시 설정은 그대로입니다. 저장된 단독 위치가 없다면 첫 분리는 계산만 한 위치가 아니라 **실제로 적용된 부착 말풍선 본문** 위치를 사용합니다. 처음부터 캐릭터가 숨겨졌다면 일반 부착 배치가 대체 위치입니다. 위치는 캐릭터 좌표와 별도 저장되며 이후 분리는 IME 조합 중에도 저장된 위치를 우선합니다. 단독 배경 드래그는 말풍선만 옮기고 캐릭터를 켜면 붙고 다시 끄면 단독 위치로 돌아갑니다. 접힘/펼침·답장·재측정에서는 화면 제한 외에 단독 위치를 유지하고 화면 제거·배치 변경으로 화면 밖에 나가면 남은 화면에 복구합니다. 실행 중 선택·보기·답장·초안은 숨김/표시를 지나도 유지되지만 초안은 재시작 후 복원되지 않습니다. 단독 중 바꾼 배치는 재부착할 때만 적용합니다. `reset`은 표시 설정을 유지하고 예전 단독 위치를 지워 필요 시 새로 적용한 부착 배치에서 다시 정하며 캐릭터 좌표를 복사하지 않습니다. 답장 미확정 입력 중 숨김/표시·배치·초기화는 단독 위치 확정을 조합 종료까지 미루고 나중의 초기화는 이전 위치보다 우선합니다. AppKit 콜백에서 조합 문자·확정 초안·선택은 유지됐으나 물리적 IME/포커스 인증은 아닙니다.

**설정 → 메뉴 막대 아이콘**의 **항상 표시**(안정판 v0.2.0 이후 기본)와 **복구가 필요할 때만 표시**는 창 표시와 독립적입니다. 복구 모드에서는 **두 창 모두 숨김** 또는 **전체 창 클릭 통과**일 때 아이콘을 표시합니다. 캐릭터만/단독 말풍선만/둘 다 보이는 조작 가능 상태나 투명 영역 클릭 통과만 켠 상태에서는 두 창이 숨겨지지 않은 한 숨깁니다. 항상 표시는 이들 모든 상태에서 아이콘을 표시합니다. 종료 중에는 어느 모드에도 표시하지 않으며 알파 포인터 폴링만으로 복구 조건을 바꾸지 않습니다. 아이콘 우클릭/Control-click의 **캐릭터 표시·조작 복구**는 복구 필요 시에만 나타나고 캐릭터를 보이게 하며 전체 창 클릭 통과를 끕니다. 말풍선 표시와 투명 영역 클릭 통과는 유지하며 켜진 말풍선은 재부착됩니다. 복구 모드 아이콘은 메뉴를 닫으면 다시 사라지고 CLI `show`는 말풍선을 켜지 않고 캐릭터만 표시합니다. 과거 `bf23ced` 조건부 아이콘은 현재 설정을 상속하는 것이 아닌 [과거 프리뷰](migrations/unreleased.ko.md)의 동작입니다.

`preferences.json`의 `menu_bar_mode`는 `always`/`recovery_only`를 저장합니다. 키 없는 기존 프로필(과거 조건부 프리뷰 포함)도 항상 표시로 시작합니다. 저장 성공은 즉시 적용되어 재시작·다른 설정 저장 후 유지되고 미지의 필드는 보존합니다. 실패하면 이전 모드·아이콘을 유지하며 모드 변경은 창 표시·클릭 통과·위치·초안·실행 관리를 바꾸지 않습니다.

**설정 → 메뉴 막대 아이콘 → 이미지 선택…**에서 **정적 PNG**를 가져옵니다(인코딩 ≤4 MiB, 디코딩 ≤100만 픽셀). 애니메이션·손상·잘림·완전 투명 파일은 거절합니다. 원래 색을 유지해 18 pt 안에 비율대로 맞추고 1×/2× Retina를 제공합니다. 성공한 사본은 설정 디렉터리 `menu-bar-icons/`에 관리하고 선택적 `preferences.json`의 `menu_bar_icon.asset`으로 참조하므로 외부 원본을 이동해도 됩니다. `preferences.json`, `lifecycle.json`, `characters/`와 함께 백업하세요. 설정이 없으면 발바닥 기본 그림을 표시합니다. 가져오기/저장 실패는 이전 선택을 유지하고, 재시작 때 관리 그림이 없어지거나 손상되면 **오류와 기본 그림**을 표시하면서 메타데이터는 유지합니다. **기본 아이콘 복원**은 그림만 바꾸며 모드·창·클릭 통과·위치·초안·실행 관리는 보존합니다. 가져오기는 네이티브 디코딩 전 **모든 PNG 청크 CRC**(보조 청크·IEND 포함), IDAT zlib Adler-32와 색 형식·인터레이스 패스별 정확한 압축 해제 스캔라인 길이를 확인합니다. 관리 사본은 기존 파일을 대체하지 않고 원자적으로 게시합니다. 구형 중단 작업의 개인 임시 하드 링크는 소유·접근 제한·동일 inode가 확인된 별칭일 때만 **동일한 정상 PNG를 명시적으로 다시 가져와** 복구할 수 있습니다. 시작 시 일괄 정리하거나 다른 링크·파일·손상된 PNG를 복구하지 않습니다. [과거 beta 기록](releases/unreleased.md)은 실제 이미지 선택기·VoiceOver 인증이 아닙니다.

## 워크트리 삭제

펼친 말풍선 **카드 헤더**를 우클릭/Control-click하면 현재 선택과 관계없이 그 카드가 대상입니다. **배경**에서 열면 *메뉴를 연 시점* 선택 카드가 대상이고 적격 선택이 없으면 **워크트리 삭제…**가 없습니다. 메뉴에 대상이 표시되며 입력 영역/기타 컨트롤 메뉴는 네이티브 동작 그대로입니다. **대화창 닫기**는 삭제가 아닌 숨김입니다.

확인 창에는 저장소, **정확한 체크아웃 경로**, 카드 하나가 아닌 **작업 공간 전체**의 탭·패널 수가 표시됩니다. 삭제는 그 작업 공간과 모든 탭·패널을 닫고 실행 중 에이전트/프로세스를 종료하며 연결 체크아웃과 **무시된 파일·빌드 출력물**까지 지웁니다. 주 저장소와 Git 브랜치는 삭제하지 않고 휴지통/실행 취소는 없습니다. **취소**가 첫 번째·기본 동작으로 Return·숫자 키패드 Enter·Escape도 취소합니다. **워크트리 삭제**는 별도 두 번째 동작이며 배치 후 기본 취소 버튼 설정에 실패하면 삭제 자체를 중단합니다. 자신의 폐기 가능한 대상, 파일과 모든 프로세스 영향을 먼저 확인하세요.

현재 정상 관찰 중인 일관된 로컬 출처와 유효하고 모호하지 않은 연결 워크트리 메타데이터만 대상입니다. 주 저장소 루트·원격/보관/오프라인 카드·누락/오류 메타데이터·구형 서버는 제외합니다. 서버가 `worktree.remove`를 지원하지 않으면 알릴 뿐 Git/셸/SSH·강제 삭제로 우회하지 않습니다. IME 조합 중 삭제가 비활성화되고 제출 전에도 검사합니다. 한 번에 한 작업만 진행하며 고정한 대상을 확인 후 새 서버 스냅샷으로 다시 검증하고 `force: false`로 **한 번만** 요청합니다. 낙관적 행 삭제나 자동 재시도는 없습니다. 변경된 추적/미추적 파일·잠긴 체크아웃은 서버가 거절할 수 있지만 **ignored 파일은 삭제될 수 있습니다**. 보통 5초 감시자 갱신이 카드 표시의 기준이며 행·선택·창이 바뀌어도 결과 안내는 남습니다. 전달이 불명확하면 **수동 재시도 전 실제 서버/워크트리 상태를 별도로 확인**하세요. 요청은 `workspace_id`를 지정하며 원자적 예상 체크아웃/generation CAS가 없어 마지막 검사 이후 서버 재시작·작업 공간 재연결 경합은 막는다고 보장할 수 없습니다. [CLI 검사 토큰 계약](cli.md#워크트리-제거)은 60초 일회용 검사 대상과 상위 ACK, 이후 pane+session 부재 관측 및 실제 파일시스템 증명을 구분합니다. 실제 작업 체크아웃을 시험에 쓰지 마세요. [과거 beta 관찰](releases/unreleased.md)은 안정판 물리 입력 인증이 아닙니다.

## 말풍선과 캐릭터 설정

메뉴 막대 패널이나 문맥 **설정…**을 여세요. 말풍선 테마와 UI 언어는 네이티브 드롭다운이며 **시스템**은 OS 언어를 따르고 한국어/영어를 직접 선택할 수 있습니다. 테마·언어는 변경 시 저장하고 사용자 지정 색상은 **색상 적용**을 눌러야 합니다. 열린 창의 조용한 색상 충돌 확인은 컨트롤 가능 여부·라벨만 갱신하고 초안·색상 견본·포커스·선택·실행 취소를 건드리지 않으며 닫으면 멈춥니다. 네이티브 드롭다운·스크롤러·드래그 추적 중 말풍선 표시/배치 변경은 미루고 종료 후 최신 설정/상태를 적용합니다.

**말풍선 → 상태 아이콘·색상 표시**는 기본 켜짐이며 즉시 적용·재시작 후 유지됩니다. 끄면 문자만 표시합니다. 작업 중 파랑, 확인 대기 주황, **검증된** 성공 초록 체크, 실패 빨강이며 `Done`/승인 결과 없는 유휴는 성공으로 추측하지 않고 중립색입니다. 동일 세션의 변하지 않은 검증 완료 보고는 유휴 이벤트/스냅샷에도 유지되지만 새 작업·세션 정체성 모호함·보고 소실·단절 시 해제되며 모호함이 해소되어도 같은 캐시 보고를 재수락하지 않습니다. 새 출처는 빈 스냅샷을 포함해 첫 일관된 스냅샷 전까지 오프라인입니다. 전체 요약의 초록 체크는 **관찰 중 모든 세션의 검증된 성공**을 뜻하며 카드 필터/표시 한도와 무관합니다. 상태에는 텍스트도 항상 있고 장식 아이콘은 접근성 트리에서 제외하며 카드는 전체 제목/상태를 중복 자식 없이 제공합니다. 표시 ON/OFF는 카드 선택·필터·초안을 유지합니다. 투명 영역 클릭 통과는 포인터 폴링 방식이므로 클릭 경합을 허용할 수 없다면 끄세요.

**캐릭터** 탭은 현재/후보/작업 요약이 간결하며 후보도 의미 있는 상태도 없으면 빈 선택 카드를 숨깁니다. 아래에서 브라우저·작업 안내를 설명합니다. 탭 전환·상태 갱신 시 캐릭터 탭은 보이는 내용에 맞춰 높이가 바뀌고 말풍선·설정 탭은 기존 높이/스크롤을 유지하며 작은 화면에서는 실제 내용을 스크롤합니다. 팩 v5와 루벨리아 `default@0`은 변경되지 않았습니다([v0.3.3 수정](releases/v0.3.3.md#한국어)).

## 대사 편집

**캐릭터 → 대사 편집…**에서 별도의 크기 조절 가능한 다크 테마 창을 엽니다(기본 내용 영역 760×560, 최소 창 620×480). 실행 중 캐릭터를 바꾸지 않고 사용 가능한 캐릭터와 **원문 리비전**을 선택하고 UI 언어와 독립적인 한국어/영어 및 8개 항목(대기·작업 중·확인 대기·상태 불명·머리 터치·몸 터치·쓰다듬기·관측된 작업 완료)을 고릅니다. 상단 선택, 왼쪽 이벤트, 중앙 입력·펼칠 수 있는 별도 원본 참조, 하단 고정 상태/동작 영역으로 구성합니다. 긴 이름·오류는 마우스를 올려 전문을 봅니다. 배지는 미저장 수정을 표시합니다. 사용자 문구가 없으면 원본 문구가 처음 입력란에 채워집니다. 사용자 문구는 해당 대사만 대체하고 관측 세션 수·상태 전환·반응 시간·단절 안내는 바꾸지 않습니다.

**대사 저장**/**Command+S**는 언어·항목 하나만 저장하며 항목당 **2048 UTF-8 바이트**(글자 수 아님)까지 허용합니다. 빈 문자열/공백만 저장하면 해당 사용자 대사를 제거하며 팩/기본 반응/상태 문구로 돌아갈 뿐 말풍선을 숨기지 않습니다. 현재 실행 캐릭터와 ID가 같으면 과거 리비전에서 저장해도 해당 말풍선 문구를 갱신하고, 다른 캐릭터를 편집해도 활성화하지 않습니다. **이 대사 초기화**는 미저장 초안이 사라질 때 확인하며 **캐릭터 대사 전체 초기화…**는 항상 확인하고 두 언어의 사용자 대사를 제거합니다. 초안은 캐릭터·언어·항목별로 분리되고 문맥/UI 언어 변경과 창 닫기/다시 열기를 지나 실행 중 메모리에 남지만 재시작 후에는 저장된 항목만 남습니다. **Command+Z**/**Shift+Command+Z** 실행 취소/다시 실행은 현재 편집 문맥별입니다. 저장 실패 시 초안과 이전 확정 문구를 유지합니다.

사용자 대사는 팩 파일이 아닌 `preferences.json`에 저장합니다. 내장·가져온 캐릭터는 ID 키로 리비전·업데이트·복원 사이에 공유합니다. 외부 `--assets`는 정규화된 경로로 따로 저장하며 활성화 시 확정한 경로는 이번 실행 중 원본 폴더 이름을 바꿔도 편집 가능하지만, 재시작 때 `--assets` 경로를 바꾸면 기존 저장 문구는 **자동 이전되지 않습니다**. 관리 registry 두 파일이 모두 손상되어 읽기 전용 폴백에 들어가도 내장 원본은 현재 목록 generation에서 활성화·registry 복구 없이 읽을 수 있습니다. 사용 불가능한 관리 리비전은 복구된 것처럼 표시하지 않습니다.

외부 저장은 편집 초안을 조용히 덮지 않습니다. 오래된 리비전/항목 충돌은 저장을 막고 **저장값 불러오기**는 최신 확정 문구를 명시적으로 가져오며 **초안 기준 갱신**은 로컬 텍스트를 새 기준에 유지한 뒤 저장 전 재검증합니다. 충돌 중 텍스트·포커스/선택·실행 취소 이력을 유지하고 IME 조합 중에는 불러오기/기준 갱신을 조합 종료까지 미룹니다. 정확한 `(target, reference)`나 사용 불가 참조와 초안을 보존하며 몰래 다른 리비전으로 변경하지 않습니다. 첫 준비 완료 메타데이터는 포커스 중이어도 손대지 않은 필드를 채우지만 도착 전 원문 편집(공백·IME 포함)은 초안으로 남고 조합 종료 후 보류 동기화를 처리해 이후 포커스·선택·실행 취소를 덮지 않습니다. 자동 조회는 캐시된 메타데이터 오류를 반복하지 않고 명시적 다시 열기/선택 또는 새 읽기에서 한 번 재시도할 수 있습니다. CLI의 전체 identity JSON, 원문 reference/generation, 선택적 baseline은 같은 안전 경계입니다([대사 CLI 계약](cli.md#대화문-dialogue)). 충돌 제어는 이전 v0.2.0/v0.2.1 바이너리에 소급 적용되지 않습니다.

## 캐릭터 팩

기본 제공은 루벨리아(`default@0`) **한 개**이며 PNG/rig 선택형 캐릭터·의상은 별도 [캐릭터 갤러리](https://hanbong5938.github.io/herdr-characters/)에 있습니다. **캐릭터 → 캐릭터 브라우저 열기…**는 별도의 유지되는 크기 조절 가능 네이티브 창입니다. 이름·ID와 공식 태그를 검색하고 **전체 / 설치됨 / 공식 카탈로그**로 필터링합니다. 정지 초상화는 설치 팩 아카이브가 아니며 찾아보기만 해서는 다운로드하지 않습니다. 네트워크/카탈로그 오류에서도 기본·로컬 팩은 관리할 수 있지만 공식 다운로드는 불가하고 지원되지 않는 형식은 다운로드·적용 버튼이 비활성입니다. 실제 게시된 지원 공식 카드의 **다운로드 및 적용**을 명시적으로 눌러 검증 다운로드·설치·활성화를 요청하세요. 같은 ID의 공식/설치 팩은 필터 전반에 **카드 한 개**이며 설치 리비전이 실제로 활성화돼야 설치됨/공식 카탈로그 양쪽에서 **활성**으로 보입니다. 설치 카드에는 로컬 초상화와 선택·조회/진단·업데이트/삭제·과거 리비전 복원이 남습니다. 같은 ID의 수동 가져오기 팩은 공식 출처/버전의 증거가 아니고 자동 덮어쓰지 않습니다. 원격 1024 × 1024 rig 미리보기는 **인코딩·디코딩 각 4 MiB** 예산에서 허용하며 팩 검증 제한은 바뀌지 않습니다.

설치 카드/리비전의 **선택**은 후보만 지정하므로 고정 푸터에서 검토한 뒤 **캐릭터 적용**을 눌러야 합니다. **선택 취소**는 제출 전 후보만 지웁니다. 두 창을 닫아도 후보가 보존되고 브라우저 검색/필터도 다시 열면 남습니다. 폴더/`.herdrchar` **캐릭터 추가…**만으로는 후보·활성 캐릭터가 바뀌지 않습니다. CLI `pack select ID`는 최신 리비전, `pack restore ID --revision N`은 기존 과거 리비전을 UI 적용 없이 즉시 선택합니다. 활성 팩을 삭제하면 루벨리아로 돌아가며 기본 `default@0`은 가져오기·업데이트·삭제할 수 없습니다. 창을 닫아도 진행 중 다운로드는 계속되고 **다운로드 취소**는 커밋 전까지만 변경을 막습니다.

팩 변경 중에는 선택/적용/선택 취소/가져오기/업데이트/삭제/복원을 차단하고 읽기 전용 조회·진단은 허용합니다. 팩 변경이 진행 중이지 않다면 IME 조합 중 오래된 렌더링 카드의 변경 동작은 차단하고 선택 취소·조회는 계속 허용할 수 있습니다. 파일 선택기/확인 창에서 돌아오면 바쁜 작업과 목록 generation을 다시 검사하고 자동으로 최신 generation으로 맞추지 않습니다. 팩 저장소 잠금 경합은 초상화 로딩을 잠시 연장할 수 있지만 실제 미리보기 실패는 오류입니다. 작업 중 → 유휴 전환 시 설치 카드/세대 교체 없이 업데이트·삭제·복원 가능 여부를 갱신하고 조회는 유지합니다. 취소/실패해도 후보는 남습니다. **제출되지 않은 거절**과 **제출 후 결과 불명**은 다릅니다. 후자의 전체 작업 ID를 푸터 툴팁/진단에서 확인해 `pack status OPID`로 조사하고 무작정 재실행하지 마세요. 적용 완료/새 후보 뒤에도 최근 UI 작업 세부 결과는 진단에 남습니다. 비활성 팩의 가져오기/업데이트/삭제는 렌더러 활성화가 없어도 완료될 수 있으며 현재 캐릭터·저장 선택의 불일치는 완료 여부와 별도로 표시합니다. 네이티브 활성화 실패 시 설치/저장과 화면의 캐릭터는 다를 수 있습니다. **성공적으로 완료된 캐릭터 팩 작업 요약 카드만 숨기고** 진단은 남깁니다. 후보·오류·진행·실패·취소·결과 불명은 계속 표시하며 후보 없이 의미 있는 안내 제목은 **작업**입니다. 세션의 검증 성공 요약은 숨기지 않습니다.

팩 CLI의 선택/복원 ID는 위치 인자(`--id` 없음)입니다. 작업 ID·예상 generation·유한 대기/비대기 옵션이 있으며 기본 오프라인 변경은 동기 완료하지만 명시적인 비동기/유한 대기는 데몬이 필요하고 몰래 실행하지 않습니다. ACK는 저장/네이티브 적용이 아니고 유한 대기는 ACK 후 잠자기·상태·디코딩 전체에 절대 기한 하나를 적용하며 이미 최종 실패인 `--no-wait` 결과도 오류 종료합니다. 불명확하면 작업 ID를 보관해 조회하고 재시도하지 마세요. URL/카탈로그 CLI로 새 공식 브라우저 작업을 만드는 명령은 없습니다. 전체 명령 표 대신 [팩 CLI 계약](cli.md#팩-명령-및-기존-경계)을 사용하세요. 캐릭터 제작/템플릿은 [개발 안내](development.ko.md#캐릭터-제작)에서 다룹니다.

## 관찰 대상 설정

원격 관찰은 v0.1.6에 처음 배포됐고 안정판 v0.2.0에는 간결한 관찰 설정·재연결 명령 복사·단독 원격 전용 watcher 시작 수정이 포함됩니다. **설정 → 관찰 대상**의 **이 Mac**은 기본 켜짐, **원격 머신**은 기본 꺼짐입니다. 원격에서는 먼저 **대화형 터미널**에서 [Herdr 저장 머신 안내](https://herdr.dev/docs/0.9.2/connecting-machines/)에 따라 SSH 머신을 추가·인증하세요(예: `herdr machine add workbox`). 원격 서버 설치/승인 질문도 터미널에서 해결합니다. 그런 다음 원격 머신을 켜고 **관찰할 머신**에서 활성 저장 프로필을 명시적으로 선택합니다. 프로필 하나는 호스트 전체가 아니라 **저장된 원격 Herdr 세션 하나**를 관찰합니다. 등록·attach만으로 선택되지 않습니다. 화면을 표시할 **로컬 Mac**에서 앱을 실행하세요. 원격 호스트에는 호환 Herdr 서버만 필요하고 앱/플러그인은 필요 없으며 로컬 CLI로 조회합니다.

아직 정상적인 로컬 서버가 없을 때 원격 전용 프로필을 설정하려면 **첫 앱 시작 전에** 설치된 네이티브 CLI에서 선택적으로 `herdr-desktop-pet settings set exit_with_herdr off`를 실행해 30초 종료 유예 후 종료되지 않게 할 수 있습니다. 원격 조회가 정상이 되면 원한다면 다시 켜세요. 원격 플러그인/Herdr 플러그인 액션은 필요 없습니다. **이 Mac**을 꺼도 로컬 카드만 제외하며 등록 로컬 실행 관리 endpoint나 비활성화 확정 종료를 바꾸지 않습니다. 머신 목록은 원격 관찰이 꺼져도 **5초**마다 갱신되고 켜졌을 때는 선택된 활성 프로필만 **5초**마다 조회합니다. 선택은 앱 재시작·원격 끄기를 지나도 유지되고 이름 변경에도 유지됩니다. 프로필 비활성화/삭제는 관찰만 제외하며 프로세스를 중지하지 않습니다. 로컬·각 원격 출처는 같은 세션 ID라도 별도 카드 레이블/정체성을 사용합니다.

행은 이름·저장 세션·상태를 분리해 표시하고 긴 오류는 줄바꿈하고 스크롤합니다. 최초 목록 조회와 빈 목록을 구분하며 갱신 실패 시 이전 목록과 오래된 목록 경고를 함께 보여줍니다. 원격을 끄면 예전 성공 상태가 아닌 **관찰 꺼짐**을 보여줍니다. 미선택·일시 중지·확인 중·관찰 중·이용 불가·비활성 상태도 구분합니다. 불투명 프로필 ID 기준 컨트롤 재사용으로 폴링/이름 변경 때 포커스·스크롤을 보존하고 목록이 줄면 스크롤 범위를 조정합니다. 라벨/문맥 접근성 이름은 한영 현지화했고 **등록 방법**/접힌 진단은 읽기 전용입니다. 출처 스위치·선택 프로필은 카드·수·전체 상태·완료/결과 반응을 결정하고 카드의 상태 필터는 포함된 카드의 표시만 바꿉니다. 모두 끄면 일부러 제외한 출처의 단절 경고가 아닌 **알 수 없음**입니다.

폴링 사이 5초 미만의 상태 변화·짧은 완료는 놓칠 수 있습니다. 단절 시 마지막 카드는 **오프라인**으로 남고 실시간이 아닌 상태 불명으로 집계됩니다. 재연결/재선택 후 첫 스냅샷은 과거 완료를 재생하지 않는 기준값입니다. 인증 문제 시 `herdr machine list`로 ID를 확인하고 아래 명령의 인용된 자리표시자를 정확한 ID로 바꾸어 **사용자가 대화형 터미널에서 직접** 실행하세요: `herdr machine reconnect '<profile-id>'`. **오류 자세히 보기**는 읽기 전용이며 **재연결 명령 복사**는 안전하게 인용된 명령만 복사하고 실행하지 않습니다. 앱은 인증 질문에 답하거나 원격 소프트웨어를 설치하거나 실패한 원격 관찰을 로컬 조회로 대체하지 않으며 원격 카드는 읽기 전용입니다. 로컬 관찰은 Herdr ≥0.9.0이고 원격에는 [Herdr 0.9.2 CLI 문서](https://herdr.dev/docs/0.9.2/cli-reference/#saved-ssh-machines)에 설명된 **로컬 CLI**의 저장 머신 API 전달(`herdr --machine <profile-id> api snapshot`)과 호환 원격 서버가 추가로 필요합니다. CLI 부족은 설정에서 보고하며 로컬 관찰의 버전 기준을 올리지 않습니다. `client.attached` 자동 실행에는 단순 0.9.3 매니페스트 기준이 아닌 **별도 패치 호스트**가 필요합니다([호스트 통합](../integrations/herdr/README.md)).

## 실행 관리와 플러그인 액션

설정의 **Herdr 실행 시 자동 시작**(`auto_start`)과 **모든 Herdr 서버 연결이 끊기면 종료**(`exit_with_herdr`)는 새 프로필에서 둘 다 켜진 독립 스위치입니다. 기존 `lifecycle.json`의 boolean `enabled`는 false까지 그대로 `auto_start`로 이전하고 빠진 `exit_with_herdr`는 기존 독립 실행 동작을 위해 꺼짐으로 시작합니다. 둘 다 `preferences.json`이 아닌 `lifecycle.json`에만 저장하고 endpoint·시작 메타데이터와 무관한 필드를 보존합니다. 잘못된 JSON/값은 기본값으로 초기화하지 않고 오류이며 저장 실패도 기존 스위치·실행 정책을 보존하고 오류를 표시합니다.

자동 시작이 켜지면 서버 시작 또는 **성공한 shell/terminal 클라이언트 attach**에서 앱이 없을 때 실행합니다. 꺼진 상태의 자동 `ensure`는 없는 앱을 정상적으로 건너뛰며 실행 중 endpoint는 등록할 수 있지만 숨긴 앱을 강제로 표시하지 않습니다. 수동 `start`는 설정을 바꾸지 않고 실행됩니다. `stop`/네이티브 **Quit**은 시작 대기 중인 경우를 포함해 이번 실행만 종료합니다. `restart`는 수동으로 다시 시작하고 설정·위치·크기를 보존합니다. 자동 시작이 켜져 있다면 다음 해당 이벤트에서 다시 시작할 수 있으므로 이를 막으려면 스위치를 끄세요. Herdr 플러그인 비활성화/연결 해제는 **별도 호스트 기능**입니다. 순정 Herdr 0.9.0/0.9.3은 `client.attached`가 없으며 공식 0.9.3의 제공 패치 또는 추후 실제 훅 제공 호스트가 필요합니다. 알 수 없는 훅 경고는 성공이 아닙니다([호스트 통합](../integrations/herdr/README.md)).

처음 관찰한 로컬 endpoint에서 유효한 `plugin_list`에 `desktop-pet`이 없다면 **이 서버에 미설치**, 비활성화가 아닙니다. 로컬 스냅샷·선택한 원격 관찰은 계속할 수 있습니다. 명시적 `enabled: false`는 endpoint를 분리합니다. 같은 데몬이 그 endpoint에서 활성화 **또는 비활성화** 항목을 한 번이라도 봤다면 이후 항목 부재는 연결 해제로 취급하고 분리합니다. 기억은 이번 실행의 재확인·재연결을 지나지만 새 데몬에서는 초기화됩니다. **등록된 모든 로컬 endpoint**의 비활성화/연결 해제가 확정되면 원격 서버가 정상이어도, `exit_with_herdr`가 꺼져도 **즉시** 종료합니다. 처음부터 항목이 없던 경우는 이 조건이 아닙니다. 그 외에는 종료 스위치가 켜졌을 때 **마지막 정상 서버 연결**이 끊긴 뒤 **30초** 내 정상 연결이 돌아오지 않으면 종료합니다. 처음 시작부터 연결이 없어도 같은 유예를 적용합니다. 클라이언트 detach만으로 서버를 잃은 것이 아니며 오래된 endpoint/실패 재시도로 유예를 늘리지 않습니다. 스위치를 끄면 카운트다운을 취소하고 단절 상태에서 켜면 새 30초를 시작합니다. 정상 서버 하나만 남아도 앱을 유지하며 종료 설정을 끄면 수동 앱은 Herdr 없이 유지할 수 있습니다. 자동 시작 변경만으로 이번 앱을 종료/표시하지 않으며 `show`/`hide`/`toggle`은 표시만 바꿉니다.

실행 중 활성 Herdr 호스트에서는 `herdr plugin action invoke status --plugin desktop-pet` 형태로 `settings`, `restart`, `stop` 등도 호출합니다. 전역 `settings`는 앱이 꺼져도 **실행 관리 설정창만** 열지만 해당 호스트가 필요합니다. 네이티브 앱 실행 파일의 `settings`, `settings get`, `settings set auto_start off`, `settings set exit_with_herdr on`은 호스트 없이 가능하며 get/set은 구조화 JSON을 반환합니다. set은 정확한 두 키와 `on|off`만 허용하고 앱을 시작하거나 다른 설정을 바꾸지 않으며 잘못된 입력·저장 실패를 오류로 반환합니다. `status`도 둘 다 보고합니다. 추가 액션 ID는 실행 관리 `start`, `ensure`, `stop`, `restart`, `status`, `settings`; 표시 `show`, `hide`, `toggle`; 클릭 통과 `passthrough`, `alpha_passthrough`; 말풍선 `show_bubble`, `hide_bubble`, `bubble_above|below|left|right|auto`; 위치·크기 `reset`, `bigger`, `smaller`입니다. [네이티브 CLI 계약](cli.md#한국어)은 즉시 액션과 절대값 presentation/preferences, 비공개 소켓과 명령 계열별 작업 조회를 구별하며 공개 `orchestrate`/HTTP 서비스는 없습니다.

## 앱 내 업데이트

**설정 → 앱 업데이트**에는 자동 확인(기본 켜짐), **지금 확인**, 실행 버전·출처, 마지막 성공 확인과 출처별 명시적 버튼이 있습니다. 앱 실행 중 자동 확인은 하루 최대 한 번입니다. 둘 다 **읽기 전용 확인**이며 설치·재시작·Brew 메타데이터 갱신·Git 변경을 하지 않습니다. 베타 전환 또는 채널/ref 자동 변경은 없고 실행에는 별도 네이티브 동의가 필요합니다.

- **Herdr 관리:** 지정 소켓의 부모나 앱의 덮어쓴 프로필이 아닌 *원래 주입된 호스트 플러그인 설정·전역 Herdr registry*를 사용합니다. 활성 source/ref, 체크아웃 루트, 플러그인 하위 디렉터리는 별개이며 하위 디렉터리 플러그인도 전체 체크아웃이 설치 경계입니다. 새로운 CLI 파일만으로는 부족하고 **같은 실행 중 호환 호스트**(updater는 ≥0.9.3)가 출처를 확인해야 설치를 제안합니다.
- **Homebrew:** 캡처한 manager prefix와 정확한 안정판/베타 포뮬러·채널을 유지합니다. 실제 교체 경계는 prefix 전체가 아닌 **그 포뮬러의 모든 keg를 포괄하는 Cellar 하위 트리**입니다. 다른 베타 포뮬러는 안정판을 막지 않지만 동일 포뮬러의 다른 실행 프로필은 막습니다. 확인은 캐시 메타데이터만 읽고 별도 승인한 업그레이드에서만 갱신·동일 포뮬러 교체가 가능합니다.
- **로컬 체크아웃:** 디스크의 현재 파일을 명시적으로 다시 빌드하고 Git pull/reset/ref 변경은 하지 않습니다. 동일 실행 파일로 재빌드됐어도 새 인스턴스가 실제 준비돼야 적용입니다.
- **검증된 외부 설치:** 이미 설치된 서명·protocol-2 호환 패키지라면 설치기를 재실행하지 않는 **설치된 업데이트 적용**을 제안할 수 있습니다. 수동/불명 출처를 Herdr/Homebrew로 몰래 바꾸지 않습니다.

동의와 Prepare는 미저장 초안·IME·진행 작업·제스처를 다시 확인하고 변경 조작을 동결하지만 **정확한 원본 인스턴스는 계속 실행**합니다. 대사 undo/redo 및 브라우저 검색/필터/로컬 폴더의 AX·내부 callback도 포함하며 안전한 취소/조정 뒤 기존 제어 상태·편집 이력을 복원합니다. 도우미 소유권 **ACK는 설치·Stop·Quit 완료가 아닙니다**. 정확히 예약한 Stop의 수락 응답이 전부 전달되어야 updater 종료를 확정할 수 있습니다. 답장 전송 실패에는 설치를 시작하지 않고 원본을 해동하며 일반 사용자 Stop/Quit가 updater 재시작보다 우선합니다. **도우미 생성 전** 실패가 입증된 경우 원인을 수정하고 새 Check 후 재시도할 수 있지만 도우미 생성/소유권 불명은 근거 있는 복구 전까지 막습니다.

독립 **서명 도우미**와 선택 설정·상태·사용자 에셋은 실제 교체할 설치 경로 밖에 있어야 하며 같은 물리 설치를 공유하는 다른 실행 프로필도 교체를 막습니다. 도우미는 선택 프로필·백엔드·에셋을 유지하고 새 인스턴스의 실제 준비를 확인하며 **설치**와 **적용**을 구분합니다. 적용됨은 “공개 최신판”이 아닙니다. 불명·활성·읽을 수 없는·구형 protocol 예약은 근거를 보존하고 위험한 새 작업을 막으며 관리자 자동 재실행이나 저널 자동 삭제를 하지 않습니다. 정확한 원본이 준비된 **NoSpawn** 중단만 입증되면 원본을 재시작하지 않고 해동하고, 이후 성공한 새 Check에서 이전 이력을 지우지 않고 새 계획을 제안할 수 있습니다. 영속화된 실행 의도 뒤에는 PID/종료 정보가 없어도 관리자 작업이 불명확할 수 있어 반복 실행해서는 안 됩니다. 오프라인 `update-status`는 저장 기록이지 현재 프로세스/서명 증명이 아닙니다. 검증한 비공개 도우미의 `status`와 lease를 갖는 명시적 `recover`(재실행 아님)를 [업데이트 상태·복구 계약](cli.md#앱-업데이트-상태와-복구)에 따라 사용하세요. 검증된 설치 후보도 명시적 복구 시작 전에는 미적용일 수 있습니다. 구 protocol-1 계획/예약은 보존·차단하고 자동 이전/삭제하지 않습니다. 기존 공개 v0.2.0/v0.2.1·옛 베타는 확인만으로 protocol 2가 되지 않습니다. 먼저 이 소스를 `--source`로 설치하거나 실제 공개 v0.3.3 자산을 검증해 설치하세요. 소스 매니페스트/버전만으로 자산 게시나 채널 전환을 주장할 수 없습니다.

## 설정과 문제 해결

- `HERDR_PLUGIN_CONFIG_DIR`에는 `lifecycle.json`(두 실행 관리 스위치), `preferences.json`(기타 설정·대사), 관리 `characters/`·`menu-bar-icons/`가 있고 `HERDR_PLUGIN_STATE_DIR`에는 프로세스 잠금·`<state-dir>/control.sock`·데몬 `desktop-pet.log`와 업데이트 상태가 있습니다. 주입되지 않으면 Herdr XDG 플러그인 설정/상태 디렉터리를 사용합니다. 네이티브 `--config-dir`·`--state-dir`로 프로필을 격리할 수 있지만 주입된 환경변수가 우선합니다. 특히 안정판/베타 동시 사용은 시작·명령·종료·백업에 실제 설정 **및 상태** 두 경로를 맞추세요. `--socket PATH`는 네이티브 CLI 제어 소켓이 아닌 Herdr 백엔드 지정입니다([CLI 연결 계약](cli.md#연결-식별자-작업-상태)).
- 창 숨김이나 전체 클릭 통과는 시작 실패가 아닙니다. 위의 메뉴 막대 복구를 사용하세요. `plugin link` 후 실행되지 않았다면 `client.attached` 경고를 확인하고 수동 `start`, 데몬 `status`·로그를 확인하세요. 꺼진 `auto_start`는 의도적인 자동 시작 건너뜀이고 실행 중 호스트에 연결만 해서는 바로 실행되지 않습니다. 패치 호스트 격리 설치와 훅 확인은 [호스트 안내](../integrations/herdr/README.md)에 있습니다.
- `Herdr watchers are shutting down`이 나오면 상속된 `HERDR_SOCKET_PATH`/`HERDR_CLIENT_SOCKET_PATH`, `PATH`의 실제 Herdr CLI 실행 파일/버전, 그 소켓을 소유한 서버를 확인하세요. **다른 서버**의 `herdr plugin list`로 데몬의 endpoint를 판정할 수 없습니다. 같은 CLI·소켓·세션을 대상으로 조사하고 원격이면 저장 머신 전달 지원 버전/선택 프로필도 검사하세요. 패치 호스트는 자동 실행 훅을 제공할 뿐 모든 서버에 플러그인을 설치하지 않습니다.
- 원격 오류는 [관찰 대상 설정](#관찰-대상-설정)의 프로필 상태·대화형 재인증·API 전달 CLI를 확인하세요. 로컬 화면을 원하면 원격 호스트에서 SSH로 GUI를 실행하지 마세요. `agent.prompt` 제한과 원격 읽기 전용은 [메시지 전달](#인라인-답장과-메시지-전달)을 참고하세요.
- 릴리스 다운로드 오류 시 `github.com` 접근 및 실제 Release 자산을 확인하세요. 명시적 `--prebuilt`는 **소스 빌드로 전환하지 않으며** 옵션 없는 설치만 조건부로 소스 빌드하므로 도구가 필요합니다. 포뮬러 게시를 별도 확인하고 ad-hoc 서명 검증을 Developer ID 서명/공증으로 오인하지 마세요([설치](../readme.ko.md)).
- 제공자 연동은 Herdr 업스트림 기능을 사용하며 해당 수명주기 훅 설치 뒤 기존 제공자 세션을 재시작/다시 로드하세요. 앱은 관측 상태만 표시하고 제공자 결과를 추측하지 않습니다. 버전별 동작은 [릴리스 기록](releases/README.ko.md), 호스트 세부 사항은 [호스트 통합](../integrations/herdr/README.md)을 참고하세요.
