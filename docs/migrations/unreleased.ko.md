# 로컬 Unreleased 네이티브 체크아웃으로 업그레이드

[English](unreleased.md) · [Unreleased 기록](../releases/unreleased.md) · [버전 문서](../releases/README.ko.md)

**이 안내는 로컬 `worktree/rapid-harbor-d2a6`의 `bf23ced1649fd0074aec8736644c8f02aa0c492b`에만 적용하며 `main`이나 공개 v0.1.11 바이너리의 동작 안내가 아닙니다.** 문맥 설정·조건부 복구, 캐릭터·말풍선 독립 표시, 간결한 관찰 설정, 단독·원격 전용 watcher 시작의 네이티브 네 묶음은 이 로컬 체크아웃에 구현되었지만 병합되지 않았습니다. 문서·게시 도구가 `main`에 반영되어도 네이티브 기능이 함께 병합되는 것은 아닙니다. 고정된 공개 앱과 앱 버전은 여전히 **v0.1.11**이며 다음 버전·미리보기 다운로드는 지정하지 않습니다. 브랜치·커밋은 구현을 식별할 뿐 공개 원격에서 가져올 수 있다는 보장이 아닙니다. 인라인 답장은 이미 v0.1.6에 배포되었습니다. [이전 입력창 이전 안내](v0.1.4-to-v0.1.6.md#한국어)를 참고하세요.

`main`이나 공개 바이너리는 [루트 설치·실행 안내](../../readme.ko.md)를 따르세요. 기준 앱은 기존 메뉴 막대 설정 진입점과 로컬·원격 관찰 설정을 사용합니다. `main` 소스 빌드에서 이 안내의 독립 표시·조건부 복구·간결한 관찰 UI·문맥 설정·watcher 시작 수정을 기대하지 마세요. 아래 네이티브 미리보기 동작은 해당 로컬 체크아웃에만 적용하며 공통 설정·데이터 보존·IME·메시지 전달·호스트 기능 경고는 여전히 중요합니다.

## 기존 프로필 보존

기존 `HERDR_PLUGIN_CONFIG_DIR` / `HERDR_PLUGIN_STATE_DIR` 또는 같은 Herdr XDG 플러그인 프로필을 사용하세요. 앱 교체 전에 설정을 백업하세요. `lifecycle.json`, `preferences.json`, `characters/`를 유지하며 업그레이드 때문에 삭제·재생성하지 마세요. 저장된 캐릭터 선택·가져온 리비전·사용자 대사는 기존 저장소에 남습니다. 재시작 후에는 저장한 대사만 유지되며 답장·편집기 초안은 현재 실행의 메모리에만 남습니다. 실행 관리 설정은 `lifecycle.json`만 소유하며 예전 `enabled`를 `false`도 유지해 `auto_start`로 옮깁니다. 기존 프로필에 `exit_with_herdr`가 없으면 꺼짐으로 이전하고 새 프로필은 둘 다 켜짐입니다. endpoint·startup·무관한 필드를 보존하며 잘못된 설정은 오류로 보고합니다. 저장 실패는 이전 스위치·실행 정책을 유지하고 프로필을 초기화하지 않습니다. 외부 `--assets` 대사는 활성화 시 정규화한 경로 키를 사용하며 재시작 시 폴더 이름을 바꿔도 기존 키를 자동 이전하지 않습니다.

**해당 로컬 구현을 이미 가지고 있을 때만** 그 체크아웃에서 `bash scripts/install.sh --source`를 실행하고 도구·패키징·패치된 호스트 연결은 [소스 설치 안내](../../readme.ko.md#이-체크아웃-설치-소스-빌드)를 따르세요. 이 명령은 현재 체크아웃을 빌드할 뿐 로컬 브랜치를 가져오거나 구현을 바꾸지 않으며 `main`에서 실행해도 네이티브 미리보기 기능을 **제공하지 않습니다**. 옵션 없는 설치는 보통 고정된 v0.1.11 바이너리를 내려받고 `--prebuilt`는 소스로 전환하지 않습니다. 네이티브 실행 파일·액션 ID·캐릭터 팩 형식은 그대로 유지합니다. 이 안내는 앱·호스트 릴리스, 원격 플러그인 자동 설치, 새 설정 프로필이나 SSH 전송 변경을 요구하지 않습니다. 새 체크아웃이 저장한 데이터의 다운그레이드 호환성은 보장하지 않습니다.

## 표시 상태는 독립적이며 실행 관리가 아님

| 캐릭터 | 말풍선 | 로컬 미병합 체크아웃 결과 |
| --- | --- | --- |
| 표시 | 표시 | 캐릭터에 부착된 말풍선 |
| 표시 | 숨김 | 캐릭터만 표시 |
| 숨김 | 표시 | 꼬리 없는 이동 가능한 단독 말풍선, 세션 카드·답장 사용 가능 |
| 숨김 | 숨김 | 창은 없지만 앱·세션은 계속 실행, 복구 아이콘 사용 가능 |

`show` / `hide` / `toggle`은 캐릭터만 표시·숨김합니다. 말풍선은 `show_bubble` / `hide_bubble` 또는 **말풍선 → 말풍선 표시 여부**로 별도 제어합니다. 캐릭터를 숨겨도 켜진 말풍선은 숨기지 않습니다. 최초 분리 위치는 캐릭터 좌표가 아닌 부착된 말풍선 배치에서 계산하며 단독 위치를 별도로 저장하고 다음 분리 때 복원합니다. 캐릭터를 표시하면 다시 부착합니다. 단독 배경 드래그는 말풍선만 움직입니다. 작은 보기·펼친 보기와 답장 재배치는 화면 범위 조정이 필요한 경우 외에는 위치를 유지하며 디스플레이 제거·배치 변경 시 화면 밖 말풍선을 남은 화면으로 복구합니다.

현재 실행에서 캐릭터 숨김·표시를 바꿔도 카드 선택·작은/펼친 보기·답장 상태·초안·포커스·입력기(IME) 조합은 유지합니다. 초안은 재시작 후 사라집니다. 단독 상태에서 바꾼 배치 설정은 다시 부착할 때 적용합니다. `reset`은 두 표시 설정을 바꾸지 않고 캐릭터 위치를 초기화하고 단독 위치를 지우거나 부착 배치에서 다시 설정합니다. 캐릭터 좌표를 단독 위치 설정에 복사하지 않습니다. **대화창 닫기**는 말풍선만 숨기고 앱·캐릭터·세션과 실행 중 초안을 유지하며 말풍선 표시 설정을 저장합니다.

전체 창 클릭 통과는 두 창 모두에 적용되어 단독 말풍선·인라인 답장도 조작할 수 없습니다. 투명 영역 클릭 통과는 캐릭터 그림에만 적용되고 말풍선은 조작 가능합니다. 포인터 폴링 방식의 클릭 전달 경합이 허용되지 않으면 투명 영역 클릭 통과를 끄세요.

## 설정과 조건부 복구

캐릭터·대화창 배경·카드 헤더를 우클릭 또는 Control-click하고 **설정…**을 선택하면 동일한 전체 3탭 패널을 엽니다. 텍스트 입력은 네이티브 편집 메뉴를 유지하고 버튼·드롭다운·스크롤바도 기존 네이티브 동작을 유지합니다. 메뉴 취소는 카드 선택·초안을 보존합니다. 입력기 미확정 문자가 있으면 대화창의 **설정…**과 **대화창 닫기**를 비활성화하고 선택 시에도 조합 여부를 다시 확인합니다. 조합을 마친 뒤 메뉴를 다시 여세요. 최신 macOS 활성화 API와 macOS 13 호환 경로를 사용하지만 키보드 포커스 이동 허용 여부는 macOS가 결정합니다.

메뉴 막대 복구 아이콘은 **두 창 모두 숨김 또는 전체 창 클릭 통과 켜짐**일 때만 표시하며 재시작 후·설정창이 열린 중에도 같은 조건을 적용합니다. 두 창 표시·캐릭터만 표시·조작 가능한 단독 말풍선만 표시 상태에서는 메뉴 막대 자리를 차지하지 않습니다. 투명 영역 포인터 폴링만으로 아이콘을 표시·숨김하지 않습니다. 단독 말풍선 메뉴에는 **캐릭터 표시**가 있습니다.

**캐릭터 표시·조작 복구 / Show and Enable Character**는 캐릭터를 표시하고 전체 창 클릭 통과를 끕니다. 말풍선 표시와 투명 영역 클릭 통과는 그대로 둡니다. 표시 중인 말풍선은 다시 부착하고 숨겨진 말풍선은 숨김을 유지합니다. 전체 초기화가 아닌 일부 설정만 바꾸는 복구입니다. 메뉴의 **설정…**과 **종료**도 사용할 수 있습니다. CLI `show`는 이 복구 액션과 달리 캐릭터 표시만 바꾸고 말풍선을 켜거나 전체 클릭 통과를 끄지 않습니다.

## 원격 관찰: 저장된 선택 유지·읽기 전용

**이 Mac**은 기본 켜짐, **원격 머신**은 기본 꺼짐입니다. 오른쪽 정렬 네이티브 스위치는 **관찰할 머신** 아래 저장된 프로필 선택과 별도입니다. 행은 머신 이름·저장된 세션·상태를 구분합니다. 내용에 맞는 행·카드·스크롤 크기로 고정 간격·중복 도움말을 대체하며 불투명한 프로필 ID별 컨트롤 재사용으로 폴링·이름 변경 중 포커스·스크롤을 유지합니다. 목록이 줄면 스크롤 범위를 조정합니다. 레이블·문맥 접근성 이름은 한국어·영어로 제공합니다.

최초 목록 조회·확인된 빈 목록·미선택·일시 중지·확인 중·관찰 중·사용 불가·비활성을 구분합니다. 조회 실패 시 이전 목록을 유지하고 오래된 목록임을 명시합니다. 원격 관찰을 꺼도 선택을 유지하되 이전 성공 상태는 관찰 꺼짐 안내로 가립니다. 머신 등록·이름 변경이 새 프로필을 자동 선택하지 않습니다. 프로필 비활성화·제거는 관찰에서 제외할 뿐 원격 프로세스를 종료하지 않습니다. 모든 관찰을 끄면 알 수 없음 상태입니다. 관찰 스위치는 카드·수·상태·반응을 제어하고 카드 필터는 표시되는 카드만 좁힙니다.

SSH 설정·머신 등록/인증·서버 설정 승인은 [대화형 Herdr 터미널](https://herdr.dev/docs/0.9.2/connecting-machines/)에서 직접 진행하세요. 선택한 활성 프로필은 호스트 전체가 아닌 저장된 원격 세션 하나를 관찰합니다. 원격에는 호환되는 실행 서버가 필요하지만 캐릭터 앱·플러그인은 필요하지 않습니다. 목록 갱신·선택 프로필 조회는 약 5초 간격이고 원격 관찰을 꺼도 목록을 갱신합니다. 짧은 전환은 누락될 수 있습니다. 끊긴 카드의 데이터는 마지막으로 본 오프라인·알 수 없음 데이터이지 실시간 상태가 아닙니다. 복구·재선택 직후 첫 스냅샷은 기준 상태이며 이전 완료 반응을 재생하지 않습니다.

등록 안내와 접힌 진단은 읽기 전용입니다. **재연결 명령 복사**는 프로필 ID를 안전하게 셸 인용한 `herdr machine reconnect '<profile-id>'` 명령을 클립보드에 복사하고 네이티브 피드백을 제공하며 **실행하지 않습니다**. `herdr machine list`로 ID를 확인하고 터미널에서 직접 복구하세요. 앱은 인증을 묻거나 원격 소프트웨어를 설치하거나 SSH 전송을 바꾸거나 원격 실패를 로컬 조회로 대체하지 않습니다. 원격 카드는 관찰 전용이며 머신 전달 경로로 메시지를 보내지 않습니다.

## 원격 전용 시작과 watcher 종료

캐릭터는 **로컬 Mac**에서 실행합니다. 터미널에서 저장 머신을 인증하고 **원격 머신**을 켠 뒤 활성 프로필을 명시적으로 선택하세요. 원격 세션 attach·머신 등록만으로는 관찰하지 않습니다. 아직 정상 로컬 서버가 없다면 선택적으로 **처음 시작 전에** 네이티브 CLI를 사용하세요.

```sh
herdr-desktop-pet settings set exit_with_herdr off
```

소스 설치에서는 설치된 CLI 대신 `./dist/HerdrDesktopPet.app/Contents/MacOS/herdr-desktop-pet`을 사용할 수 있습니다. 네이티브 설정은 캐릭터가 꺼짐·호스트 없음·플러그인 비활성 상태에서도 동작하고 캐릭터를 실행하지 않습니다. Herdr 플러그인 액션은 실행 중인 활성 호스트가 필요합니다. 원격 조회가 정상화되면 원할 경우 `exit_with_herdr on`으로 다시 켜세요.

**이 Mac 끄기는 로컬 표시 데이터만 제외하며 로컬 endpoint의 실행 관리를 끄지 않습니다.** 최초의 유효한 로컬 `plugin_list`에 desktop-pet이 없는 것은 비활성화가 아닙니다. 로컬 스냅샷·구독·원격 조회를 유지합니다. 명시적 `enabled: false`는 해당 endpoint를 분리합니다. 이 데몬에서 활성 또는 비활성 행을 이전에 본 뒤 사라진 것은 관찰된 연결 해제이므로 분리합니다. 이 이력은 같은 데몬의 재확인·재연결 중 유지되지만 새 데몬에는 이어지지 않습니다.

**등록된 모든 로컬 endpoint에서 비활성화·연결 해제가 확인되면 즉시 종료**하며 정상 원격 조회·`exit_with_herdr` 꺼짐도 예외가 아닙니다. 최초부터 항목이 없음은 이 종료 조건이 아닙니다. 나머지 정상 연결 소실은 종료 설정이 켜졌을 때 기존 30초 유예를 적용하며 최초 서버 없는 시작도 포함합니다. 정상 재연결은 유예를 취소하고 정상 서버 하나가 남으면 종료하지 않습니다. 클라이언트 detach는 서버 소실이 아니며 오래된 endpoint·실패한 재시도는 유예를 늘리지 않습니다. 종료 설정을 끄면 진행 중 유예를 취소하고 단절 중 켜면 새 30초를 시작합니다. Stop·Quit은 현재 실행만 끝내며 자동 시작을 끄지 않으면 다음 조건 충족 이벤트로 재실행할 수 있습니다. 자동 시작 설정 변경 자체는 현재 캐릭터를 종료·표시하지 않습니다.

## 기능 요구 사항을 따로 진단

로컬 관찰은 Herdr 0.9.0 이상을 지원합니다. 원격 조회는 [저장 머신 API 전달](https://herdr.dev/docs/0.9.2/cli-reference/#saved-ssh-machines)을 지원하는 로컬 CLI(`herdr --machine <profile-id> api snapshot`, 0.9.2 문서의 기능)와 호환 원격 서버가 필요합니다. 로컬 답장에는 별도로 `agent.prompt`가 필요하며 원래 기록은 0.9.2에서의 확인이지 관찰 최소 버전을 만족하는 모든 서버의 지원 보장이 아닙니다. 오프라인·오래된 세션·준비되지 않은 대상·미지원 대상은 전송할 수 없습니다. 셸·SSH·패널 입력 우회나 자동 재시도는 없습니다. 전달 불명은 재전송 전에 확인하고 승인·질문은 실제 터미널에서 처리하세요. 예상 세션을 원자적으로 검증하지 않는 API라 제출 순간 패널 대상 교체 가능성이 남습니다.

client-attach 자동 시작은 별도로 공식 Herdr 0.9.3 소스에 [client-attached 패치](../../integrations/herdr/client-attached.patch)를 적용·빌드한 호스트 또는 실제로 훅 지원을 명시한 릴리스가 필요합니다. 순정 0.9.0·0.9.3에는 없으며 manifest 최소 버전은 지원 증거가 아닙니다. [패치된 호스트 안내](../../integrations/herdr/README.md)의 `PATCHED_HERDR`를 사용하고 PATH의 순정 `herdr`로 대신하지 마세요. 연결 경고와 구독 수락을 확인하세요. 이미 실행 중인 서버에 플러그인을 연결·활성화만 해서는 캐릭터가 실행되지 않으며 한 번 시작하거나 다음 조건 충족 attach를 기다려야 합니다.

`Herdr watchers are shutting down`이면 상속된 `HERDR_SOCKET_PATH` / `HERDR_CLIENT_SOCKET_PATH`, PATH의 CLI 파일·버전, 해당 소켓을 제공하는 서버를 따로 확인하세요. 다른 서버의 플러그인 목록은 데몬이 관찰한 endpoint의 진단이 아닙니다. 원하는 CLI·소켓·세션을 함께 확인하고 원격 프로필·전달 CLI 버전도 점검하세요. 패치된 호스트가 어느 서버에도 desktop-pet을 설치해 주지는 않습니다.
