# Herdr Desktop Pet v0.1.5 release notes

## Status: tagged, no published binary

This historical page is reconstructed from the [v0.1.5 source tag](https://github.com/hanbong5938/herdr-desktop-pet/tree/v0.1.5), its original documentation, and the subsequent v0.1.6 integration evidence. **v0.1.5 exists as a tag only: packaging failed before assets were published. There is no published v0.1.5 binary or publication date to report.** A source tag or a README's anticipated prebuilt is not a completed Release.

## Intended changes and packaging failure

The tagged source documents the replacement of v0.1.4's always-visible multiline composer with on-demand, one-line replies under selected local session cards, plus the approved ten-pose Rubelia redraw and character/dialogue UI work. These changes first reached a published binary in [v0.1.6](v0.1.6.md); the v0.1.5 documentation's statements that its prebuilt includes them describe an intended artifact, not a shipped one.

The failure applied **one decoder's deadline to the entire ten-pose catalog**. Catalog preparation needed to account for all bounded decoder-worker batches plus renderer setup. The v0.1.6 fix expands the catalog preparation budget while keeping individual decoder timeouts, worker count, and RGBA quotas enforced; it does not remove resource limits or promise instant startup.

## Upgrading safely

Use a published release rather than looking for v0.1.5 assets. When upgrading from the [v0.1.4 composer](v0.1.4.md) to v0.1.6 inline replies, **Enter changes from inserting a newline to submitting a prompt**; committed line breaks become spaces. Escape cancels active IME composition first, otherwise folds only the reply rather than collapsing the bubble. Follow the [v0.1.4 → v0.1.6 migration](../migrations/v0.1.4-to-v0.1.6.md).

Replies remain local-only `agent.prompt`; remote cards are read-only. An ACK means prompt acceptance, not completed agent work. If delivery is uncertain, inspect the session before manually resending; there is no automatic retry. Drafts are in memory only and do not survive restart. The source tag is not a new Herdr host release: client-attach auto-start still requires official Herdr 0.9.3 with the supplied patch applied and built, or an actual host release advertising the hook; stock 0.9.0/0.9.3 and a manifest version floor do not prove support. See the [host integration guide](../../integrations/herdr/README.md).

### 한국어 요약

v0.1.5는 **태그만 있으며 사전 빌드 바이너리는 게시되지 않았습니다**. 한 디코더의 제한 시간을 열 포즈 전체 카탈로그에 적용해 패키징이 실패했고, v0.1.6에서 전체 작업 묶음과 렌더러 준비 시간을 반영하면서 개별 제한은 유지했습니다. v0.1.4에서 게시된 v0.1.6으로 옮길 때 **Enter는 줄바꿈이 아니라 전송**으로 바뀝니다. IME 조합 중에는 전송하지 않으며 Escape는 먼저 조합을 취소하고, 그 외에는 답장칸만 접습니다. 원격 카드는 읽기 전용이고 ACK는 처리 완료가 아닙니다. 전달 여부가 불명확하면 실제 세션을 확인한 뒤 재전송하세요. 자동 재시도와 재시작 후 초안 복원은 없습니다. 클라이언트 attach 자동 실행에는 제공된 패치를 적용해 빌드한 공식 Herdr 0.9.3 호스트(또는 실제로 훅을 지원하는 후속 릴리스)가 필요합니다. 앱 태그나 최소 버전 표기만으로 순정 호스트의 지원이 보장되지 않습니다.
