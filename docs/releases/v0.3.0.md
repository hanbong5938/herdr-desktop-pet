**v0.3.0 stable source and the default/prebuilt target.** These manifests select `0.3.0`; this reviewed note is prepared before the exact release tag. A successful public v0.3.0 installation is established only by the non-draft GitHub Release with a complete uploaded archive and checksums and by the updated stable installer/formula—not by this note or a tag alone. `--source` builds the checkout in hand. Public v0.2.1 remains a separate historical Arin compatibility release.

## Changes from v0.2.1

- The expanded bubble adds Search intersecting the Status filter, Stable/Name/Source ordering and independent Running first priority before the 128-card display cap. Search/Status are in-memory; sort choices persist only after a successful save. Selecting a filtered-out card folds its reply without erasing its exact-session draft; IME composition defers structural list updates, and Enter in Search cannot send a prompt.
- Native same-UID CLI automation provides `presentation`, `preferences`, `sessions`, `dialogue` and guarded `worktree` commands. Read the coherent snapshot, use daemon/session identities and operation IDs, then query family-scoped status on uncertain delivery instead of blindly retrying. `sessions list --limit` is a page size, not the GUI row cap; worktree removal requires a short-lived, one-use inspection token and can delete ignored files. Remote sessions stay read-only, and an `agent.prompt` ACK is not agent completion. See the [CLI contract](../cli.md).
- Dialogue editing preserves unsaved text, selection, IME and undo across metadata refresh; concurrent external changes expose a conflict instead of overwriting a local draft. Explicitly reload saved text or rebase the draft before saving. Reply and editor drafts remain memory-only and do not survive app restart.
- Compact/expanded, attached/standalone bubbles resize from all four body edges and corners; requested mode sizes persist in `preferences.json`, while absent overrides use automatic sizing. Native controls retain their input regions and scrolling; Restore automatic size clears the two size overrides without resetting visibility, position, selection or drafts.
- The native character browser searches installed and official catalog cards. Browsing does not download packs; **Download & Apply** explicitly obtains, verifies, installs and selects a supported published official pack. A matching local ID is not assumed to be the official pack or silently replaced. The optional pack catalog and downloads are separate from the app release. Rubelia remains the only bundled `default@0`.
- **Settings → App updates** provides default-on, read-only daily checking and Check now, with the running version/source and an explicit installation-origin-specific action after native consent. Protocol 2 separates managed Herdr source/ref, Homebrew formula Cellar root, local rebuild and already installed candidate application; checks never install, restart, pull Git or refresh Brew metadata. A signed standalone helper uses a durable execution fence, installation/profile reservation and explicit recovery rather than replaying uncertain work. `installed` and `applied` are separate; old protocol-1 journals/reservations remain preserved and blocked, not silently migrated. A check or an Apply result is not proof of the latest public release. See [updater recovery](../cli.md#app-update-status-and-recovery).
- The rig decode **worker only** gains the JIT entitlement for its decoder runtime. The main app, renderer, character pack format v5, resource limits, artwork, motion and licenses are unchanged. This preserves the v0.2.1 reference-only `meshSource` fix: Arin archive validation still requires app v0.2.1 or newer. Existing v0.2.0 native visibility/lifecycle and reply behavior remain.

## 한국어 · v0.3.0 안정판 안내

**v0.3.0 안정판 소스이자 기본/사전 빌드 대상입니다.** 네 매니페스트는 `0.3.0`을 선택하며 이 정본 노트는 정확한 릴리스 태그 이전에 검토합니다. v0.3.0 공개 설치 성공은 문서·태그가 아니라 draft가 아닌 GitHub Release의 완전한 압축 파일·체크섬 자산과 갱신된 안정판 설치기/포뮬러, 설치된 CLI·실행 데몬의 버전/경로로 확인하세요. `--source`는 현재 체크아웃을 빌드합니다. 이전 공개 v0.2.1 Arin 호환성 릴리스는 별도 역사로 유지합니다. 실제 게시 상태는 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)을 확인하세요.

- 펼친 말풍선에 상태 필터와 교집합인 검색, 기본순·이름순·출처순 정렬 및 독립적인 실행 중 우선이 추가됐습니다. 128개 GUI 표시 제한 전에 적용합니다. 검색·상태는 메모리 전용이고 정렬은 저장 성공 시에만 유지됩니다. 필터로 숨겨진 답장 초안은 해당 세션에 유지하며 검색창 Enter는 전송하지 않고 IME 조합 중 목록 구조 변경은 보류합니다.
- 같은 사용자 전용 소켓의 네이티브 CLI에서 `presentation`, `preferences`, `sessions`, `dialogue`, 보호된 `worktree` 자동화를 제공합니다. 데몬·세션 신원, 일관된 읽기와 작업 ID를 확인하고 불확실한 전달은 재시도 전에 명령 계열별 status로 조사하세요. `sessions list --limit`는 GUI 총 표시량이 아닌 페이지 크기입니다. 워크트리 삭제는 한 번만 쓰는 짧은 수명의 검사 토큰이 필요하며 무시된 파일도 삭제할 수 있습니다. 원격 세션은 읽기 전용이고 Herdr 접수는 에이전트 완료가 아닙니다. [CLI 계약](../cli.md#한국어)을 따르세요.
- 대사 편집은 메타데이터 갱신에도 미저장 초안·선택·IME·실행 취소를 유지하며 외부 변경과 충돌하면 조용히 덮어쓰지 않습니다. 저장값을 명시적으로 불러오거나 초안 기준을 갱신하세요. 답장·편집기 초안은 재시작 후에는 남지 않습니다.
- 말풍선은 접힘/펼침·연결/단독 상태의 네 변·네 모서리로 크기를 조절합니다. 모드별 요청 크기는 `preferences.json`에 보존하고 설정값이 없으면 자동 크기입니다. 네이티브 입력 영역과 실제 넘침 스크롤을 유지하며 **자동 크기로 복원**은 크기 요청 두 개만 지웁니다.
- 네이티브 캐릭터 브라우저는 설치된 팩과 공식 카탈로그를 검색합니다. 탐색만으로 팩을 받지 않으며 지원하는 공개 공식 팩에서 **다운로드 및 적용**을 명시적으로 선택해야 다운로드·검증·설치·선택합니다. 같은 ID의 로컬 팩을 공식본으로 간주하거나 자동 교체하지 않습니다. 팩 카탈로그·다운로드는 앱 배포와 별개이고 기본 번들은 루벨리아 `default@0` 하나입니다.
- **설정 → 앱 업데이트**는 기본 켜진 읽기 전용 하루 간격 확인과 지금 확인을 제공하고 실행 버전·출처와 별도 동의가 필요한 설치 출처별 조치를 표시합니다. 확인만으로 설치·재시작·Git 변경·Brew 캐시 갱신은 하지 않습니다. protocol 2는 Herdr 원본/ref, Homebrew 실제 포뮬러 Cellar 루트, 로컬 재빌드, 이미 설치된 후보를 구분하고 독립 도우미의 실행 fence·예약·명시 복구로 불확실한 작업을 재실행하지 않습니다. 설치와 적용 결과는 별도이며 구형 protocol-1 기록은 자동 변환·삭제하지 않고 차단·보존합니다. [업데이트 복구 계약](../cli.md#한국어)을 확인하세요.
- rig 디코더 **worker에만** JIT 권한을 부여합니다. 본체·렌더러·팩 형식 v5·자원 제한·그림·동작·라이선스는 바꾸지 않습니다. v0.2.1의 참조 전용 `meshSource` 호환성 수정을 유지하므로 Arin 압축 팩 검증에는 앱 v0.2.1 이상이 필요합니다. v0.2.0 네이티브 표시·실행 관리·답장 동작도 유지합니다.

PR #17의 병합 전 소스 `4eb2eb3ecbe1b949e021aaef2b22650d7e32f713`에는 native 573개(ignored 1개), coordinator 29개, Bun 55개/기대값 469개, TypeScript·설치 문법·release 빌드·패키징 및 로컬 **ad-hoc** 서명 본체/도우미 검사가 기록돼 있습니다. 격리된 AppKit/AX·LocalRebuild·ApplyInstalled·명시 복구의 실제 소스 관찰은 [과거 기록](unreleased.md)에 남깁니다. 별도 이전 JIT 소스 측정의 10모델 중앙값 16.20초→1.31초는 한 M4 Max에서의 결과이지 전체 환경 보장이나 현재 병합 빌드 증거가 아닙니다. 이 기록은 새 v0.3.0 태그·공개 압축 파일·사용자 Brew 업그레이드·Developer ID 서명/공증·물리 입력 인증이 아닙니다.

**v0.3.0 통합 소스의 실제 로컬 검사(PR #17과 별개):** TypeScript, Bun 56개/기대값 477개, native 주 테스트 587개 통과·1개 ignored와 별도 FIFO 자식 1개(총 588개 통과), 실제 메인 스레드 AppKit composer, coordinator 29개(라이브러리 21개·바이너리 8개), 설치기 셸 문법, native release 빌드·패키징, 안정판 v0.3.0 release-docs 검사를 통과했습니다. 소유 호스트/프로필의 격리된 ad-hoc 서명 패키지 앱에서 한국어/영어의 실제 표시 updater 카드 AppKit 래스터를 확인했습니다. 실제 표시된 Check와 네이티브 Later 취소에서 원본 PID `65010`/인스턴스 `ceb6c3b1c3c314d996a2dc53a8416dce`를 보존하고 작업을 만들지 않았습니다. 네이티브 GUI에서 승인한 실제 LocalRebuild `2a2b18c9da3586c7ca07c30411655293`는 원본 exit 0·`manager_exited` fence 후 Completed, `installed:true`, `applied:true`였고 새 PID `66536`/인스턴스 `ef8d1fcd777289647da67852e9fcc600`은 원래 설정/상태/소켓, 언어 `en`을 유지하며 UI·제어·Herdr 등록 준비를 확인했습니다. 완료된 도우미 작업의 명시 복구도 Completed를 유지했습니다. 패키지 본체/도우미 protocol 2, 도우미 strict·앱 deep 서명과 worker 전용 JIT 권한을 확인했고 소유 앱을 정상 종료했습니다. 이는 **로컬 통합 소스/격리 실행** 근거이지 PR CI·공개 다운로드·사용자 Brew 업그레이드·Developer ID 서명/공증·물리 입력 인증이 아닙니다.
