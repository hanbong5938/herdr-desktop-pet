# Herdr Desktop Pet v0.1.9 release notes

v0.1.9 ships the five-fold-face ten-pose Rubelia default and adds a source-checkout character-production skill forked from DAEMONLET. These historical notes are reconstructed from contemporaneous artwork records, tagged documentation, and the [published release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.1.9). They do not report new artwork generation, rights clearance, or test execution.

## Rubelia's approved face authority

The owner-approved 2026-10-02 illustration retains its outfit, body, and upper-thigh framing. A local Qwen-Image-2.1 face-only correction uses Rubelia's five-fold champion portrait as the facial identity reference; the selected seed is `2026100502`. The [tagged source record](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.9/assets/rubelia-default/source-record.json) records exactly unchanged authority RGBA outside the edit-mask support and exactly unchanged full alpha. It describes a masked local edit, not manual face painting or a donor-face transplant.

The corrected illustration supplies `waiting` and the drawing authority for nine newly generated complete poses. Each other pose has its own source-derived layered PSD, matte, expression shapes, native rig, and complete phase/reaction motion rather than borrowing another pose's body or face pixels. The menu thumbnail is a genuine native waiting-pose capture.

Rubelia remains the owner's shared-world-canon character, the only bundled character, and `default@0`; the `rubelia-at12-multi-pose` manifest identity is unchanged. Existing imported character selections are not replaced, and older published binaries remain unchanged.

## Source-checkout authoring skill

The local Qwen-Image-2.1 + See-through production skill is a fork of DAEMONLET's `skills/create-pet-character`, pinned to upstream commit `1f5b1560162e4370368b0ab55c32c3271e5921c0`. Its upstream MIT notice is retained unchanged with the upstream provenance. It adapts local generation, pose-local decomposition/expressions, staged native review, and herdr v5 ten-pose output; it is an authoring workflow, not an additional bundled character or runtime image generator.

External engines, authoring runtime libraries, and model weights are not bundled with the app. The MIT software license does not license model weights, generated artwork, or character rights. The dependency record distinguishes ComfyUI's GPL-3.0 code, See-through's declared MIT code, declared versus unverified See-through model terms, and Qwen's retained research-license record. In particular, the exact Qwen weight revision was not recorded, the authoring record does not grant commercial use or redistribution, and some external model terms remain unverified. Owner artwork approval does not remedy those model-license boundaries.

Use the [current production skill](../../.agents/skills/create-pet-character/SKILL.md) for authoring and its [external dependency record](../../.agents/skills/create-pet-character/external-dependencies.json) for detailed terms; the frozen versions are linked below.

## Known limitations in this release

- `writing`, `failed`, and `bored` have slightly more downcast eyes than `waiting`.
- Small opaque white fragments remain between some hair strands.

These are v0.1.9's original limitations. [v0.1.10](v0.1.10.md) later corrects reviewed white-background pockets and rims; it does not rewrite v0.1.9's published archives or erase this historical limitation.

## Upgrading and compatibility

This is an app release, not a new Herdr host release. The manifest pins `0.1.9`; the `0.9.3` host minimum remains a lifecycle patch baseline. The prebuilt retains lifecycle settings, editable dialogue, status indicators, and inline-card replies from [v0.1.6](v0.1.6.md), plus [v0.1.8's fixes](v0.1.8.md).

Apple Silicon macOS 13+ is required. Local observation supports Herdr 0.9.0+; remote observation requires a compatible saved-machine forwarding CLI (documented in Herdr 0.9.2) and compatible remote server. Local replies require `agent.prompt` support separately; remote cards remain read-only. Client-attach auto-start requires official Herdr 0.9.3 source with the supplied patch applied and built, or a future actual host release advertising that hook. Stock Herdr 0.9.0/0.9.3 lack `client.attached`; inspect link warnings and confirm subscription acceptance. A manifest floor alone is not proof. See the [integration authority](../../integrations/herdr/README.md).

App bundles are ad-hoc signed, not Developer ID signed or notarized. Use the [English guide](../../readme.md) or [Korean guide](../../readme.ko.md) for current installation, and the tagged guides below for this release's instructions.
