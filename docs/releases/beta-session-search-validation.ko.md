# 0.3.0-beta.1 세션 검색: 다른 Mac 실제 GUI 수동 점검표

이 문서는 **실제 베타 자산을 받은 뒤** 그 Mac의 로그인된 데스크톱에서 사람이 수행할 점검입니다. 소스 프로브나 기존 자동 테스트의 재실행 지침이 아닙니다. 세션 검색·상태 필터·정렬은 안정판 v0.2.0 이후의 새 minor 기능입니다. 이 문서 작성 시 계획한 [`beta/0.3.0-beta.1`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.0-beta.1) 링크는 **실제 게시·업로드를 증명하지 않으므로**, 사용할 때 Release 카탈로그의 실물 자산을 확인하세요. 안정판 v0.2.0/latest 및 beta/0.2.0-beta.1/.2/.3 태그·자산은 이 점검에서 교체하지 않습니다. 사용자가 실제 활성/key 창 GUI 수락 전에 병합·베타 준비를 허가했으므로, 이 문서는 통과 보고서가 아닙니다. [게시 준비 당시 기능·근거](unreleased.md#prepublication-working-copy-addition-session-search-and-ordering)와 [안정판 이전·프로필 보존](../migrations/v0.1.11-to-v0.2.0.md)을 참고하세요.

## 시작 전: 실행 주체와 데이터 보호

- 원격 Mac에서 로그인된 **실제 사용자 데스크톱**과 키보드/입력기/마우스가 준비된 뒤, 그 사용자 자신이 앱 창을 띄워 확인합니다. 화면이 꺼져 있거나 로그인 창·잘못된 사용자 데스크톱·GUI 포커스가 불확실한 원격 셸에서는 앱 GUI를 실행하지 마세요. 이 Mac의 화면을 대신 조작할 수 없는 담당자는 점검을 `UNEXERCISED`로 남깁니다.
- 설치 전 실제 사용 중인 설정·상태 **두 디렉터리 모두** 백업합니다. `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`가 설정 백업에 들어가는지 확인합니다. 안정판과 베타는 기본적으로 프로필과 제어 소켓 네임스페이스를 공유하므로 기존 앱·데몬과 자동 재시작 가능한 호스트를 먼저 정지하고, 기존 앱을 **종료한 다음** 베타 앱을 교체/시작합니다. 동시에 비교할 때는 각 앱의 `--config-dir`과 `--state-dir` **양쪽 모두** 서로 다른 디렉터리로 분리하고 start/stop/status 전 과정에 동일한 두 경로를 사용합니다. 베타에서 안정판의 라이브 프로필을 덮어쓰지 마세요.
- 받은 파일의 실제 Release URL·태그·자산 이름·바이트 수·체크섬과 다운로드 일시를 기록하고 게시 자산 자체를 검증합니다. 게시 전에는 링크를 실물 다운로드로 취급하지 않습니다. 앱을 시작하기 전에 베타 CLI의 `--version`이 `0.3.0-beta.1`인지 확인하고, 로그인된 사용자 데스크톱에서 시작한 **뒤** 같은 config/state 경로의 CLI `status`에서 `app_version`이 `0.3.0-beta.1`인지, 실행 파일 경로가 설치한 **해당 베타 바이너리**인지 대조합니다. `--version`만 맞고 `status`가 기존 데몬/다른 실행 파일을 가리키면 중단하고 기존 데몬·소켓·PATH·주입 환경을 조사합니다. 다른 베타/안정판 CLI를 섞거나 `--socket`을 제어 소켓 경로라고 오인하지 마세요.
- 테스트에 쓸 **일회용 로컬 세션**과 관찰용 원격 세션을 분리합니다. 원격 카드는 읽기 전용이며 답장은 적격한 로컬 세션에서만 시험합니다. 명시적으로 승인한 안전한 테스트 대상 외에는 Enter/Command-Enter 등을 실제 프롬프트 전달 검사로 사용하지 않습니다. 아래 **워크트리 삭제**는 소중한 체크아웃에서 절대로 실행하지 않습니다. 꼭 기능을 확인한다면 별도 일회용 checkout만 사용하고 `force: false`에서도 ignored 파일이 삭제될 수 있음을 확인하세요.

## 기록 방법

각 항목 옆에 `PASS` / `FAIL` / `UNEXERCISED` 중 하나를 기입합니다. `PASS`는 **이번에 받은 정확한 베타 바이너리와 실제 창/키보드/IME에서 관찰한 결과**에만 사용합니다. `FAIL`은 기대와 다른 실제 관찰, `UNEXERCISED`는 조건/포커스/세션/타이머 경로를 만들지 못했거나 결과만으로 구별할 수 없는 경우입니다. 겹침을 시도했더라도 포커스 이동으로 조합이 확정됐으면 **겹침 항목은 UNEXERCISED**입니다. 보고서에는 macOS/CPU, 앱 자산·SHA-256·설치 경로, CLI `--version`, `status`의 `app_version`·실행 파일, 설정/상태 경로(민감한 이름은 가림), 사용한 IME·언어·스크롤바 설정, Herdr 버전/세션 출처, 각 단계의 시각·화면 캡처 또는 짧은 영상(개인 정보 제거), 기대값/실제값과 재현 순서를 남깁니다. 패키지·서명·다운로드 확인과 GUI 결과를 서로 대신하지 마세요.

## 결과 전달

`PASS __ / FAIL __ / UNEXERCISED __`와 실패/미실행 항목 번호, 바이너리/프로필/IME·세션 증거 및 재현 절차를 함께 전달하세요. 이전 작업본의 Rust/Bun 수치, 오프스크린 AppKit 호출, beta2/beta3 설치 성공은 이 베타의 **실제 GUI 수락 결과가 아닙니다**. 관찰하지 못한 스크린샷·전송·예약 콜백을 추정해 채우지 마세요.
