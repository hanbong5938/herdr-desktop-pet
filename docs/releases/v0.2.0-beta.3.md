# Herdr Desktop Pet v0.2.0-beta.3 release notes

**Opt-in manual macOS UI test, not a stable release.** This isolated snapshot uses app version `0.2.0-beta.3` and tag `beta/0.2.0-beta.3`; the original working-copy manifests remain `0.1.11`. The Apple Silicon/macOS 13+ archive is `HerdrDesktopPet-v0.2.0-beta.3-macos-arm64.tar.gz`, accompanied by its `.sha256` and `SHA256SUMS`. Download all three from the [beta3 prerelease page](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.3) and verify SHA-256 before unpacking the separately named `HerdrDesktopPetBeta.app`. The beta app is ad-hoc signed, **not notarized**; Gatekeeper may require explicit approval. The separate Homebrew formula installs under its prefix, not `/Applications`, and provides `herdr-desktop-pet-beta` without replacing the stable CLI. After the beta3 formula is published, install with `brew install hanbong5938/tap/herdr-desktop-pet-beta` or upgrade an existing beta with `brew update && brew upgrade herdr-desktop-pet-beta`. Check `herdr-desktop-pet-beta --version` before starting it: the beta formula is rolling, while this tag and archive are immutable. A tag or note alone does not prove public assets or formula publication.

Public `main` remains `9cbad32d1ad2385b8c99fd0692b8306ccc39b037`; stable v0.1.11, its assets/latest, the stable Homebrew formula, default/`--prebuilt` installation, and original 0.1.11 manifests remain unchanged. Stable `0.2.0` has not shipped. The immutable [beta1 prerelease](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.1) and [beta2 prerelease](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.2) retain their own binaries and evidence. Beta1 retains the reported reply-glyph/Markdown bugs; beta2 fixes those but does **not** contain the new reply keyboard shortcuts. The beta2 archive's 20,467,673 bytes and SHA-256 `ddb61fa2ff45aa0fcc603c175423667512b7fa043461b6ab5e9f2c37576a6432` are **beta2 only**, never beta3 checksums.

## Changes

Beta3 carries forward the beta2 capabilities—independent character/bubble visibility, compact local/remote observation settings, context/recovery menu, selectable menu-bar visibility and managed PNG icon, linked-worktree removal, standalone/remote-only watcher start, and the beta2 reply-glyph-clipping and Markdown Release/Wiki inline-mask corrections. See the [canonical beta2 change record](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.2.0-beta.2/docs/releases/v0.2.0-beta.2.md) for their contracts and limits; these are **not** new beta3 features or stable v0.1.11 behavior. Stock Herdr 0.9.0/0.9.3 do not supply `client.attached`; client-attach auto-start still requires the separately patched host.

**Beta3 delta relative to immutable beta2:** the reply composer previously supported native `paste:` but its menu-less panel did not dispatch Command shortcuts. Focused `ComposerView` now routes unmodified Command-A/C/X/V through `performKeyEquivalent:` and a `keyDown:` fallback to native select-all/copy/cut/paste, following the existing dialogue-editor pattern. Native paste retains single-line normalization (including CRLF), UTF-16 selection and replacement, and Cocoa/IME ownership of marked text. Additional Shift, Option or Control modifiers are not intercepted. This is reply-editor keyboard dispatch, not a system-wide shortcut, host capability, or new clipboard format.

## Evidence and outstanding manual checks

**Fresh isolated beta3 source proof:** TypeScript check, **44 Bun tests / 355 expectations**, scoped Rust formatting, native arm64 release check/build and **343 tests** (342 main plus one bounded FIFO child) passed. The actual main-thread AppKit geometry executable passed both native scroller styles and Unicode/selection/marked-text boundaries. A separate disposable **0.2.0-beta.3** process exercised the real production `ComposerView` and `BubblePanel` using native key equivalents, window `sendEvent:` and `keyDown:` with a private named pasteboard. Korean/emoji/CRLF paste, UTF-16 replacement, select-all/copy/cut, Caps Lock, focus, extra-modifier and marked-text guards passed; the user's clipboard was never read or written. Probe entrypoints were removed and exact production sources restored before the final production gates/build. This is programmatic AppKit input proof, not physical keyboard/IME certification or a permanent clipboard regression test.

**Pre-tag packaged proof:** the 20,467,942-byte archive has SHA-256 `14bf452aa492fa520a4979ca3e18711e505c52c178c1e1e2edb355b2b07b0920`. An independent extraction passed arm64/version `0.2.0-beta.3` and deep strict signature checks. The real extracted app started against an owned Herdr backend with UI/control ready, registration accepted and data connected; hide/show retained the enabled bubble. Exporting builtin `default@0` through an executable symlink and separate offline profile succeeded (28,048,065 bytes); the packaged default remains Rubelia v5 rig. The owned app was stopped. **Publication boundary:** anonymous asset downloads, public release metadata and actual beta2→beta3 Brew upgrade/fresh install are post-publication checks, not evidence available in this frozen pre-tag note. Publish only as an opt-in, non-draft, non-latest prerelease with all three assets. This beta tag does not trigger the stable `v*` Release/Wiki workflow; this canonical note exists only in isolated beta source, not the original stable Wiki-scanned note tree. **Physical keyboard focus, real IME, picker interactions, alert Return/keypad Enter/Escape/Delete, pointer gestures and VoiceOver remain unverified** and require an interactive desktop check.

Quit stable before beta start. Back up actual configuration and state, including `preferences.json`, `lifecycle.json`, `characters/` and managed `menu-bar-icons/`. Unless **both configuration and state** are explicitly isolated, stable and beta share profile and control namespace: never run them concurrently. To roll back, quit beta, restore the backup, then restart stable; downgrade compatibility of beta-written data is not guaranteed. Test **Remove Worktree…** only on a disposable linked worktree: ignored files can be deleted and running processes, panels or workspace state affected; confirmation is not an undo. Follow the [English manual test/backup guide](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.2.0-beta.3/docs/migrations/unreleased.md) or [Korean guide](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.2.0-beta.3/docs/migrations/unreleased.ko.md).

공개 `main`은 `9cbad32d1ad2385b8c99fd0692b8306ccc39b037` 그대로이며 안정판 v0.1.11·자산/latest·안정판 포뮬러·기본/`--prebuilt` 설치·원본 0.1.11 매니페스트도 변하지 않습니다. 안정판 `0.2.0`은 아직 출시하지 않았습니다. 고정된 [beta1](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.1)과 [beta2](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.2)의 자산·검증은 각각의 기록입니다. beta1에는 보고된 답장 글자 잘림/Markdown 문제가 남고 beta2는 이를 고쳤지만 새 답장 단축키는 없습니다. beta2 압축파일의 20,467,673바이트·SHA-256 `ddb61fa2ff45aa0fcc603c175423667512b7fa043461b6ab5e9f2c37576a6432`는 **beta2 전용**이며 beta3 체크섬이 아닙니다.

### 변경 사항

beta3는 캐릭터·말풍선 독립 표시, 간결한 로컬/원격 관찰 설정, 문맥/복구 메뉴, 메뉴 막대 표시 모드·관리 PNG 아이콘, 연결 워크트리 삭제, 독립·원격 전용 watcher 시작, beta2의 답장 글자 잘림·Markdown Release/Wiki 인라인 마스킹 수정을 유지합니다. 계약과 한계는 [beta2 공식 변경 기록](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.2.0-beta.2/docs/releases/v0.2.0-beta.2.md)을 참고하세요. beta3 신규 기능이나 안정판 v0.1.11 기능으로 재분류하지 마세요. 순정 Herdr 0.9.0/0.9.3에는 `client.attached`가 없으므로 client-attach 자동 시작에는 별도 패치 호스트가 필요합니다.

**고정된 beta2 대비 beta3 변경:** 기존 답장창은 네이티브 `paste:`는 지원했지만 Edit 메뉴 없는 패널에서 Command 단축키가 연결되지 않았습니다. 포커스된 `ComposerView`는 기존 대사 편집창 패턴을 따라 `performKeyEquivalent:`와 `keyDown:` 대체 경로에서 Command-A/C/X/V를 네이티브 전체 선택·복사·잘라내기·붙여넣기로 보냅니다. CRLF를 포함한 기존 한 줄 붙여넣기 정규화, UTF-16 선택·대체, 표시 중인 조합 문자에 대한 Cocoa/IME 소유권을 유지합니다. 추가 Shift/Option/Control 조합은 가로채지 않습니다. 시스템 전체 단축키·호스트 기능·새 클립보드 형식은 아닙니다.

### 확인 근거와 남은 수동 점검

**격리 beta3 소스의 새 검증:** TypeScript, Bun **44개/기대값 355개**, 변경 범위 Rust 형식 검사, 네이티브 arm64 release 검사·빌드·테스트 **343개**(주 테스트 342개 + 제한시간 FIFO child 1개)가 통과했습니다. 실제 메인 스레드 AppKit 배치 executable도 두 스크롤러 스타일과 Unicode·선택·조합 경계를 통과했습니다. 별도의 일회성 **0.2.0-beta.3** 프로세스에서 실제 production `ComposerView`·`BubblePanel`, 네이티브 key equivalent·창 `sendEvent:`·`keyDown:`과 사설 named pasteboard로 한글·이모지·CRLF 붙여넣기, UTF-16 선택 대체, 전체 선택·복사·잘라내기, Caps Lock·포커스·추가 modifier·조합 보호를 확인했습니다. 사용자 클립보드는 읽거나 쓰지 않았습니다. probe 진입점을 제거하고 원본 production 소스를 정확히 복원한 뒤 최종 게이트·빌드를 실행했습니다. 프로그램으로 전달한 AppKit 입력의 증거이며 물리적 키보드·IME 인증이나 영구 클립보드 회귀 테스트는 아닙니다.

**태그 고정 전 패키지 검증:** 압축파일 크기는 20,467,942바이트, SHA-256은 `14bf452aa492fa520a4979ca3e18711e505c52c178c1e1e2edb355b2b07b0920`입니다. 별도 압축 해제본의 arm64·`0.2.0-beta.3` 버전·엄격한 심층 서명이 통과했습니다. 실제 앱을 전용 Herdr backend에 연결해 UI/control ready·등록 수락·데이터 연결과 hide/show 시 활성 말풍선 유지를 확인한 뒤 종료했습니다. executable 심볼릭 링크와 별도 오프라인 프로필로 내장 `default@0` 내보내기(28,048,065바이트)가 통과했으며 기본 캐릭터는 Rubelia v5 rig 그대로입니다. **게시 경계:** 익명 자산 다운로드·공개 release metadata·실제 beta2→beta3 Brew 업그레이드/신규 설치는 게시 후 확인할 항목이며 고정 전 문서에 이미 있었던 증거가 아닙니다. 세 자산을 동반한 선택형 non-draft·non-latest prerelease로만 게시합니다. 베타 태그는 안정판 `v*` Release/Wiki 워크플로를 실행하지 않고 공식 beta3 기록은 격리 소스에만 있으며 원본 안정판 Wiki 검사 트리에는 없습니다. **물리적 키보드 포커스·실제 IME·이미지 선택 창·확인 창 Return/숫자 키패드 Enter/Escape/Delete·포인터 제스처·VoiceOver는 미검증**이므로 실제 대화형 데스크톱에서 확인해야 합니다.
