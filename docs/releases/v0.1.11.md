# Herdr Desktop Pet v0.1.11 release notes

v0.1.11 adds a localized native menu for closing only the bubble window. These historical notes are reconstructed from the contemporaneous tagged documentation and the [published release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.1.11), not from newly executed native interaction tests.

## Native bubble-only Close menu

Right-click or Control-click the bubble background or a session card header to open the native **Close Bubble Window / 대화창 닫기** menu.

- Choosing Close hides **only the bubble**. The character, app, and Herdr session continue running.
- Canceling the menu or hiding the bubble preserves card selection and reply drafts.
- Text fields keep their native editing/copy-paste menus. Buttons, dropdowns, and scrollbars retain their own native interactions rather than being replaced by the bubble menu.
- Closing is disabled during active IME marked-text composition. The action rechecks composition when it runs, so eligibility at menu creation is not the only safeguard. Finish composition and reopen the menu to close.
- Reopen the bubble using **Bubble → Bubble visible / 말풍선 → 말풍선 표시 여부** in this release's menu-bar panel.
- Closing persists the existing bubble-visibility preference. Reply drafts remain only in memory for the current app run and do **not** survive restart.

This menu is the v0.1.11 bubble-only Close feature. Contextual Settings menus, conditional recovery icons, and independent standalone-bubble behavior belong to [Unreleased](unreleased.md), not to this published version.

## Retained default and limits

The release keeps the corrected ten-pose Rubelia default from [v0.1.10](v0.1.10.md): reviewed white-background hair pockets and contaminated rims, including the bent-arm gap, were removed without changing face, clothing, skin interior, expressions, or motion. Source-bound mattes and repair provenance travel with the pack.

Rubelia remains the only bundled character, with `default@0` and the `rubelia-at12-multi-pose` identity retained; existing imported character selections and older published binaries remain unchanged. The five-fold-face source/owner/model records and MIT-preserving DAEMONLET authoring skill remain. External engines and model weights are not bundled, and owner artwork approval does not grant model rights; see [v0.1.9's provenance and license boundaries](v0.1.9.md).

Some downcast poses still differ slightly from the waiting face. This release does not claim a new facial redesign or erase [v0.1.9's historical white-fragment limitation](v0.1.9.md#known-limitations-in-this-release).

## Upgrading and feature-specific compatibility

This is an app release, not a new Herdr host release. Apple Silicon macOS 13+ is required. The prebuilt includes the bubble menu alongside the existing lifecycle settings, editable dialogue, status indicators, and inline-card replies.

Local observation supports Herdr 0.9.0+. Remote observation additionally needs a compatible saved-machine forwarding CLI (documented in Herdr 0.9.2) and a compatible remote server. Reply submission requires the local `agent.prompt` method separately; remote cards remain read-only. A successful prompt submission is Herdr's acknowledgment, not proof that the agent finished; uncertain delivery must be checked before manually resending, with no automatic retry or shell/SSH fallback.

Client-attach auto-start still requires official Herdr 0.9.3 source with the supplied `client-attached.patch` applied and built, or a future actual host release advertising that hook. Stock Herdr 0.9.0/0.9.3 do not provide `client.attached`; the manifest's minimum version alone cannot establish compatibility. Inspect plugin-link warnings and confirm subscription acceptance. Linking/enabling on an already-running server alone does not launch the pet: start it once or wait for a later qualifying client attach with auto-start enabled. The [integration guide](../../integrations/herdr/README.md) remains the host-patch authority.

App bundles are ad-hoc signed, not Developer ID signed or notarized. The prebuilt requires no source-build toolchain. Use the [English guide](../../readme.md) or [Korean guide](../../readme.ko.md) for current installation instructions; the tagged guides below preserve v0.1.11's menu-bar controls.

## 한국어 요약

말풍선 배경·세션 카드 헤더를 우클릭 또는 Control-click하면 네이티브 **대화창 닫기** 메뉴가 열립니다. 닫기는 말풍선만 숨기고 캐릭터·앱·Herdr 세션은 계속 실행합니다. 메뉴 취소와 닫기 후에도 카드 선택·답장 초안은 유지하며, 텍스트 편집 메뉴·버튼·드롭다운·스크롤바의 네이티브 동작은 그대로입니다.

입력기(IME) 조합 중에는 닫기를 비활성화하고, 액션 실행 시에도 조합 상태를 다시 확인합니다. 조합을 마친 뒤 메뉴를 다시 여세요. 이 버전에서는 메뉴 막대 패널의 **말풍선 → 말풍선 표시 여부**로 다시 엽니다. 표시 설정은 저장하지만 초안은 현재 앱 실행 중에만 메모리에 남아 재시작 후 복원되지 않습니다. 문맥 설정·조건부 복구 아이콘·독립 단독 말풍선 기능은 이 릴리스에 포함시키지 않습니다.

Apple Silicon macOS 13+가 필요합니다. 로컬 관찰은 Herdr 0.9.0+, 원격 관찰은 호환 저장 머신 전달 CLI/서버, 답장은 로컬 `agent.prompt` 지원이 각각 필요하며 원격 카드는 읽기 전용입니다. 전달 여부가 불확실하면 확인 없이 다시 보내지 마세요. 클라이언트 attach 자동 시작에는 공식 Herdr 0.9.3에 제공된 패치를 적용해 빌드한 호스트가 필요합니다. 순정 0.9.3이나 매니페스트 최소 버전만으로 훅 지원을 보장하지 않으며 연결 경고와 구독 수락 여부를 확인해야 합니다. 실행 중인 호스트에 연결·활성화한 것만으로 실행되지는 않으므로, 수동 시작하거나 자동 시작을 켠 상태에서 이후 정상적인 클라이언트 attach를 기다리세요. `default@0`·가져온 캐릭터 선택·이전 배포 파일은 유지합니다.
