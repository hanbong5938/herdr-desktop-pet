# Herdr Desktop Pet 0.1 release line

[Versions](README.md) · [한국어](README.ko.md) · [Versioning and compatibility](policy.md)

The last published binary **in the 0.1 line** is **v0.1.11**; it is not the current stable-version contract. Published complete binary releases in this line are **v0.1.4** and **v0.1.6–v0.1.11**. **v0.1.5 is tagged only**: packaging failed before assets were published. The four native groups first recorded at local `worktree/rapid-harbor-d2a6` commit `bf23ced1649fd0074aec8736644c8f02aa0c492b` were absent from the historical v0.1.11 binary. They and the later native changes are promoted in the [v0.2.0 stable contract](v0.2.0.md); [Unreleased](unreleased.md) retains historical provenance and verification without turning v0.1.11 into a feature release.

This is a historical navigation page, not a live release-status table or a support promise. The generated Wiki derives **Release-Status** and **Older-Releases** from the current GitHub release catalog and uploaded assets.

## 한국어 요약

0.1 계열의 마지막 공개 바이너리는 v0.1.11입니다. 이는 현재 안정판을 0.1.11로 고정한다는 뜻이 아닙니다. v0.1.4와 v0.1.6–v0.1.11에는 공개 바이너리가 있고, **v0.1.5는 패키징 실패로 태그만 있으며 다운로드가 없습니다.** v0.1.9의 흰 조각 제한은 당시 기록에 남기고, v0.1.10의 수정이 과거 파일을 바꾼 것으로 설명하지 않습니다.

과거 `worktree/rapid-harbor-d2a6`의 `bf23ced1649fd0074aec8736644c8f02aa0c492b`에 기록된 네 가지 네이티브 변경은 v0.1.11 바이너리에는 없었습니다. 이후 변경까지 포함한 현재 안정판 계약은 [v0.2.0 기록](v0.2.0.md)과 [한국어 포함 업그레이드 안내](../migrations/v0.1.11-to-v0.2.0.md)를 따르세요. v0.1.4 입력창과 v0.1.6에 이미 포함된 카드별 답장은 Enter/Escape 동작이 다릅니다. 원격 카드는 읽기 전용이며, 대화창 닫기·숨기기는 앱이나 Herdr 세션 종료가 아닙니다. 과거 버전 링크를 보관해도 지원 기간이나 백포트는 약속하지 않습니다.
