# Herdr Desktop Pet v0.3.5 release notes

[Versions](README.md) · [0.3 upgrade guidance](0.3.md) · [Development](../development.md)

## English

v0.3.5 is this checkout's stable source/default-prebuilt target after v0.3.4. This note, a version manifest or a tag alone does not establish publication. Before installing a prebuilt, confirm a non-draft [GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases) with `HerdrDesktopPet-v0.3.5-macos-arm64.tar.gz`, its individual `.sha256`, `SHA256SUMS` and the separate `HerdrDesktopPet-v0.3.5-rig-native.json` deployed-byte provenance sidecar. The installer archive contains only `HerdrDesktopPet.app`; the sidecar is neither inside that archive nor an installer input.

- Interrupted native left-button capture recovers after the button is released without generating a false tap. A new press uses its own drag anchor; duplicate/stale events cannot take it over or complete another window's gesture, and a Control-left release cannot finalize an earlier tap. Ordinary taps, Option-drag and resize grips retain their behavior. A valid bubble resize with a lost release callback can accept its preview once, subject to tracking and IME guards.
- The attached bubble keeps its entire body outside the character's stable bounds. Auto placement holds its current side while the reply/control minimum fits, including during card expansion, reply opening and content reflow; resizing uses that side's safe region without overwriting the saved size request. If no side fits, a bounded tailless least-overlap fallback appears in front of the character window without moving the character.
- Opening a reply lays out the attached bubble before focusing, then keeps the selected card, input and caret visible. Reflow preserves the native editor, draft and selection. During IME composition it defers layout/content changes that would reparent or resize the editor; only a safe window-position recovery may occur if screen or character geometry makes the current position unsafe.

Character-pack format v5, bundled Rubelia `default@0`, the optional (not automatically installed) Chaerin pack, the native rig ABI identity/struct-size checks, and the sealed initial-motion bytes remain unchanged. The standalone protocol-2 update coordinator, worker-only JIT and signing/install protections remain intact. v0.3.4's eye ownership and post-signing provenance contract are retained; no previous tag, asset, artwork or authored motion is replaced.

For an upgrade, stop the old daemon, back up actual config and state (including characters and updater records), verify the public archive/checksums and separate provenance sidecar and confirm the stable installer/formula cutover. Restart and check CLI `--version`, `status` with `app_version: 0.3.5`, and the running executable. A built source tree or local package is not proof of a published release or a consumer upgrade. The corresponding `beta/0.3.5-beta.1` is a separate, non-latest prerelease target with the same functionality and its own assets; verify its publication separately.

### Local stable candidate verification (not publication)

- The locked release native suite passed 621 tests plus one isolated FIFO child (one ignored); the main-thread AppKit composer geometry/insertion check and standalone coordinator's 29 tests passed. The local v0.3.5 release build/package passed: all 68 `deployed_sha256` identities matched signed app `Contents`, with arm64 binaries, deep strict signatures, helper/app protocol 2, worker-only JIT and symlinked-CLI bundled-pack export checked.
- An isolated daemon reported `app_version: 0.3.5`, the expected bundle path and UI/control readiness. Five placement frames were stable over 600 ms; unknown dialogue short/long/short (7/510/7) applied natively with stable subsequent frames, and standalone/re-attach visibility transitions passed. The backend was intentionally absent, with `exit_with_herdr` disabled for this smoke check. Screen capture could not produce desktop screenshots; rendered native AppKit composer PNGs were inspected, **not** a physical drag/IME certification. These local checks do not prove uploaded Release assets or a consumer upgrade.

## 한국어

v0.3.5는 v0.3.4 이후 이 체크아웃의 안정판 소스·기본/사전 빌드 대상입니다. 이 노트·버전 매니페스트·태그만으로 게시를 증명할 수 없습니다. 사전 빌드 설치 전 비초안 [GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases)에 `HerdrDesktopPet-v0.3.5-macos-arm64.tar.gz`·개별 `.sha256`·`SHA256SUMS`와 별도 배포 바이트 출처 사이드카 `HerdrDesktopPet-v0.3.5-rig-native.json`이 있는지 확인하세요. 설치기 압축 파일에는 `HerdrDesktopPet.app`만 담고 사이드카는 별도 릴리스 자산이지 압축 파일 구성원이나 설치기 입력이 아닙니다.

- 네이티브 좌버튼을 놓았지만 놓기 콜백이 유실된 포인터 캡처를 가짜 탭 없이 복구합니다. 새 누르기는 고유한 드래그 시작점을 사용하며 중복·오래된 이벤트가 이를 빼앗거나 다른 창의 제스처를 끝내지 못합니다. Control-left 놓기로 이전 탭을 확정하지 않습니다. 일반 탭·Option-드래그·크기 조절점 동작은 유지하고 유효한 말풍선 조절의 놓기 콜백이 유실되면 추적·IME 조건에 따라 미리보기를 한 번 확정할 수 있습니다.
- 부착 말풍선 본문 전체를 캐릭터의 안정적인 경계 밖에 둡니다. 자동 배치는 카드 펼치기·답장 열기·내용 갱신 중에도 답장/컨트롤 최소 공간이 있는 현재 방향을 유지하고, 크기 조절은 저장 요청을 덮어쓰지 않고 해당 방향의 안전 영역을 사용합니다. 어느 방향도 맞지 않으면 캐릭터를 옮기지 않고 캐릭터 창 앞에 화면 내 겹침이 가장 적은 꼬리 없는 말풍선을 둡니다.
- 답장을 열기 전 부착 말풍선 배치를 계산하고 포커스를 주며 선택 카드·입력칸·커서를 보이는 위치에 둡니다. 재배치 중에도 네이티브 편집기·초안·선택 범위를 유지합니다. IME 조합 중 편집기를 재부착하거나 크기를 바꿀 내용/배치 변경은 미루고, 화면·캐릭터 경계 변화로 현재 위치가 위험할 때에만 안전한 창 위치 복구를 허용합니다.

캐릭터 팩 형식 v5·내장 루벨리아 `default@0`·자동 설치되지 않는 선택형 채린 팩과 네이티브 rig ABI 식별/구조체 크기 검사·봉인된 초기 motion 바이트는 변경되지 않습니다. 독립 protocol-2 업데이트 코디네이터, worker 전용 JIT, 서명/설치 보호도 유지합니다. v0.3.4의 눈 소유권과 서명 후 출처 기록 계약을 이어가며 옛 태그·자산·그림·원본 모션을 교체하지 않습니다.

업그레이드 전 구형 데몬을 종료하고 캐릭터·업데이터 기록을 포함한 실제 설정·상태를 백업하세요. 공개 압축 파일/체크섬·별도 출처 사이드카와 안정판 설치기/포뮬러 전환을 확인하고, 재시작 후 CLI `--version`, `status`의 `app_version: 0.3.5` 및 실행 경로를 함께 확인하세요. 소스 빌드나 로컬 패키지만으로 공개 배포·소비자 업그레이드가 증명되지 않습니다. 같은 기능을 담은 대응 `beta/0.3.5-beta.1`은 별도 non-latest 사전 릴리스 대상이므로 베타 자산의 실제 게시도 별도로 확인하세요.

### 로컬 안정판 후보 검증 (게시 증거 아님)

- 잠금된 release 네이티브 검사 621개와 격리된 FIFO 자식 검사 1개가 통과했고 1개는 무시했습니다. 메인 스레드 AppKit 편집기 배치/입력 검사와 독립 코디네이터 29개 검사도 통과했습니다. 로컬 v0.3.5 release 빌드/패키징에서 서명된 앱 `Contents`의 `deployed_sha256` 68개가 모두 일치했고 arm64 바이너리·깊은 엄격 서명·helper/app protocol 2·worker 전용 JIT·심볼릭 링크 CLI의 기본 팩 내보내기를 확인했습니다.
- 격리된 데몬은 `app_version: 0.3.5`, 예상 앱 번들 경로와 UI/컨트롤 준비 상태를 보고했습니다. 말풍선 배치 다섯 프레임이 600 ms 동안 안정적이었고 알 수 없는 상태 대사 짧음/김/짧음(7/510/7)이 네이티브로 적용된 뒤 프레임이 안정적이었으며 단독/재부착 표시 전환도 통과했습니다. 이 점검에서는 백엔드를 의도적으로 두지 않고 `exit_with_herdr`를 껐습니다. 데스크톱 화면 캡처는 생성되지 않았고 실제 AppKit 편집기가 렌더링한 PNG를 검토했지만 **물리적 드래그/IME 인증은 아닙니다**. 이 로컬 점검은 공개 릴리스 자산이나 소비자 업그레이드의 증거가 아닙니다.
