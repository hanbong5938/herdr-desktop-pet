The v0.2.0 stable source promotes the native beta3 feature set to the normal `HerdrDesktopPet.app`, `herdr-desktop-pet` CLI, stable installation and Homebrew formula. The original beta1/beta2/beta3 tags and releases remain separate and immutable; their verification and hashes are **beta-only evidence**, not evidence for the stable build or package. The [0.1 line](0.1.md) documents its historical binaries, including v0.1.11 and tagged-only v0.1.5. The GitHub Wiki's generated **Release-Status** and **Older-Releases** pages use the actual Release catalog and uploaded assets; this source overview is not a live publication-status report or a support-lifetime promise.
