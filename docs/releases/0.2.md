The v0.2.0 stable source promotes the native beta3 feature set to the normal `HerdrDesktopPet.app`, `herdr-desktop-pet` CLI, stable installation and Homebrew formula. The original beta1/beta2/beta3 tags and releases remain separate and immutable; their verification and hashes are **beta-only evidence**, not evidence for the stable build or package. The [0.1 line](0.1.md) documents its historical binaries, including v0.1.11 and tagged-only v0.1.5. The GitHub Wiki's generated **Release-Status** and **Older-Releases** pages use the actual Release catalog and uploaded assets; this source overview is not a live publication-status report or a support-lifetime promise.

v0.2.1 fixes reference-only `meshSource` links excluded from the final rig: the v0.2.0 app failed to validate the actual Arin archive with `RIG_INVALID`. Arin archive import requires app v0.2.1 or newer. This is a patch of public v0.2.0, not the unrelated unreleased `main` features. Artwork, rig overrides, motion, `default@0`, v5 pack format and licensing are unchanged; see the [patch note](v0.2.1.md) for verification and safe upgrade boundaries.

## 한국어

v0.2.0 안정판의 [한영 릴리스 노트](v0.2.0.md)와 [v0.1.11 → v0.2.0 한영 업그레이드 안내](../migrations/v0.1.11-to-v0.2.0.md)를 참고하세요. 이 버전의 소스는 beta3의 네이티브 기능을 일반 앱·CLI·안정판 설치와 포뮬러로 옮기며 과거 beta1/2/3 태그·배포 파일은 유지합니다. 베타 검증 결과를 안정판 빌드·패키지 증거로 바꾸어 쓰지 마세요. 문서나 태그만으로 실제 게시를 판단하지 말고 [GitHub Releases](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 공개 릴리스와 압축 파일·체크섬 자산을 확인하세요. 이전 [0.1 계열](0.1.md)은 과거 기록이며, 생성된 Wiki 상태 페이지는 실제 공개 목록을 기준으로 합니다.

v0.2.1은 공개 v0.2.0 기반의 참조 전용 `meshSource` 호환성 패치입니다. 실제 Arin 압축 팩은 v0.2.0에서 `RIG_INVALID`였으며 수동 가져오기는 앱 v0.2.1 이상이 필요합니다. 미공개 `main` 기능·그림·rig override·motion·`default@0`·팩 형식 v5·라이선스는 변경하지 않습니다. [한영 패치 노트](v0.2.1.md)의 검증·업그레이드 경계를 확인하고, 게시 여부는 [v0.2.1 GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.2.1)의 실제 자산과 체크섬으로 판단하세요.
