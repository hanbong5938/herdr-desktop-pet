# Herdr Desktop Pet v0.3.3 release notes

[Versions](README.md) · [0.3 release line and bilingual upgrade](0.3.md) · [CLI contract](../cli.md)

## English

v0.3.3 is the stable source and default/prebuilt target, incorporating focused fixes after v0.3.2. This note and the four source manifests do not establish that the v0.3.3 binary, checksums, installer or Homebrew formula have been published. Confirm the non-draft, non-prerelease [GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases) with its arm64 archive, individual `.sha256` and `SHA256SUMS` before using a prebuilt installation.

### Fixes since v0.3.2

- The installed character browser presents **one official installed card** across all filters instead of duplicating an official pack in installed/official views. Explicit verified Download & Apply remains the route to install published official packs.
- Remote official character portraits with a **1024 × 1024 canvas** are accepted within the existing **4 MiB** download and decoding budgets; pack validation limits remain in force.
- Character-management **Update, Remove and Restore** controls refresh their enabled state through the installed card accessor when a busy operation ends, without replacing the card or changing its generation. **Inspect** remains available; a previously disabled Update can become enabled again after busy → idle.
- The summary for a **completed successful character-pack operation** is hidden after completion rather than lingering. This does not hide successful session status or change session observation.

v0.3.2 introduced the [integrated 0.3 capabilities](v0.3.2.md): search/order, CLI automation, conflict-aware dialogue drafts, eight-way bubble resizing, official browser, installation-aware protocol-2 updates and worker-only JIT decoding. The v0.2.1 Arin compatibility fix remains. Character-pack format **v5**, bundled Rubelia **`default@0`**, artwork and licensing are unchanged. Existing releases/tags/assets are not rewritten. A separate aligned `beta/0.3.3-beta.1` with its own `HerdrDesktopPetBeta.app` identity is planned; the beta is not the stable installer, and this plan does not assert beta assets are published.

### Evidence and upgrade boundary

The v0.3.3 candidate passed TypeScript, 56 Bun tests / 477 expectations, 590 main native tests plus one isolated FIFO child (one ignored), the existing main-thread AppKit composer and 29 coordinator tests. Locked release builds, packaging, installer shell syntax and stable note/version validation passed. Packaging verified arm64 app/helper, updater protocol 2, strict signatures and JIT entitlement only on the decode worker.

The actual packaged daemon reported `app_version: 0.3.3`, its bundle executable and UI/control readiness in an isolated profile. Presentation/preferences reads and built-in Rubelia dialogue targets passed, followed by normal stop. Its missing backend was intentional and data remained disconnected; these are programmatic runtime checks, not physical GUI/IME or a user Homebrew upgrade. Earlier actual official download/apply, portrait/filter and same-generation management-menu observations in [Unreleased](unreleased.md) predate the version bump and remain separately scoped evidence.

Follow the [0.3 upgrade guidance](0.3.md#upgrade-from-v021-or-beta): stop the running daemon before replacing it; back up actual configuration and state (including characters and updater records); do not silently replay or discard protocol-1 reservations. Once verified public assets and the updated installer/formula exist, check CLI `--version` for `0.3.3`, then restart and inspect `status` for `app_version: 0.3.3` and the expected executable. A source build's version alone does not prove publication or replace a running old daemon. Keep beta and stable configuration **and** state separate when running both. The arm64 app uses ad-hoc signing, not Developer ID notarization.

## 한국어

v0.3.3은 v0.3.2 이후의 집중 수정을 포함하는 안정판 소스·기본/사전 빌드 대상입니다. 이 노트와 네 가지 소스 매니페스트만으로 v0.3.3 바이너리·체크섬·설치기·Homebrew 포뮬러의 게시를 주장하지 않습니다. 사전 빌드 사용 전 [GitHub Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)에서 비초안·비프리릴리스 안정판과 arm64 압축 파일·개별 `.sha256`·`SHA256SUMS`를 확인하세요.

### v0.3.2 이후 수정

- 설치된 공식 캐릭터 팩은 모든 필터에서 **공식 설치 카드 하나**로 표시하며 설치·공식 목록에 중복 표시되지 않습니다. 게시된 공식 팩은 계속 명시적인 검증 다운로드·적용으로 설치합니다.
- **1024 × 1024 캔버스**의 원격 공식 캐릭터 초상화를 기존 다운로드·디코딩 **4 MiB** 예산 안에서 허용합니다. 팩 검증 제한은 유지합니다.
- 캐릭터 관리 카드의 **업데이트·제거·복원** 제어는 작업 중 → 유휴 상태에서 카드나 세대를 교체하지 않고 설치 카드 접근자를 통해 활성 상태를 갱신합니다. **검사(Inspect)**는 유지하며 작업 중 비활성화된 업데이트도 종료 후 다시 활성화될 수 있습니다.
- **캐릭터 팩 작업이 성공적으로 완료된** 뒤의 요약을 숨깁니다. 세션의 성공 상태 요약을 숨기거나 세션 관찰을 변경하지 않습니다.

검색·정렬, CLI 자동화, 충돌 인식 대사 초안, 8방향 말풍선 크기, 공식 브라우저, 설치 출처별 protocol-2 업데이트와 worker 전용 JIT는 [v0.3.2 기능](v0.3.2.md)으로 유지합니다. v0.2.1 Arin 호환성 수정도 유지합니다. 캐릭터 팩 형식 **v5**, 기본 루벨리아 **`default@0`**, 그림·라이선스는 바뀌지 않으며 기존 릴리스·태그·자산을 덮어쓰지 않습니다. 독립적인 `HerdrDesktopPetBeta.app`을 쓰는 `beta/0.3.3-beta.1`의 정렬된 베타 배포를 계획하지만 베타는 안정판 설치기가 아니며 이 계획은 베타 자산 게시의 증거가 아닙니다.

### 증거·업그레이드 경계

v0.3.3 후보에서 TypeScript, Bun 56개·477 expectations, 네이티브 주 테스트 590개·격리 FIFO 자식 1개(ignored 1개), 실제 메인 스레드 AppKit composer와 coordinator 29개를 통과했습니다. locked release 빌드·패키징, 설치기 shell 문법·안정판 노트/버전 검사를 통과했으며 arm64 앱/도우미, updater protocol 2, strict 서명과 decode worker에만 있는 JIT entitlement를 확인했습니다.

실제 패키지 데몬을 격리 프로필에서 실행해 `app_version: 0.3.3`·번들 실행 경로·UI/control 준비 상태, presentation/preferences 읽기와 내장 루벨리아 대사 대상을 확인하고 정상 종료했습니다. 백엔드 부재는 의도적이며 데이터는 연결되지 않았습니다. 이는 프로그램 방식 런타임 검사이지 물리적 GUI/IME·사용자 Homebrew 업그레이드 인증이 아닙니다. [Unreleased](unreleased.md)의 실제 공식 다운로드·적용, 미리보기·필터, 같은 세대 관리 메뉴 검증은 버전 변경 전의 별도 소스 관측으로 유지합니다.

[0.3 한영 이전 안내](0.3.md#한국어--v03-계열)에 따라 교체 전 기존 데몬을 종료하고 캐릭터·updater 기록을 포함한 실제 설정·상태를 백업하세요. 구형 protocol-1 예약은 임의로 재실행·삭제하지 않습니다. 공개 자산과 설치기/포뮬러 갱신을 확인한 뒤 CLI `--version`의 `0.3.3`, 재시작한 데몬 `status`의 `app_version: 0.3.3`과 실행 경로를 확인하세요. 소스 버전만으로 게시나 기존 데몬의 교체를 증명할 수 없습니다. 베타·안정판을 동시에 실행한다면 설정 **및** 상태를 모두 분리하세요. arm64 앱은 ad-hoc 서명이며 Developer ID 공증은 아닙니다.
