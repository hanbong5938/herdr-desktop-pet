## English

v0.3.6 is the new stable source/default-prebuilt target after v0.3.5. This note, source manifests and a tag alone do not establish publication. Before using the new prebuilt route, confirm the exact non-draft [GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases) and its complete assets:

- `HerdrDesktopPet-v0.3.6-macos-arm64.tar.gz`
- `HerdrDesktopPet-v0.3.6-macos-arm64.tar.gz.sha256`
- `SHA256SUMS`
- separate `HerdrDesktopPet-v0.3.6-rig-native.json` deployed-byte provenance sidecar

The Apple Silicon macOS 13+ archive contains only `HerdrDesktopPet.app`. The sidecar is outside the archive and signed bundle, not an installer input; compare it to actual extracted signed files before claiming deployed-byte provenance. The app is ad-hoc signed, **not notarized**. Stable Homebrew cutover follows publication and verification of the actual archive SHA-256, never a guessed hash. Existing v0.3.5 stable and beta tags, archives, checksums, sidecars and the separate beta formula remain unchanged; this release does not imply a new paired beta publication.

### Changes

- **Local Tern observation in the shared native app:** `--host herdr|tern|both` chooses the captured launch mode. Explicit `--host` wins over canonical `HERDR_PET_OBSERVATION_MODE`; default remains Herdr. Tern-only startup/readiness needs no Herdr server, plugin or socket, including with `exit_with_herdr` enabled. `--socket` still selects only the Herdr backend. The separate public [Tern plugin](https://github.com/hanbong5938/tern-desktop-pet) observes its local window inventory through bounded same-UID private exchanges, not remote Tern hosts. Window identity, epoch, sequence, generation and five-second freshness reject stale targets; closed or stale windows become Offline without stopping the Tern-only pet.
- **Guarded one-time replies:** a selected local Tern pane receives semantic `agents:ask`, not PTY injection. `prompt_accepted` reports `committed:false` and `delivery:"accepted_may_be_queued"`; acceptance alone is neither model delivery nor completed work. Unknown delivery never causes automatic ask replay. Tern worktree deletion is not added.
- **Direct-integration repairs:** unbound registration is result-free/command-null; lost first replies recover on ordinary polling, retired sources reset without replay, and exactly bound rejected receipts discard only captured reports. JSON requests are bounded at 256 KiB and complete encoded replies including LF at 512 KiB. The shared 64-source budget reclaims only expired offline Tern sources after pending finalization, never live or Herdr sources; the existing monotonic control tick expires freshness independently of Herdr polling. Connection executable/config/state values are validated and committed atomically; cancel/failure retains the old profile and malformed canonical data never falls back to legacy keys. Endpoint comparison uses full absolute/canonical identities, not basenames. The immutable configured `status.herdr_socket` is not proof of a live Herdr endpoint or a Tern dependency.
- **Bounded plugin inventory staging:** four cooperative zero-delay callbacks read tabs, sessions, agents, then hosts/panes and validate coherent context. Profile/incarnation/phase fences span asynchronous work. Accepted/failed receipts trigger a fresh full-inventory exchange immediately, without waiting for the unchanged periodic timer or replaying the ask. This bounds inventory API work per callback, not individual SDK-call duration, OS scheduling, general process overhead or delivery latency.
- **Four native languages:** Korean (`ko`), English (`en`), Simplified Chinese (`zh-Hans`) and Japanese (`ja`) cover native UI, updater consent/helper, dialogue editor and bundled Rubelia dialogue. System selection follows supported macOS preferred languages; explicit Traditional Chinese tags are skipped unless `Hans` is specified. Language-specific drafts and saved overrides remain independent. Four README/usage and promotional-site locales are retained; untranslated external catalog metadata falls back to English and the separate character gallery remains Korean/English. Existing v0.3.2 offline screenshots remain historical, not new translated captures or release evidence.
- **Protocol-3 beta opt-in:** automatic read-only checking remains default-on; **Receive beta updates** is independently default-off. Policy-specific successful-check timestamps remain separate; policy changes invalidate the old candidate. Strict SemVer selects eligible stable or opted-in beta releases without downgrading, and a final release outranks its same-base beta. Checks/toggles do not install, restart, refresh Brew or mutate Git. Explicit consent binds policy, candidate and source/target installation origins. Worker staging, exact image/origin startup pins, prospective host checks, captured channel ownership, once-only final Prepare ACK and leased recovery preserve installation/profile protection and never replay uncertain manager execution. Current activity and previous operation remain distinct, with expandable diagnostics.

The signed app and standalone helper advertise additive JSON capabilities `{"protocol":3,"observation_mode":1}`; compare fields semantically, not serialized key order. Plans/journals remain protocol 3. Default Herdr context can omit the mode key for legacy protocol-3 helper compatibility; an explicitly captured mode key requires helper observation capability 1, and Tern/both require matching app/helper capability and exact ready mode. The installer retains matched protocol-2 package support and rejects mixed pairs; existing protocol-1/2 operation records remain byte-preserved and require their retained matching helper, not silent migration by the new updater. The helper crate's independent version is not the app version.

Current v0.3.6 source packaging requires protocol 3 and observation-mode capability 1 on both executables before replacing the output bundle; a stale legacy helper cannot produce a seemingly successful but incompatible package.

### Installation and upgrade

**After** the exact v0.3.6 assets and stable formula are published, consumers use two explicit installation commands; no Rust/Cargo, Bun, Node.js or native source build is required:

```sh
brew install hanbong5938/tap/herdr-desktop-pet
tern plugin install https://github.com/hanbong5938/tern-desktop-pet
```

The formula installs the app under Homebrew's prefix, not `/Applications`. Installing the Tern plugin does not silently download, build or execute the native app. Source development remains optional; a successful source build is not publication evidence. The manifest-pinned installer offers `--prebuilt` without source fallback and explicit `--source` for development.

Stop the old daemon before replacement or changing launch mode; back up actual config **and** state, including preferences, lifecycle, installed characters, icons and updater records. Keep the same saved data for an upgrade, but use separate config/state paths for independent Herdr/Tern or stable/beta profiles. For an explicit Tern-only profile:

```sh
PET="$(command -v herdr-desktop-pet)"
PET_CONFIG="$HOME/.config/herdr/plugins/config/desktop-pet-tern"
PET_STATE="$HOME/.local/state/herdr/plugins/desktop-pet-tern"
"$PET" --version
"$PET" --host tern --config-dir "$PET_CONFIG" --state-dir "$PET_STATE" start
"$PET" --host tern --config-dir "$PET_CONFIG" --state-dir "$PET_STATE" status
```

In an actual Tern window, **Configure desktop pet connection** must use the same absolute executable, config and state paths. Verify `app_version: 0.3.6`, the expected running executable, `observation_mode:tern`, UI readiness and the window's connection status; use the same paths/mode for stop and later commands. Installing/linking a plugin alone is not connection verification or automatic native startup.

Character-pack format v5, bundled Rubelia `default@0`, optional separately published character packs, existing artwork/rights/source records, authored motion and rig overrides remain unchanged. The rig ABI identity/struct-size checks, sealed initial-motion bytes, v0.3.4 eye ownership/post-signing provenance and v0.3.5 pointer capture/bubble/reply/IME repairs are retained. No older asset is rewritten and no imported/default character is silently replaced.

Apple Silicon macOS 13 이상용 압축 파일은 `HerdrDesktopPet.app`만 포함합니다. 서명 후 배포 파일 사이드카는 압축 파일·서명 번들 밖에 있으며 설치 입력이 아닙니다. 실제 추출 파일과 대조해야 배포 바이트 출처를 주장할 수 있습니다. 앱은 **ad-hoc 서명·미공증**입니다. 안정판 tap은 실제 게시 압축 파일의 SHA-256 검증 후 갱신하며 해시를 추측하지 않습니다. 기존 v0.3.5 안정판·베타 태그/자산/체크섬/사이드카와 별도 베타 포뮬러는 유지하며 새 대응 베타 게시를 주장하지 않습니다.

### 변경 사항

- **공통 네이티브 앱의 로컬 Tern 관찰:** 명시적 `--host herdr|tern|both`, 정규 `HERDR_PET_OBSERVATION_MODE`, 기본 Herdr 순으로 시작 모드를 고정합니다. Tern 전용 시작·준비에는 `exit_with_herdr`가 켜져도 Herdr 서버·플러그인·소켓이 필요 없습니다. `--socket`은 계속 Herdr 백엔드 전용입니다. 별도 공개 [Tern 플러그인](https://github.com/hanbong5938/tern-desktop-pet)은 동일 UID 비공개 교환으로 자기 로컬 창을 관찰하며 원격 Tern은 지원하지 않습니다. 창 신원·epoch·sequence·generation·5초 신선도가 오래된 대상을 차단하고 닫힌/오래된 창은 앱을 종료하지 않고 Offline이 됩니다.
- **한 번만 전달하는 답장:** 검증한 로컬 pane에 의미론적 `agents:ask`를 보내며 PTY 입력으로 대체하지 않습니다. `prompt_accepted`의 `committed:false`, `delivery:"accepted_may_be_queued"`는 수락 영수증일 뿐 모델 전달·작업 완료가 아닙니다. 불명 전달에 자동 재시도가 없고 Tern worktree 삭제도 추가하지 않습니다.
- **직접 연동 수정:** 첫 등록은 results 없이 command-null이고 첫 응답 유실은 정상 poll로 복구합니다. retired 신원은 ask 재생 없이 초기화하고 정확히 바인딩된 rejected 영수증은 해당 요청의 보고만 제거합니다. JSON 요청 256 KiB·LF 포함 전체 응답 512 KiB 한도를 실제 직렬화로 검사합니다. 공유 64개 소스 한도는 pending 종결 뒤 만료된 오프라인 Tern만 회수하며 live/Herdr는 축출하지 않습니다. monotonic 제어 tick은 Herdr poll과 독립적으로 만료시킵니다. 실행 파일/설정/상태 연결을 함께 검증·원자적으로 저장하고 취소·실패는 이전 프로필을 유지합니다. 정규 데이터가 잘못되면 이전 키로 fallback하지 않고 endpoint는 전체 절대/canonical 경로로 비교합니다. 고정된 `status.herdr_socket`은 살아 있는 Herdr endpoint나 Tern 의존성의 증거가 아닙니다.
- **한도 있는 SDK 목록 수집:** 네 번의 zero-delay 콜백에서 tabs·sessions·agents를 각각 읽고 마지막에 hosts/panes와 검증을 수행합니다. 비동기 작업 동안 프로필/incarnation/단계를 보호합니다. 수락·실패 영수증은 기존 주기 타이머를 기다리지 않고 신선한 전체 교환을 즉시 시작하며 ask를 재생하지 않습니다. 이는 콜백별 목록 API 작업 한도이며 개별 SDK 호출·OS 스케줄링·프로세스 오버헤드·전달 지연의 보장은 아닙니다.
- **네 언어:** 한국어(`ko`)·영어(`en`)·중국어 간체(`zh-Hans`)·일본어(`ja`)를 UI·업데이트 동의/도우미·대사 편집·내장 루벨리아 대사에 적용합니다. 시스템 선택은 지원하는 macOS 선호 언어를 따르고 `Hans`가 없는 명시적 번체는 다음 언어로 넘어갑니다. 언어별 초안·저장 override는 독립적입니다. README/사용 안내/소개 사이트의 네 언어를 유지하며 미번역 외부 카탈로그는 영어 fallback, 별도 캐릭터 갤러리는 한국어/영어입니다. 기존 v0.3.2 오프라인 스크린샷은 과거 자료이며 새 번역 화면·게시 증거가 아닙니다.
- **프로토콜 3 베타 opt-in:** 읽기 전용 자동 확인은 기본 켜짐, 독립적인 **베타 업데이트 받기**는 기본 꺼짐입니다. 정책별 성공 시각을 분리하고 정책 변경은 이전 후보를 무효화합니다. 엄격한 SemVer로 선택한 안정판/베타 중 상위 버전만 제안하며 같은 기본 버전의 정식판이 우선이고 베타를 꺼도 다운그레이드하지 않습니다. 확인/스위치만으로 설치·재시작·Brew 갱신·Git 변경을 하지 않습니다. 별도 동의는 정책·후보·원본/대상 출처에 묶입니다. worker staging·정확한 이미지/출처 시작 pin·대상 호스트 확인·캡처한 채널 소유권·한 번의 최종 Prepare ACK·lease 복구가 설치/프로필을 보호하며 불명 관리자 실행을 재생하지 않습니다. 현재 작업과 이전 결과를 구별하고 원본 진단은 펼쳐 볼 수 있습니다.

서명된 앱·독립 도우미의 additive JSON capability는 `{"protocol":3,"observation_mode":1}`이며 문자열 키 순서가 아니라 필드로 비교합니다. 계획/저널은 프로토콜 3 그대로입니다. 기본 Herdr context는 이전 protocol-3 도우미 호환을 위해 모드 키를 생략할 수 있지만 명시적으로 캡처한 키가 있으면 도우미 observation capability 1이 필요하고 Tern/both에는 동일 앱·도우미 capability와 정확한 준비 모드가 필요합니다. 설치기는 동일 protocol-2 쌍도 유지하며 혼합은 거절합니다. 이전 protocol-1/2 작업 기록은 바이트 그대로 보존하고 해당 버전 도우미로 검사/복구하며 새 도우미가 몰래 이전하지 않습니다. 도우미 crate 버전은 앱 버전과 독립적입니다.

현재 v0.3.6 소스 패키징은 출력 번들을 교체하기 전에 앱과 도우미 모두 프로토콜 3·관찰 모드 capability 1인지 검사합니다. 이전 도우미가 남아 있어도 호환되지 않는 패키지를 성공한 것처럼 만들지 않습니다.

### 설치와 업그레이드

정확한 v0.3.6 자산과 안정판 포뮬러가 **게시된 뒤** 위 영문 코드의 두 명령으로 네이티브 앱을 먼저 설치하고 공개 Tern 플러그인을 별도로 설치합니다. Rust/Cargo·Bun·Node.js·소스 빌드가 필요 없습니다. 포뮬러는 `/Applications`가 아닌 Homebrew prefix에 앱을 놓습니다. 플러그인 설치는 앱을 몰래 내려받거나 빌드·실행하지 않습니다. 선택형 소스 개발 또는 매니페스트 고정 `--prebuilt` 설치(소스 fallback 없음)는 별도 경로이며 소스 빌드가 게시 증거는 아닙니다.

교체·모드 변경 전 기존 데몬을 종료하고 실제 설정 **및** 상태(대사/선호 설정·lifecycle·설치 캐릭터·아이콘·업데이트 기록)를 백업하세요. 업그레이드는 기존 저장 데이터를 유지하고 독립 Herdr/Tern·안정판/베타는 설정과 상태를 모두 격리합니다. 위 Tern 전용 예시처럼 같은 `--host tern`, `--config-dir`, `--state-dir`로 시작·상태·종료를 실행하세요. 실제 Tern 창의 **Configure desktop pet connection**에도 같은 절대 실행 파일/설정/상태 경로를 지정합니다. `app_version: 0.3.6`·예상 실행 경로·`observation_mode:tern`·UI 준비·창 연결 상태를 확인하세요. 플러그인 설치/연결만으로 실제 창 검증이나 앱 자동 시작을 주장하지 않습니다.

팩 v5·내장 루벨리아 `default@0`·별도 게시 선택형 팩·기존 그림/권리/출처 기록·작성된 motion·rig override는 유지합니다. rig ABI 신원/구조체 크기 검사·봉인 초기 motion 바이트·v0.3.4 눈 소유권/서명 후 출처·v0.3.5 포인터/말풍선/답장/IME 수정을 유지합니다. 이전 자산을 덮어쓰거나 선택/기본 캐릭터를 몰래 바꾸지 않습니다.

- 실제 패키징한 v0.3.6 앱을 격리 설정/상태와 `--host tern`으로 시작했으며 설정된 Herdr 소켓의 부모 경로도 없었습니다. 상태는 `app_version: 0.3.6`, `ui_ready:true`였고 실제 `tern-exchange`가 유효한 빈 스냅샷을 수락했으며 일반 Stop으로 정상 종료했습니다. 가짜 Herdr endpoint 없는 Tern 전용 시작/교환 근거이지 실제 에이전트 전달 근거는 아닙니다.
