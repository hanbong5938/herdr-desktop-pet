# Herdr Desktop Pet v0.1.6 release notes

## Summary and upgrading

This historical page is reconstructed from the published [v0.1.6 Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.1.6), tagged guides, and contemporaneous integration evidence. Use the Release page for its published assets and publication information; the test counts below are reported historical evidence, not newly executed checks.

v0.1.6 is the published inline-card reply and approved Rubelia redraw release. It includes lifecycle settings, editable dialogue, status indicators, and remote observation, retaining the Rubelia-only bundle and separate optional character repository. [v0.1.5](v0.1.5.md) was tagged but did not publish a binary.

**Upgrading from v0.1.4 changes Enter from newline to Send.** Read the [v0.1.4 → v0.1.6 migration](../migrations/v0.1.4-to-v0.1.6.md) before using replies. Existing imported selections remain unchanged, and `default@0` retains its identity. Per-session reply drafts do not survive app restart.

## Inline replies and send safety

- Expand the bubble, then select a local agent session card to open its initially hidden one-line reply. **All** is not a reply target. Selecting another local card folds the old reply and opens the new one; remote cards show read-only feedback without an input or Send button.
- **Enter**, **Command+Enter**, or **Send** submits. Committed line breaks from typing, paste, or text import become spaces; active Cocoa marked text is not altered before commitment. IME composition never submits. **Escape** first cancels active composition, otherwise folds only the reply. Outside-bubble clicks fold only the reply, except during composition; other inside-bubble clicks do not automatically fold it. Neither action collapses the bubble.
- Per-session drafts survive folding and bubble collapse in memory. A successful matching ACK clears and folds only the matching current reply: edits made during a send or a newly selected field survive. Failure or uncertain delivery preserves the draft and reply state. Prompt acceptance is not completed agent processing.
- Selection, filtering, and structural row replacement are deferred during composition. Only the latest still-valid, visible target is replayed after checking the current filter, display cap, and connection generation; committed text remains with its original session/generation. Reentrant Cocoa callbacks queue navigation instead of reborrowing an in-flight layout.
- Replies attach to the final displayed row and final card width after insertion/deletion. Status lookup remains independent of filter/display cap while composition is retained; offline composing rows keep their full accessibility/tooltip identity and fitting localized status badge, with submission disabled when ineligible. Matching-ACK close invalidates content safely during tracking regardless of whether a frame tick or wake consumes the ACK.
- The reply uses a visible border, opaque palette-derived fill, and compact native action button. Theme changes retain geometry, drafts, and preedit; live status, Korean/English hints, and send eligibility continue to update while navigation waits.

Messages go only through the selected local source's `agent.prompt` API, never a global CLI, shell, SSH, or raw pane input. Local excluded/offline, stale or unready sessions, and unsupported servers cannot send; `unsupported_method` is reported without fallback. Remote cards, including retained ones, are read-only. Handle approval/question UI in the actual terminal. Check an uncertain result before manually resending: there is no automatic retry. The host API targets the current pane occupant without an atomic expected-session guard, so an instantaneous agent/session replacement remains possible.

## Included lifecycle, dialogue, status, and pack behavior

These are included capabilities and context, not a claim that every capability originated in v0.1.6:

- **Lifecycle:** `auto_start` and `exit_with_herdr` are independent and owned exclusively by `lifecycle.json`. New profiles default on/on; existing boolean `enabled` migrates to auto-start, preserving false, while an absent exit setting defaults off for existing profiles. Other fields remain intact; invalid data and failed saves report errors without silently changing prior policy. Manual start works with auto-start off. Stop/Quit ends this run or pending startup, not future automatic starts; restart preserves settings, position, scale, and preferences. With exit enabled, initial server absence or loss of the last healthy server starts a 30-second grace, canceled by healthy reconnection. Client detach is not server loss; stale endpoints/retries do not extend grace. Confirmed disable across registered endpoints is a separate immediate-stop host condition. The later initially-missing/unlink-history watcher fix is not attributed to this release.
- **Offline lifecycle controls:** the global plugin settings action opens only the lifecycle window and requires a live enabled host; native `settings`, `settings get`, and `settings set auto_start|exit_with_herdr on|off` work without a running pet/host and do not launch it. Get/set return structured JSON and reject invalid arguments/save failures. Changing auto-start does not stop/show the running pet; ensure does not force a hidden pet visible.
- **Dialogue:** a separate resizable editor can inspect inactive characters and historical revisions without renderer activation. Korean/English drafts are isolated by character/language/event, covering eight phase/reaction events, with original-text reference, unsaved badges, context-local undo/redo, and Save/Command+S. Entries allow 2048 UTF-8 bytes; blank text removes the override, reset-entry confirms dirty draft loss, and reset-all confirms removing both languages. Drafts survive context changes/reopening in this run, but only saved text survives restart; failed saves retain drafts and committed text. `preferences.json` stores overrides by character ID across revisions; external assets use a separate activation-time canonical-path identity, not automatically migrated after a path change. Editing language does not change UI language or observation/reaction semantics.
- **Status:** saved icons/colors retain the v0.1.4 validated-outcome semantics: idle/`Done` alone is not success; ambiguity, report loss, new activity, or disconnect revokes the previous result without re-accepting the same cached report when ambiguity clears. Sources start Offline until a coherent snapshot. Text labels accompany icons; summaries cover all observed sessions regardless of display filtering. Native tracking defers bubble display/placement changes, then drains latest settings without losing selection or drafts.
- **Remote observation:** Local defaults on, Remote off. Users authenticate SSH/saved machines in a terminal, then select enabled profiles; each observes its saved session, not the entire host. Polling is about five seconds, so short transitions can be missed. Selections survive Remote off, rename, and restart; disabling/removing a profile stops its contribution, not its processes. All sources off shows Unknown. Disconnected cards retain last-known data as Offline; recovery/reselection starts a baseline without replaying old completion reactions. The remote host needs a compatible Herdr server but no pet app/plugin. The pet does not perform interactive setup, send remote prompts, or substitute Local on remote failure; authentication recovery is a manual `herdr machine reconnect '<profile-id>'` command.
- **Pack selection and history:** Characters row/revision choices stage a candidate until explicit Apply; Cancel clears an unsubmitted choice, and reopening retains it. Pending mutations block selection and mutation controls while read-only inspection/diagnostics remain available. Picker/confirmation returns recheck busy state and original listing generation. Failed/canceled operations retain the candidate; unknown submitted results retain their full operation ID for `pack status`, distinct from rejected submissions. Latest UI results and live-versus-committed selection warnings remain distinct from operation completion; inactive mutations can complete without renderer activation. CLI select/restore remain immediate with existing queue/idempotency behavior. Importing a directory or `.herdrchar` does not select it; select chooses newest revision, restore chooses historical revision, and removing an active pack returns to Rubelia. `default@0` cannot be imported, updated, or removed. If both registry files are corrupt, built-in original dialogue remains readable at the listing generation without repair/activation; unavailable managed revisions do not become available. Check uncertain mutations with their operation ID rather than blindly repeating them.

## Compatibility and known limits

- Apple Silicon macOS 13+ native distribution only; no Windows distribution or accessibility-based click-routing claim. Bundles are ad-hoc signed, not Developer ID signed or notarized; explicit macOS approval may be needed. Alpha click-through is pointer-polled and has a click-routing race.
- Local observation supports Herdr 0.9.0+. `agent.prompt` was reported verified with 0.9.2, not guaranteed by that observation baseline. Remote observation separately needs compatible saved-machine API forwarding (documented in 0.9.2) and a compatible remote server.
- This is **an app release, not a new Herdr host release**. Manifest `min_herdr_version = 0.9.3` is a patch baseline, not proof of `client.attached`. Attach auto-start requires official Herdr 0.9.3 source with the supplied patch applied and built, or an actual host release advertising the hook; stock 0.9.0/0.9.3 do not provide it. Use the [host integration guide](../../integrations/herdr/README.md), inspect plugin-link warnings, and verify subscription. Linking/enabling on an already-running server alone does not launch the pet: start once or wait for a qualifying attach with auto-start on.
- The original tagged installer used authenticated `gh` for explicit prebuilt download; Homebrew did not require GitHub login. Current installation instructions are in the [English guide](../../readme.md) and [Korean guide](../../readme.ko.md), not inferred from the old tag. The [v0.1.7 notes](v0.1.7.md) describe the later symlinked CLI resource fix.
- Reported native probes do **not** prove physical-keyboard Korean/Japanese IME behavior, OS-granted focus transfer, or binary publication. Publication is established separately by the actual Release assets. The pre-existing native clippy all-target `erasing_op` issue was out of scope.

### 한국어 업그레이드 요약

v0.1.6에는 카드별 한 줄 답장과 승인된 루벨리아 열 포즈 새 그림이 포함됩니다. **v0.1.4의 Enter 줄바꿈은 v0.1.6에서 전송으로 바뀝니다.** 확정 입력의 줄바꿈은 공백으로 바꾸지만 IME 미확정 조합은 유지하며 조합 중에는 전송하지 않습니다. Escape는 먼저 조합을 취소하고, 그 외에는 말풍선이 아니라 답장칸만 접습니다. 전송 중 수정한 초안이나 새로 선택한 답장칸은 일치하는 ACK가 아니면 지우지 않습니다. 실패·전달 불명확 시 상태를 보존하며, ACK는 에이전트 처리 완료가 아닙니다. 초안은 앱 재시작 후 복원되지 않습니다.

로컬의 유효하고 준비된 세션에만 `agent.prompt`로 보내고 원격 카드는 읽기 전용입니다. 승인·질문은 실제 터미널에서 처리하고, 전달 여부가 불명확하면 확인 없이 재전송하지 마세요. 자동 재시도·셸/SSH 우회는 없으며, 호스트 API에는 전송 순간 패널 세션 교체를 원자적으로 막는 기능이 없습니다. 팩 작업 결과가 불명확할 때도 작업 ID로 `pack status`를 확인한 뒤 처리하세요.

앱 릴리스는 Herdr 호스트 릴리스와 별개입니다. 클라이언트 attach 자동 실행에는 제공된 패치를 적용·빌드한 공식 Herdr 0.9.3(또는 실제 훅 지원을 명시한 후속 호스트)이 필요하며, 순정 0.9.0/0.9.3이나 최소 버전 표기는 지원 증거가 아닙니다. 연결 경고와 구독 수락을 확인하세요. 로컬 관찰의 0.9.0 기준은 메시지 API 지원을 보장하지 않으며, 원격 관찰에는 호환되는 저장 머신 전달 CLI와 서버가 별도로 필요합니다. Apple Silicon macOS 13+용 ad-hoc 서명 앱으로 공증되지 않았으며 macOS의 명시적 실행 승인이 필요할 수 있습니다. 기록된 프로토콜 주입 검사는 실제 키보드 IME나 운영체제 포커스 이동을 입증하지 않습니다. [마이그레이션 안내](../migrations/v0.1.4-to-v0.1.6.md)를 확인하세요.

## Historical evidence appendix

The [v0.1.6 tagged integration notes](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.6/TODO.txt) report the following scoped results. They are retained as evidence, **not rerun here**:

- `cargo test`: **273 passing**, plus `cargo build` and `bun check` passed for the source checkout. An actual source-built native app in an isolated profile with a real Unix-socket fixture exercised direct Cocoa committed insertion, UTF-16 selection, undo/redo, pasteboard import, Korean/Japanese marked-text protocol preedit, selected-row reflow, deferred filtering, and a matching `agent.prompt`/ACK.
- Native source-loss probes covered retained offline accessibility identity, locale/indicator transitions, and fitting status frames. Model tests covered accepted outcomes versus offline/ambiguous identity, hidden rows, remote read-only, and connection generation. These are protocol/model checks, not physical-keyboard IME or OS focus guarantees, and do not themselves establish binary publication.
- With **12 seconds of injected delay per real decoder**, full native validation completed in **52.17 seconds**. Isolated AppKit/CLI startup reached **`ui_ready` and `control_ready` in 51.71 seconds**, with **`default@0` active**. Individual decoder deadlines, bounded worker count, and RGBA quotas remained enforced. These fixture measurements establish the scoped catalog-budget regression, not typical startup time or unlimited tolerance for delay.
- The subsequent native regression suite reported **275 passed**. The 273 and 275 counts describe separate reported scopes/stages, not a new combined total.
