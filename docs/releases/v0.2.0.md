# Herdr Desktop Pet v0.2.0 release notes

[Versions](README.md) · [0.2 line](0.2.md) · [English/한국어 upgrade guide](../migrations/v0.1.11-to-v0.2.0.md) · [Herdr integration](../../integrations/herdr/README.md)

v0.2.0 promotes the native behavior shipped in the separate beta3 channel to the stable `HerdrDesktopPet.app` and `herdr-desktop-pet` CLI. The historical beta1/beta2/beta3 tags and prerelease assets remain intact, and the separate rolling beta formula is preserved; none is replaced by this stable release. This is an **app** release, not a new Herdr host or character-pack release. The built-in Rubelia `default@0` and v5 pack format, art and licensing boundaries are unchanged. See the [historical v0.1.11 note](v0.1.11.md) for the preceding stable behavior.

## Changes from v0.1.11

- **Independent windows and readable replies:** Character and bubble visibility are independent. Hiding the character leaves an enabled bubble as a movable standalone panel; showing the character reattaches it. Full-window passthrough affects both windows, while alpha passthrough affects only character art. The saved standalone position and IME-aware placement survive hide/show/reset as appropriate; card selection and reply drafts survive those actions **only during this run**, not restart. The reply input reserves the full native text line, border and scroller space, fixes glyph clipping and horizontal offsets in Legacy/Overlay and tight layouts, and routes focused Command-A/C/X/V to native select-all/copy/cut/paste while respecting marked text, extra modifiers and single-line paste normalization.
- **Settings, menu and icon:** Right-click or Control-click the character, bubble background or card header for contextual **Settings…** in the existing three-tab panel. **Close Bubble Window** still hides only the bubble, not the app or Herdr session; text fields and controls keep native menus, and bubble actions guard IME composition. The menu-bar icon defaults to **Always show** even for profiles without `menu_bar_mode`; **Only when recovery is needed** is an explicit alternative, showing the icon only when both windows are hidden or full-window passthrough is enabled. The recovery action shows/enables the character without changing bubble visibility or alpha passthrough. Choose a bounded static PNG for the status image or restore the template pawprint; the managed `menu-bar-icons/` copy means deleting the external original does not remove the imported image. PNG integrity and nonblocking regular-file input checks protect imports; this is not a promise of bounded network-filesystem latency.
- **Observation and lifecycle:** Compact This Mac / Remote machines settings show measured, localized status and preserve focus/scroll through polling. Catalog errors retain the prior profiles rather than masquerading as a confirmed empty list; reconnect **copies** a shell-quoted command but never executes it. A missing local plugin row on the first check is not a disable event, so standalone/remote-only observation can continue; confirmed disable or unlink after membership is known stops the pet even if a remote profile is healthy. Other lost-health cases keep the grace period. Remote cards remain read-only; turning local display observation off does not disable lifecycle policy.
- **Linked-worktree removal:** An eligible current local linked-worktree card offers **Remove Worktree…** with a target-specific, Cancel-default confirmation. It excludes the main repository checkout and revalidates after confirmation, then sends a single `{workspace_id, force: false}` request to a server that supports `worktree.remove`. **Ignored files can be deleted even with `force: false`**; workspaces, panes and processes may be affected. There is no trash/undo, branch deletion, force, shell/git fallback, automatic retry or atomic binding to the earlier checkout/generation: after uncertain delivery, inspect the checkout and workspace before any manual retry. Older or incompatible host metadata may omit the action; a host without the actual removal API cannot perform it.
- **Documentation build fix:** Release/current/frozen Wiki Markdown scanning no longer lets malformed outer links mask valid inner links and images. The generated Wiki remains a reading view of canonical tagged release notes and current-source navigation, not an independent source of app behavior.

## Install or upgrade safely

Apple Silicon macOS 13+ is required. The stable Homebrew formula installs the app under Homebrew's prefix, **not** `/Applications`, and provides the `herdr-desktop-pet` CLI; it does not install a Herdr plugin or patch the host. Stop the running stable daemon **before** upgrading: `start` reuses an existing daemon, so `--version` by itself cannot prove the running process was replaced.

```sh
herdr-desktop-pet stop
brew update && brew upgrade herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status
```

For a new stable installation, run `brew install hanbong5938/tap/herdr-desktop-pet`, then `herdr-desktop-pet --version`, `herdr-desktop-pet start`, and `herdr-desktop-pet status`. The CLI version, running executable and `status` `app_version` should all be stable `0.2.0`. If Homebrew refuses loading the formula, use formula-scoped `brew trust --formula hanbong5938/tap/herdr-desktop-pet`; do not grant broader trust. For a manual prebuilt, obtain `HerdrDesktopPet-v0.2.0-macos-arm64.tar.gz`, its `.sha256`, and `SHA256SUMS` from the actual [GitHub Release catalog](https://github.com/hanbong5938/herdr-desktop-pet/releases) and verify the archive checksum before unpacking. A source build on the v0.2.0 `main` checkout includes these native features; optionless/prebuilt installation pins stable v0.2.0. The **Release catalog and complete uploaded assets**, not this source note or tag alone, establish what has actually been published.

If moving from beta, stop the running beta **first** (`herdr-desktop-pet-beta stop`), then install or upgrade the **stable** formula above. The beta CLI and `HerdrDesktopPetBeta.app` are not the stable app. Stable and beta share a profile/control namespace unless **both** config and state directories are isolated; do not run them concurrently against a shared profile. Before replacing either app, back up `preferences.json`, `lifecycle.json`, `characters/`, and `menu-bar-icons/` from the active profile. No forced profile migration or downgrade compatibility is promised. See the [bilingual migration guide](../migrations/v0.1.11-to-v0.2.0.md) and [root runtime guide](../../readme.md) / [한국어](../../readme.ko.md). Run a GUI app on the computer whose Desktop should display it: launching it over SSH on a remote Mac does not display a window on the local Mac.

The app bundle is **ad-hoc signed, not Developer ID signed or notarized**; macOS Gatekeeper may require approval. Local observation accepts Herdr 0.9.0+, but this minimum alone does not establish optional server APIs. Remote observation needs compatible saved-machine forwarding CLI and server; local replies need `agent.prompt`; `client.attached` automatic startup needs the [patched-capability host](../../integrations/herdr/README.md), not merely a matching host version. An observed stock Herdr 0.9.3 does not certify every Herdr 0.9.0 server or the `worktree.remove` API. Prompt acknowledgement is not task completion, and uncertain delivery must be checked before resending. No automatic retry is added.

## Verification boundary

Published beta3 at immutable `beta/0.2.0-beta.3` retains its own source, tests, AppKit probes, downloads and beta-only formula/installation evidence; those results **do not verify** stable v0.2.0 packaging, Homebrew or publication. The user subsequently confirmed that beta3 works; the earlier report of an invisible window was a remote-execution/local-display misunderstanding, **not** a newly reproduced beta3 window defect. This confirmation does not certify physical keyboard focus, real IME composition, native image chooser/confirmation interactions, pointer interaction or VoiceOver. Stable build/package/runtime/API/Homebrew evidence is separate from that beta3 record and must not be inferred from it.

**Fresh pre-tag stable-source checks:** TypeScript and **44 Bun tests / 355 expectations**, scoped Rust formatting, native arm64 release check/build and **343 tests** (342 main plus one bounded FIFO child) passed. The actual main-thread AppKit composer executable passed native geometry, Unicode insertion, selection and marked-text boundaries in both scroller styles. A newly packaged `HerdrDesktopPet.app` and independent local archive extraction passed arm64, `0.2.0` version and deep strict signature checks. The extracted app actually reached UI/control readiness, accepted registration and connected data against an owned stock Herdr 0.9.3 backend in separate config/state; hide/show retained the enabled bubble, and the app was stopped. Builtin `default@0` export through a CLI symlink succeeded (28,048,065 bytes), and an actual 1024×1024 rig preview was rendered and visually inspected. The actual Wiki generator produced **23 managed pages**, including this note, the 0.2 line and migration. These are local pre-tag proofs: CI-published asset downloads, public Release/latest and Homebrew installation checks occur after publication and are not claimed as evidence already present in this frozen note.

## 한국어 요약 · v0.1.11에서 달라진 점

v0.2.0은 별도의 beta3 채널에 포함됐던 네이티브 기능을 안정판 `HerdrDesktopPet.app`·`herdr-desktop-pet`으로 옮깁니다. beta1/2/3의 태그·배포 파일·베타 포뮬러는 수정하지 않습니다. 앱 릴리스이지 Herdr 호스트 또는 캐릭터 팩 릴리스가 아닙니다. Rubelia `default@0`, v5 팩, 그림·라이선스 경계도 유지합니다.

- **독립 표시·답장:** 캐릭터를 숨겨도 표시 중인 말풍선은 이동 가능한 독립 창으로 남고, 다시 표시하면 재부착됩니다. 전체 창 클릭 통과는 두 창, 투명 영역 클릭 통과는 캐릭터 그림에만 적용합니다. 위치·IME 조합 상태를 고려한 배치와 실행 중 카드·답장 초안을 보존하지만 **초안은 재시작 후 복원되지 않습니다**. Legacy/Overlay의 답장 입력 글자 잘림과 가로 스크롤·작은 화면 배치를 고치고, 포커스된 답장창의 Command-A/C/X/V를 네이티브 전체 선택·복사·잘라내기·붙여넣기로 연결하며 조합 입력과 추가 수정키를 침범하지 않습니다.
- **설정·아이콘:** 캐릭터·말풍선 배경·카드 헤더의 우클릭/Control-click으로 기존 3탭 **설정…**을 열 수 있습니다. **대화창 닫기**는 말풍선만 숨기며 앱·Herdr 세션 종료가 아닙니다. 기본 메뉴 막대 아이콘은 이전 조건부 복구 방식과 달리 **항상 표시**이고, 명시적으로 **복구가 필요할 때만 표시**를 선택하면 두 창이 모두 숨겨지거나 전체 창 클릭 통과일 때에만 나타납니다. 복구는 캐릭터와 조작을 되살리되 말풍선 표시·투명 영역 클릭 통과를 유지합니다. 정적 PNG를 `menu-bar-icons/`에 관리 사본으로 가져오거나 기본 발바닥 그림으로 되돌릴 수 있습니다. PNG 무결성과 일반 파일 입력을 검사하지만 네트워크 파일시스템 지연 시간까지 보장하지 않습니다.
- **관찰·실행 관리:** 간결한 This Mac / Remote machines 설정에서 저장 머신·상태를 명확히 구분하고 목록 조회 오류 시 이전 목록을 남깁니다. 재연결 명령은 셸 인용해 **복사만** 하며 실행하지 않습니다. 최초 로컬 플러그인 목록에 항목이 없는 것만으로 즉시 종료하지 않아 독립·원격 전용 관찰을 허용하지만, 이미 관찰한 항목의 비활성화·연결 해제 확인 시 원격 상태와 관계없이 종료합니다. 다른 연결 상태 상실에는 유예 시간이 남습니다. 원격 카드는 읽기 전용이고 로컬 표시 관찰을 꺼도 실행 관리 정책을 끄지는 않습니다.
- **연결 워크트리 삭제:** 자격 있는 로컬 카드의 **워크트리 삭제…**는 대상을 명시하고 취소 기본 확인 후 한 번만 `{workspace_id, force: false}`를 요청합니다. 메인 저장소 루트는 대상이 아닙니다. **`force: false`에서도 무시된 파일이 삭제될 수 있고** 워크스페이스·패널·프로세스에 영향이 있습니다. 휴지통·되돌리기·강제 삭제·git/셸 우회·자동 재시도·확인 전후 체크아웃 원자적 고정은 없습니다. 전달 불명 시 재시도 전에 실제 파일과 워크스페이스를 확인하세요. 서버의 실제 `worktree.remove` 기능과 올바른 선택적 메타데이터가 필요하며 버전 번호만으로 보장되지 않습니다.
- **문서 생성 수정:** 잘못된 외부 Markdown 링크가 유효한 내부 링크·이미지를 가리지 않도록 Release/현재·고정 Wiki 스캐너를 수정했습니다. Wiki는 태그에 고정된 정식 노트와 현재 탐색 문서에서 생성되는 읽기용 화면입니다.

## 한국어 설치·안전·검증 경계

Apple Silicon macOS 13+가 필요합니다. 기존 안정판은 실행 중 데몬을 **먼저 종료**하고 `brew update && brew upgrade herdr-desktop-pet`을 실행하세요. 신규 설치는 `brew install hanbong5938/tap/herdr-desktop-pet`입니다. `herdr-desktop-pet --version`, 새로 시작한 데몬의 실제 실행 파일과 `herdr-desktop-pet status`의 `app_version`이 모두 안정판 `0.2.0`인지 확인하세요. `start`는 실행 중 데몬을 재사용하므로 CLI 버전만으로는 부족합니다. Homebrew가 포뮬러 로드를 거부할 때만 `brew trust --formula hanbong5938/tap/herdr-desktop-pet`을 사용하세요. 앱은 `/Applications`가 아닌 Homebrew 접두 경로에 설치되며 플러그인 설치·호스트 패치는 하지 않습니다. 수동 배포 파일은 실제 [GitHub Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 `HerdrDesktopPet-v0.2.0-macos-arm64.tar.gz`, `.sha256`, `SHA256SUMS`를 받아 체크섬을 확인하세요. 옵션 없는/사전 빌드 설치는 v0.2.0을 고정하고 이 버전의 `main` 소스 빌드에도 네이티브 기능이 포함됩니다. 이 노트·태그만으로 실제 게시 완료를 판단하지 말고 공개 Release와 세 자산을 확인하세요.

베타에서 이동할 때는 `herdr-desktop-pet-beta stop`으로 먼저 멈추고 **안정판** 포뮬러를 설치·업그레이드하세요. 두 채널은 설정과 상태 디렉터리를 **둘 다** 격리하지 않으면 프로필·제어 네임스페이스를 공유하므로 동시에 사용하지 마세요. 활성 프로필의 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`를 백업하고 강제 프로필 이전·다운그레이드 호환성을 기대하지 마세요. 앱을 SSH로 원격 Mac에서 실행하면 그 컴퓨터의 Desktop에 나타나지 로컬 컴퓨터 화면에 나타나는 것은 아닙니다. [한영 업그레이드 안내](../migrations/v0.1.11-to-v0.2.0.md)를 참고하세요. 앱은 ad-hoc 서명이며 Developer ID 서명·공증되지 않아 Gatekeeper 승인이 필요할 수 있습니다. 로컬 관찰 최소 Herdr 0.9.0+가 `client.attached` 또는 `worktree.remove` 지원을 뜻하지 않습니다. 자동 시작에는 [패치된 호스트](../../integrations/herdr/README.md)가, 원격 관찰·로컬 답장에는 각각 호환 전달 CLI/서버·`agent.prompt`가 별도로 필요합니다. 순정 0.9.3 관찰이 모든 0.9.0 API 지원을 증명하지 않습니다. 답장 전달 확인은 작업 완료가 아니므로 불확실하면 확인 후 수동 재시도하세요.

변경 불가한 beta3의 검사·AppKit 실험·게시 자산·베타 설치 근거는 **beta3에만** 해당하며 안정판 패키지·포뮬러·게시 증거로 바꾸어 쓰지 않습니다. 사용자는 원격 Mac에서 실행한 창을 로컬 화면에서 찾았던 오해를 바로잡은 뒤 beta3가 작동한다고 확인했습니다. 이것은 물리 키보드 포커스·실제 IME·이미지 선택/확인 창 키·포인터·VoiceOver 인증이 아닙니다. 안정판 빌드·패키지·실행/API·Homebrew 결과는 별개로 기록해야 합니다.

**태그 고정 전 새 안정판 소스 검증:** TypeScript·Bun **44개/기대값 355개**, 변경 범위 Rust 형식 검사, arm64 release 검사·빌드·테스트 **343개**(주 테스트 342개 + 제한시간 FIFO child 1개)가 통과했습니다. 실제 메인 스레드 AppKit 입력창 executable의 두 스크롤러 스타일·Unicode 삽입·선택·조합 경계도 통과했습니다. 새 `HerdrDesktopPet.app`과 별도 로컬 압축 해제본의 arm64·`0.2.0`·엄격한 심층 서명을 확인했습니다. 설정·상태를 격리한 실제 앱은 전용 순정 Herdr 0.9.3에서 UI/control ready·등록 수락·데이터 연결에 도달했고 hide/show 시 활성 말풍선 유지 후 종료했습니다. CLI 심볼릭 링크의 내장 `default@0` 내보내기(28,048,065바이트)와 실제 1024×1024 rig 프리뷰 렌더링·시각 확인도 통과했습니다. 실제 Wiki 생성기는 새 릴리스·0.2 계열·업그레이드 페이지를 포함한 **23페이지**를 생성했습니다. 이는 로컬 태그 고정 전 증거이며 CI 공개 자산 다운로드·Release/latest·Homebrew 설치 검증은 게시 후 확인할 별도 항목으로, 이 고정 노트에 이미 있었던 결과로 주장하지 않습니다.
