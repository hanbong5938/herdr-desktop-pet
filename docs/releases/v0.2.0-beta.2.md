# Herdr Desktop Pet v0.2.0-beta.2 release notes

**Opt-in manual macOS UI test, not a stable release.** The selected isolated snapshot uses app version `0.2.0-beta.2` and tag `beta/0.2.0-beta.2`; the original working-copy manifests remain `0.1.11`. On Apple Silicon with macOS 13+, get `HerdrDesktopPet-v0.2.0-beta.2-macos-arm64.tar.gz`, its `.sha256`, and `SHA256SUMS` from the [beta2 prerelease page](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.2), verify SHA-256 before extraction, then run the separately named `HerdrDesktopPetBeta.app`. This beta bundle is ad-hoc signed, **not notarized**; Gatekeeper may require explicit approval. Alternatively install `brew install hanbong5938/tap/herdr-desktop-pet-beta` and use `herdr-desktop-pet-beta`; existing beta-formula users should run `brew update && brew upgrade herdr-desktop-pet-beta`. The beta formula installs into Homebrew's prefix, not `/Applications`. Public `main`, stable v0.1.11 and its assets, latest, the stable Homebrew formula, original working-copy manifests, and default/`--prebuilt` installation remain unchanged. Stable `0.2.0` has not shipped. The immutable [beta1 prerelease](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.1) still contains the reported clipping/scanner bugs; its source commit `6749439657f73ea6882b769f4a9968f637f8d6d4` and its publication/asset checks belong **only to beta1**.

## Changes

The following capabilities from beta1 are carried forward in beta2; they are not newly attributed to the beta2 fixes or to stable v0.1.11:

- Watcher/startup: standalone and remote-only observation starts without waiting for a local source; lifecycle policy stays separate from local observation. Client-attach auto-start still requires a separately patched Herdr host: stock 0.9.0/0.9.3 do **not** provide `client.attached`.
- Independent visibility: character and bubble can be hidden separately; a visible bubble detaches as a movable panel and reattaches when the character returns. Full-window click-through affects both windows; alpha click-through affects character artwork only. Standalone origin is saved separately, reset preserves visibility, and active IME composition defers origin updates.
- Observation settings: compact local/remote source controls preserve saved remote selections and keep remote cards read-only.
- Context/recovery: character and bubble context menus open the full Settings panel; the bubble can be closed independently, retaining run-local drafts. Historical conditional rescue behavior is selectable: **Always show** (default) or **Only when recovery is needed**. Recovery can show/enable the character without changing bubble visibility.
- Menu image: select a static PNG for the menu-bar icon, or restore the default template pawprint. Imported private managed assets persist without the original source; PNG validation checks chunk CRCs, zlib Adler-32 and inflated scanline size. Restore removes only the owned icon choice and asset, preserving unrelated and unknown preferences.
- Linked-worktree removal: only coherent live local linked-worktree cards offer **Remove Worktree…**; main roots, remote, retained, offline, and ambiguous cards do not. Confirmation defaults to Cancel. The client revalidates before one asynchronous `worktree.remove` request with `force: false`, without shell fallback, forced deletion or automatic retry. The request identifies only `workspace_id`, so revalidation is **not** an atomic guarantee against server rebinding. A backend lacking this method reports unsupported rather than silently deleting by another route.
- Four earlier P2 corrections: scoped alert Escape invokes actual Cancel independently of the default Return button; deferred standalone origin uses saved position or actually applied attached geometry with the latest scene/reset taking precedence after composition; generated Markdown URLs encode literal parentheses without double-encoding; shared/nested link and image references preserve link destinations and retarget only images, including multiline titles. Invalid definitions remain prose and valid inline destination/title spans are excluded from reference scanning.

**Beta2 fixes relative to immutable beta1:**

- Reply-input glyph clipping: Legacy and Overlay reserve a full native text line plus border/scroller chrome, propagating measured height through reply row, card and bubble. For the reported Legacy draft, observed outer/clip/document heights changed from **22/3/5 to 43/24/24 pt**, accommodating the 16 pt line through ancestor clipping. Document width and bounded horizontal scroll reset on long → short/empty edits without rewriting draft or UTF-16 selection; composition defers geometry commits, and compact optional spacing keeps selected reply and main message visible when screen space allows. Prior production AppKit source observation preserved editor identity, draft, selection and affinity across hide/show/reset/placement, marked-text callbacks and native replacement; raster output showed glyphs. The 260 pt height fixture is process-local, **not** physical-monitor evidence.
- Markdown Release/Wiki scanner: before masking or resolving an outer candidate, recognize complete inline syntax and nested real bracket-link precedence. A malformed outer title or outer link invalidated by an inner inline/defined-reference link no longer hides legitimate inner links/images from rewriting and path preflight. Undefined bracket text does not invalidate a valid outer link. Existing URL/title image-like text, supported angle destinations, and mixed image-in-link references remain protected. Prior offline production Release/current Wiki/frozen Wiki CLI checks covered tagged/mapped Guide links, raw Art images, missing or escaping targets and byte/mtime-preserving failures; they did **not** publish a new Release.

## Evidence and outstanding manual checks

**Fresh isolated beta2 source gates:** TypeScript check and **44 Bun tests / 355 expectations** passed; native arm64 release check/build and **343 total tests** passed (342 main tests plus one bounded FIFO child), separately from the actual main-thread AppKit composer executable. Scoped changed-file rustfmt passed; the earlier full-workspace check flagged four untouched existing files. Earlier production AppKit/raster observations and managed-image restoration remain separate evidence, not physical input. **Keyboard focus, real IME, alert Return/keypad Enter/Escape/Delete, picker Cancel/valid/corrupt selection, pointer gestures and VoiceOver remain unverified.** Test these on an interactive desktop.

**Packaged-archive proof before publication:** The exact `HerdrDesktopPet-v0.2.0-beta.2-macos-arm64.tar.gz` was independently extracted; arm64-only architecture, version `0.2.0-beta.2`, deep/strict ad-hoc signature and bundled rig/default@0 resources passed. Its SHA-256 is `ddb61fa2ff45aa0fcc603c175423667512b7fa043461b6ab5e9f2c37576a6432` (20,467,673 bytes). The extracted daemon reached UI/control/registration/data readiness against an owned Herdr 0.9.3 backend using isolated config and state. Actual hide/show retained enabled bubble visibility; a symlinked CLI exported the bundled default pack. These are packaging/startup/control/resource-closure checks, not physical GUI proof. Publication uses an opt-in prerelease, **not draft or latest**, with archive, `.sha256` and `SHA256SUMS`; public upload and rolling beta-formula upgrade are checked separately after publication. This beta tag does not trigger the stable `v*` Release/Wiki workflow, and this note exists only in the isolated beta source.

Before beta start, quit stable and back up the real configuration and state, including `preferences.json`, `lifecycle.json`, `characters/` and managed `menu-bar-icons/`. Unless explicitly isolating configuration **and** state, both apps share profile and control namespace: never run them together. To roll back, quit beta, restore the backup, then restart stable; downgrade compatibility of beta-written data is not guaranteed. For deletion testing use **only a disposable linked worktree**: ignored files may be removed and running processes, panels or workspace state affected. Check cancellation makes zero requests and deliberately confirmed removal targets the intended checkout; never test with a valuable checkout. ### 변경 사항

아래 기능은 beta1에서 beta2로 이어진 기존 기능이며 beta2 수정 또는 안정판 v0.1.11의 새 기능으로 해석하지 마세요.

- watcher/시작: 로컬 소스 없이 독립 실행·원격 전용 관찰을 시작하며 로컬 관찰 설정과 실행 정책을 구분합니다. client-attach 자동 시작은 별도의 패치 호스트가 필요하고 순정 Herdr 0.9.0/0.9.3의 `client.attached`를 가정하지 않습니다.
- 독립 표시: 캐릭터와 말풍선을 각각 숨기고, 말풍선만 보이면 이동 가능한 독립 패널이 됩니다. 전체 창 클릭 통과는 두 창, 알파 클릭 통과는 캐릭터 그림만 적용됩니다. 위치 저장·초기화는 표시 상태와 독립이며 IME 조합 중 위치 확정을 보류합니다.
- 관찰 설정: 간결한 로컬/원격 선택 UI가 원격 저장 선택을 유지하고 원격 카드는 읽기 전용으로 둡니다.
- 문맥 메뉴·복구: 캐릭터·말풍선 메뉴에서 전체 설정을 열고 말풍선만 닫을 수 있습니다. 실행 중 초안은 유지됩니다. 원래 조건부 복구를 **항상 표시**(기본값)/ **복구가 필요할 때만** 모드로 선택하며 말풍선 표시를 바꾸지 않고 캐릭터 조작을 복구합니다.
- 메뉴 막대 PNG: 정적 이미지를 선택하거나 기본 템플릿 아이콘으로 복원합니다. 관리 사본은 외부 원본 삭제 후에도 유지되고 PNG CRC·Adler-32·스캔라인 길이를 검증합니다. 복원은 소유 이미지와 해당 설정만 지우고 나머지 설정을 보존합니다.
- 연결 워크트리 삭제: 현재 유효한 로컬 연결 워크트리에만 제공하며 메인 루트·원격·보관·오프라인·모호한 대상은 제외합니다. 확인 창의 기본값은 취소이고 새 스냅샷 재검사 뒤 `{workspace_id, force: false}` 요청 하나만 비동기로 보냅니다. 셸 우회·강제 삭제·자동 재시도는 없습니다. `workspace_id`만 전달하므로 재검사는 서버 재연결에 대한 원자적 보장이 아니며 미지원 서버는 미지원을 알립니다.
- 이전의 네 가지 P2 수정: 한정된 Escape 처리가 기본 Return 버튼과 독립적으로 실제 취소를 실행합니다. 보류 단독 위치는 저장 위치나 실제 적용된 부착 위치를 쓰고 조합 종료 후 최신 장면·초기화를 우선합니다. 생성 Markdown URL의 리터럴 괄호만 인코딩하며 중복 인코딩하지 않습니다. 링크/이미지 공유 참조는 중첩·여러 줄 제목에서도 링크 대상을 유지하고 이미지만 바꿉니다. 잘못된 정의는 일반 문장으로 두고 정상 인라인 대상·제목은 참조 스캔에서 제외합니다.

**고정된 beta1 대비 beta2 수정:**

- 답장 입력 글자 잘림: Legacy/Overlay에서 네이티브 텍스트 한 줄과 테두리·스크롤러 공간을 확보하고 측정 높이를 답장 행·카드·말풍선에 전달합니다. 보고된 Legacy 초안의 외부/clip/문서 높이는 기존 **22/3/5 → 43/24/24 pt**로 관찰되어 상위 clipping 범위에서도 16 pt 한 줄을 확보했습니다. 긴 글 → 짧은 글/빈 글의 문서 폭·가로 스크롤을 초안·UTF-16 선택을 다시 쓰지 않고 정리합니다. IME 조합 중 배치를 보류하고 화면이 허용하면 선택 답장·주 메시지를 확보합니다. 앞선 production AppKit 소스 관찰에서 숨김·표시·초기화·배치와 native 입력 후 초안·선택·affinity가 유지되고 raster에서 글자가 보였습니다. 260 pt 화면 높이는 **프로세스 내부 fixture**이지 실제 모니터 확인이 아닙니다.
- Markdown Release/Wiki 스캐너: 외부 후보를 마스킹하거나 처리하기 전에 온전한 인라인 구문과 내부의 실제 bracket 링크 우선순위를 판정합니다. 잘못된 외부 괄호 제목이나 내부 inline/정의된 reference 링크로 무효인 외부 링크가 유효한 내부 링크·이미지를 변환·경로 검사에서 가리지 않습니다. 미정의 bracket 텍스트는 정상 외부 링크를 무효화하지 않으며 URL·제목의 이미지 모양 문자, angle destination, 이미지-in-link 혼합 참조를 보존합니다. 앞선 오프라인 production Release·current/frozen Wiki CLI 검사는 Guide 태그·매핑 링크, Art raw 이미지, 누락·저장소 밖 경로 거부와 기존 출력 바이트·mtime 유지를 다뤘지만 **새 Release를 게시한 검사는 아닙니다**.
