# Herdr Desktop Pet v0.3.2 release notes

[Versions](README.md) · [0.3 release line and bilingual upgrade](0.3.md) · [CLI contract](../cli.md)

## English

v0.3.2 is the stable source/default-prebuilt target for the integrated 0.3 line. Publication requires the exact non-draft, non-prerelease GitHub Release and complete arm64 archive, individual checksum and `SHA256SUMS`; source versions and tags alone do not publish a binary.

### Included capabilities

- Session search/status filtering, Stable/Name/Source sorting and independent Running first; native automation CLI; conflict-aware dialogue drafts with explicit reload/rebase.
- Eight-way bubble resizing, contextual Settings and independent character/bubble visibility; installed/official character browser with explicit verified Download & Apply; the v0.2.1 Arin compatibility fix.
- Installation-aware protocol-2 updates: read-only automatic/manual checks, explicit native consent, guarded rebuild/upgrade/apply and durable standalone recovery. No silent installation, beta switch, Git pull/reset or uncertain manager replay.
- Rig decoding JIT entitlement is confined to the worker, not the app or updater helper.

The [frozen v0.3.0 source note](v0.3.0.md) records the detailed inherited contract and scoped implementation evidence. Old tags/beta assets, character-pack v5, bundled `default@0`, artwork and licensing remain unchanged.

### Publication repair

[v0.3.0's workflow](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37824652666) failed twice at the dialogue-list deadline fixture before publishing assets. v0.3.1 fixed that fixture, which [passed in its workflow](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37827243595), but the adjacent mutation deadline fixture then failed on the same short first-poll assumption. Both versions remain immutable tag-only snapshots, not published binary releases.

v0.3.2 applies the same scheduling repair to the mutation fixture: a two-second poll window, with the terminal response delayed beyond it. Both regressions still require deadline rejection and exactly one request followed by one status query; operation identity remains fixed. No test is skipped and no shipping runtime deadline, polling or retry behavior changes. Neither failed tag is rewritten.

### Candidate verification

The v0.3.2 candidate passed TypeScript; 56 Bun tests / 477 expectations; 588 native tests including the isolated FIFO child (one ignored); 29 coordinator tests; release build/package, shell syntax and stable-note/version validation. Strict app/helper signatures and updater protocol 2 passed, with JIT entitlement only on `rig-decode-worker`.

The actual packaged app started in an isolated existing profile and reported `app_version: 0.3.2`, UI/control ready, accepted Herdr registration and connected data. Dialogue listing returned built-in Rubelia, English preferences were retained and normal stop succeeded. These are programmatic runtime checks, not physical keyboard/IME, notarization or a completed user Homebrew upgrade.

### Upgrade and limits

Follow [0.3 upgrade guidance](0.3.md#upgrade-from-v021-or-beta). Stop the old daemon and back up the actual config and state directories before replacing the binary. Preserve imported characters, preferences and saved dialogue; memory-only drafts do not survive restart. Protocol-1 updater records are not silently migrated, deleted or replayed. Confirm CLI `--version` and the restarted daemon's `app_version`/executable. Homebrew availability depends on the separately updated stable formula and complete published assets. The macOS arm64 package uses ad-hoc signing, not notarization or an official Developer ID signature.

## 한국어

v0.3.2는 통합된 0.3 계열의 안정판 소스·기본/사전 빌드 대상입니다. 실제 출시는 비초안·비프리릴리스 GitHub Release와 arm64 압축 파일·개별 체크섬·`SHA256SUMS`의 완전한 게시로 판단합니다. 소스 버전·태그만으로 게시를 주장하지 않습니다.

세션 검색·상태 필터·정렬·실행 중 우선, 네이티브 자동화 CLI, 충돌 인식 대사 초안, 8방향 말풍선 크기·문맥 설정·독립 표시, 공식 캐릭터 브라우저의 명시적 검증 다운로드·적용, 설치 출처별 protocol-2 업데이트·복구와 worker 전용 JIT를 포함합니다. v0.2.1 Arin 호환성을 유지하고 확인만으로 설치·재시작·베타 전환·Git 갱신을 하지 않습니다. 상세 기능과 기존 소스 검증 범위는 [동결된 v0.3.0 노트](v0.3.0.md)를 참고하세요.

v0.3.0 workflow는 dialogue-list deadline fixture에서 두 번 실패했습니다. v0.3.1의 수정된 테스트는 CI에서 통과했지만 인접 mutation deadline fixture가 같은 짧은 첫 poll 가정으로 실패했습니다. 두 버전은 자산이 게시되지 않은 태그로 보존합니다. v0.3.2는 mutation fixture에도 2초 poll 여유·그 이후 terminal 응답을 적용합니다. deadline 실패와 request 한 번·status 한 번 검증, operation identity를 유지하며 테스트를 건너뛰거나 실제 앱의 deadline·poll·재시도 동작을 바꾸지 않습니다. 기존 태그를 덮어쓰지 않습니다.

[한영 이전 안내](0.3.md#한국어--v03-계열)에 따라 기존 데몬을 먼저 종료하고 실제 설정·상태를 백업하세요. 가져온 캐릭터·설정·저장 대사는 유지하지만 메모리 초안은 재시작 후 유지되지 않습니다. 구형 protocol-1 기록은 자동 이전·삭제·재실행하지 않습니다. CLI 버전뿐 아니라 재시작한 데몬의 `app_version`·실행 파일을 확인하세요. 안정판 Homebrew 포뮬러는 실제 자산 게시 후 별도 갱신하며 베타 포뮬러·기존 베타 자산·팩 v5·`default@0`·그림·라이선스는 유지합니다. 배포는 macOS arm64 ad-hoc 서명이며 공인 Developer ID 서명·notarization은 아닙니다.

v0.3.2 후보에서 TypeScript, Bun 56개·477 expectations, 네이티브 588개(FIFO 자식 포함·1개 ignored), coordinator 29개, release 빌드·패키징, 설치기 문법·버전/노트 검사가 통과했습니다. 앱·도우미 strict 서명과 protocol 2, worker 전용 JIT를 확인했습니다. 실제 패키지 앱을 격리된 기존 프로필에서 실행해 `app_version: 0.3.2`·UI/control ready·Herdr 등록·데이터 연결, 루벨리아 대사 대상·영어 설정 유지·정상 종료를 확인했습니다. 이는 프로그램 방식 런타임 증거이며 물리 입력·실제 IME·notarization·사용자 Homebrew 업그레이드 완료 인증은 아닙니다.
