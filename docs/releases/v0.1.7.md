# Herdr Desktop Pet v0.1.7 release notes

## Summary

This historical page is reconstructed from the published [v0.1.7 Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.1.7) and contemporaneous tagged documentation. The Release page supplies its published assets and publication information; this reconstruction does not run or certify a new build.

v0.1.7 fixes bundled-resource lookup when the packaged CLI is launched through a symlink on `PATH`. It retains [v0.1.6's inline replies, approved Rubelia redraw, lifecycle, dialogue, status, remote observation, and pack behavior](v0.1.6.md), without releasing a new Herdr host or changing the character-pack format.

## Fixed and distribution changes

- Resolve the running executable through symlinks **before locating `Contents/Resources`**. A linked CLI therefore uses the bundled Rubelia default instead of failing against a build-machine assets path. The historical release workflow includes a packaged-CLI smoke probe through a symlink.
- The tagged installer downloads its manifest-pinned prebuilt anonymously over HTTPS with `curl` and validates SHA-256, archive layout/types, arm64 architecture, code signature, and the default character. An optionless install falls back to a source build only if the prebuilt is unavailable or invalid; explicit `--prebuilt` never falls back. Explicit `--source` builds checkout changes. Normal prebuilt use needs no GitHub login, `gh`, or source-build toolchain; source builds need Rust, Bun, Node.js/npm, and Xcode Command Line Tools.
- The Homebrew formula keeps the app in Homebrew's prefix and exposes the CLI on `PATH`, rather than the previous cask's `/Applications` location. Homebrew installs only the app/CLI: it neither registers the Herdr plugin nor installs a patched host. Previous cask users remove the cask, then install the formula; uninstalling keeps packs, preferences, and lifecycle state. See the [current English installation guide](../../readme.md#install-with-homebrew) or [Korean guide](../../readme.ko.md#homebrew로-설치) for operating commands.

## Upgrading and compatibility

No new data or character-pack migration is stated for this fix. `default@0` and existing imported selections remain unchanged. Coming from v0.1.4, use the [v0.1.4 → v0.1.6 migration](../migrations/v0.1.4-to-v0.1.6.md): **Enter now sends, not inserts a newline**; committed line breaks become spaces. Escape cancels active IME composition first, otherwise folds only the reply. Remote cards are read-only, and prompts use only local `agent.prompt`. ACK means accepted, not completed work; check uncertain delivery before resending, with no automatic retry. Drafts remain in memory only, not across restart.

- **Apple Silicon macOS 13+ only.** No native Windows distribution or accessibility-based click-routing support is claimed; Intel Mac/Linux are not supported by the native distribution. Alpha click-through remains pointer-polled, not a guarantee against click-routing races.
- Bundles remain ad-hoc signed, **not Developer ID signed or notarized**. The tagged guide reports no quarantine attribute for curl/git/formula installs; browser-downloaded archives may still need explicit macOS approval. Installation convenience does not change the signing/security boundary.
- App manifest version 0.1.7 pins this app release. `min_herdr_version = 0.9.3` remains the **patch baseline, not proof of `client.attached`**. Client-attach auto-start requires official Herdr 0.9.3 source with the supplied patch applied and built, or an actual future host release advertising that hook. Stock Herdr 0.9.0/0.9.3 do not implement it. Inspect plugin-link warnings and verify subscription using the [host integration guide](../../integrations/herdr/README.md). This fix does not upgrade, install, or publish that host.
- Local observation still supports Herdr 0.9.0+. Prompt support is a separate API capability reported verified with 0.9.2, and remote observation needs a compatible saved-machine forwarding CLI (documented in 0.9.2) plus compatible remote server. The resource fix does not widen these independent host requirements.
- The original scoped caveat remains: pre-existing native clippy all-target `erasing_op` was out of scope. Historical AppKit/marked-text probes from v0.1.6 do not establish physical-keyboard IME behavior or OS-granted focus transfer in v0.1.7.

### 한국어 요약

v0.1.7은 `PATH`에 심볼릭 링크로 연결한 CLI가 실제 실행 파일을 따라가 앱의 `Contents/Resources`에서 기본 루벨리아를 찾도록 고칩니다. v0.1.6의 인라인 답장·새 그림·팩 형식과 기존 선택은 유지합니다. v0.1.4에서 옮긴다면 **Enter가 줄바꿈에서 전송으로 바뀌는 점**을 먼저 확인하세요. IME 조합 중에는 전송하지 않고 Escape는 조합 취소를 우선한 뒤 답장칸만 접습니다. 원격 카드는 읽기 전용이며 ACK는 처리 완료가 아닙니다. 전달이 불명확하면 실제 세션을 확인한 뒤 재전송하세요. 자동 재시도나 재시작 후 초안 복원은 없습니다.

Apple Silicon macOS 13+용이며 ad-hoc 서명이고 공증되지 않았습니다. 브라우저로 받은 파일은 macOS의 명시적 실행 승인이 필요할 수 있습니다. 기본 설치는 사전 빌드가 없거나 검증에 실패할 때만 소스 빌드로 전환하고, `--prebuilt`는 전환하지 않습니다. 소스 빌드에는 별도 도구가 필요합니다. 기존 cask는 제거 후 formula로 옮기며 사용자 데이터는 유지됩니다. Homebrew는 앱/CLI만 설치하고 플러그인 등록이나 패치된 Herdr 설치를 하지 않습니다. 클라이언트 attach 자동 실행에는 제공된 패치를 적용·빌드한 공식 Herdr 0.9.3 또는 실제 훅 지원을 명시한 후속 호스트가 필요합니다. 순정 0.9.0/0.9.3이나 매니페스트 최소 버전은 지원 증거가 아니므로 연결 경고와 구독 수락을 확인하세요. 로컬 관찰 기준과 메시지 API·원격 전달 호환성도 별개입니다.
