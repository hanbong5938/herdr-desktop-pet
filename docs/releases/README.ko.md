**소스와 게시 상태는 다른 기준입니다.** 이 체크아웃은 v0.3.1 안정판 소스·기본/사전 빌드 대상으로 설정되며 Arin 호환성 패치가 있는 공개 v0.2.1(앱 v0.2.1 이상 필요)을 유지합니다. 검색·정렬, 자동화, 초안, 말풍선 크기, 공식 브라우저, protocol-2 업데이트와 worker JIT는 v0.3.1에 속하며 이전 v0.2.1·변경 불가 베타 바이너리에 소급 적용되지 않습니다. `--source`는 보유한 체크아웃을 빌드하고 기본/`--prebuilt`의 v0.3.1 성공 설치는 실제 비초안 Release·완전 업로드 자산·갱신된 설치기로 확인해야 합니다. [v0.3.1 노트](v0.3.1.md)·[한영 이전 안내](0.3.md#한국어--v03-계열)를 참고하세요. [과거 Unreleased 기록](unreleased.md)은 당시 소스·베타 증거이지 새 공개 v0.3.1 검증이 아닙니다.

생성된 Wiki의 릴리스 상태는 GitHub의 실제 Release 목록과 모두 업로드된 자산으로 판단하며 문서 파일이나 태그만으로 게시 완료를 판단하지 않습니다. 이 탐색 문서는 실시간 API 상태표가 아니며 안정판 압축 파일의 실제 게시 증거도 아닙니다. 과거 0.1 계열의 **v0.1.5는 태그만 있고 공개 바이너리가 없습니다.**

## 게시와 과거 기록

새 릴리스는 정확한 릴리스 태그의 검토된 `docs/releases/vX.Y.Z.md`를 Wiki 버전 페이지와 새 GitHub Release 본문의 공통 원본으로 사용합니다. [게시 절차](publishing.md)와 [호환성 정책](policy.md)을 참고하세요.

v0.1.4–v0.1.11 태그에는 이 문서 트리가 없었습니다. 따라서 과거 노트는 당시 근거를 바탕으로 현재 소스에서 재구성한 문서이며, 과거 태그의 원본과 실제 Release를 연결합니다. 과거 태그·배포 파일·Release 본문을 다시 쓰지 않습니다. 과거 검증 내용은 당시 보고된 근거이지 이 문서 작업에서 새로 실행한 검증이 아닙니다.

## 업그레이드 안전 요약

v0.3.1으로 옮길 때는 기존 데몬을 먼저 종료하고 [0.3 한영 이전 안내](0.3.md#한국어--v03-계열)와 [v0.3.1 노트](v0.3.1.md)를 확인하세요. 공개 압축 파일·체크섬 및 설치기/포뮬러 게시 전에는 v0.3.1 사전 빌드 설치를 가정하지 마세요. 이전 v0.1.11 → v0.2.0 전환은 [과거 한영 안내](../migrations/v0.1.11-to-v0.2.0.md), Arin 수정은 [v0.2.1 패치](v0.2.1.md)에서 확인할 수 있고 Arin 가져오기는 앱 v0.2.1 이상이 필요합니다. 설정·상태를 백업하고 베타와 안정판을 병행하려면 둘 다 격리하세요. `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/` 및 updater 기록을 보존하세요. 원격 카드는 읽기 전용이고 초안은 실행 중 메모리에만 남습니다. `client.attached` 자동 시작과 워크트리 삭제에는 실제 호스트 기능이 필요하며 최소 버전 숫자만으로 보장되지 않습니다.
