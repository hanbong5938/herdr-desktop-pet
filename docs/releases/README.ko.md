**소스와 게시 상태는 다른 기준입니다.** `main`의 v0.2.0 소스에는 이전 베타의 네이티브 기능 묶음과 후속 수정이 포함됩니다. `bash scripts/install.sh --source`는 현재 체크아웃을 빌드하며 기본/사전 빌드 설치는 안정판 v0.2.0에 고정됩니다. 별도 beta1/beta2/beta3 태그와 배포 파일은 과거 기록으로 남습니다. [v0.2.0 노트](v0.2.0.md)와 [이전 안내](../migrations/v0.1.11-to-v0.2.0.md)가 안정판 동작을 설명하며 [예전 Unreleased 기록](unreleased.md)은 당시 로컬/베타 소스의 이력이지 지금 `main`의 범위가 아닙니다.

생성된 Wiki의 릴리스 상태는 GitHub의 실제 Release 목록과 모두 업로드된 자산으로 판단하며 문서 파일이나 태그만으로 게시 완료를 판단하지 않습니다. 이 탐색 문서는 실시간 API 상태표가 아니며 안정판 압축 파일의 실제 게시 증거도 아닙니다. 과거 0.1 계열의 **v0.1.5는 태그만 있고 공개 바이너리가 없습니다.**

## 게시와 과거 기록

새 릴리스는 정확한 릴리스 태그의 검토된 `docs/releases/vX.Y.Z.md`를 Wiki 버전 페이지와 새 GitHub Release 본문의 공통 원본으로 사용합니다. [게시 절차](publishing.md)와 [호환성 정책](policy.md)을 참고하세요.

v0.1.4–v0.1.11 태그에는 이 문서 트리가 없었습니다. 따라서 과거 노트는 당시 근거를 바탕으로 현재 소스에서 재구성한 문서이며, 과거 태그의 원본과 실제 Release를 연결합니다. 과거 태그·배포 파일·Release 본문을 다시 쓰지 않습니다. 과거 검증 내용은 당시 보고된 근거이지 이 문서 작업에서 새로 실행한 검증이 아닙니다.

## 업그레이드 안전 요약

v0.1.11 또는 beta3에서 안정판으로 이동할 때는 실행 중인 데몬을 먼저 종료하고 [v0.1.11 → v0.2.0 한영 이전 안내](../migrations/v0.1.11-to-v0.2.0.md)를 읽으세요. beta와 안정판을 동시에 사용하려면 설정·상태 디렉터리를 둘 다 격리해야 하며, 백업에는 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`가 포함됩니다. 캐릭터·말풍선 표시가 독립적이며 전체 창 클릭 통과는 두 창, 투명 영역 클릭 통과는 캐릭터 그림에만 적용됩니다. 기본 메뉴 막대 아이콘은 항상 표시되고 조건부 복구는 선택 사항입니다. 대화창 닫기는 앱·Herdr 세션 종료가 아니고 답장 초안은 현재 실행에만 남습니다. 원격 카드는 읽기 전용이며 로컬 표시 관찰을 꺼도 실행 관리 정책은 유지됩니다. `client.attached` 자동 시작과 워크트리 삭제에는 각각 실제 호스트 기능이 필요하며 최소 버전 숫자만으로 보장되지 않습니다.
