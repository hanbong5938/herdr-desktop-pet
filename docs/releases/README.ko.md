**어느 소스인지 구분해야 합니다.** 앱 버전은 **0.1.11**로 유지합니다. 문서·게시 도구는 `main`에 있지만 [Unreleased](unreleased.md)의 네이티브 네 묶음은 로컬 `worktree/rapid-harbor-d2a6`의 `bf23ced1649fd0074aec8736644c8f02aa0c492b`에만 구현되어 있으며 `main`이나 공개 v0.1.11 바이너리에 포함되지 않습니다. 이 체크아웃을 공개 원격에서 가져올 수 있다는 보장은 없고 릴리스 버전·다운로드도 지정하지 않았습니다. 옵션 없는 설치는 매니페스트에 고정된 사전 빌드를 사용하며 `bash scripts/install.sh --source`는 이미 가지고 있는 체크아웃을 빌드합니다. `main`에서 이 명령을 실행해도 네이티브 미리보기 기능은 **제공되지 않습니다**. 기준 앱의 소스 설치는 루트 안내를 따르고, 미병합 업그레이드 안내는 해당 로컬 구현을 이미 가지고 있을 때만 사용하세요.

Wiki의 릴리스 상태는 GitHub 릴리스 목록과 실제로 완전히 업로드된 자산으로 생성합니다. 문서 파일이나 태그가 있다는 이유만으로 공개 완료라고 판단하지 않습니다. 이 안내는 실시간 API 상태표가 아닙니다. 특히 **v0.1.5는 태그만 있으며 공개 바이너리는 없습니다.**

## 게시와 과거 기록

새 릴리스는 정확한 릴리스 태그의 검토된 `docs/releases/vX.Y.Z.md`를 Wiki 버전 페이지와 새 GitHub Release 본문의 공통 원본으로 사용합니다. [게시 절차](publishing.md)와 [호환성 정책](policy.md)을 참고하세요.

v0.1.4–v0.1.11 태그에는 이 문서 트리가 없었습니다. 따라서 과거 노트는 당시 근거를 바탕으로 현재 소스에서 재구성한 문서이며, 과거 태그의 원본과 실제 Release를 연결합니다. 과거 태그·배포 파일·Release 본문을 다시 쓰지 않습니다. 과거 검증 내용은 당시 보고된 근거이지 이 문서 작업에서 새로 실행한 검증이 아닙니다.

## 업그레이드 안전 요약

로컬 `worktree/rapid-harbor-d2a6`의 미병합 구현을 이미 가지고 있다면 빌드하기 전 [한국어 미병합 체크아웃 업그레이드 안내](../migrations/unreleased.ko.md)를 읽으세요. 다음 독립 표시·복구 동작은 `main`/공개 v0.1.11 기능이 아닙니다. 해당 로컬 구현에서는 캐릭터 숨김과 대화창 숨김이 독립적이고 전체 클릭 통과는 두 창에, 알파 클릭 통과는 캐릭터 그림에만 적용합니다. 공개 기준에서도 대화창 닫기는 앱·Herdr 세션 종료가 아니며 답장 초안은 현재 실행 중에만 유지하고 재시작 후 복원하지 않습니다. 원격 카드는 관찰 전용입니다. 로컬 관찰을 끄는 것은 표시 데이터를 제외하는 것이지 로컬 플러그인 비활성화·연결 해제에 따른 종료 정책을 끄는 것이 아닙니다. Herdr 버전 번호만으로 호스트 기능을 보장하지 않으며 `client.attached` 자동 시작에는 연동 안내의 패치된 호스트가 필요합니다.
