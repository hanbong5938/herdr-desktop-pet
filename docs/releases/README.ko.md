**소스와 게시 상태는 다른 기준입니다.** 이 체크아웃은 v0.3.5 안정판 소스·기본/사전 빌드 대상이며 [v0.3.4 눈 소유권·ABI·출처 기록](v0.3.4.md), [v0.3.3 수정](v0.3.3.md)·[v0.3.2 기능](v0.3.2.md)·v0.2.1 Arin 호환성 수정을 유지합니다. [한영 노트](v0.3.5.md)는 포인터 캡처 복구·부착 말풍선 배치·IME 답장 동작을 설명합니다. `--source`는 현재 소스를 빌드하고 기본/`--prebuilt` 설치에는 정확한 비초안 v0.3.5 Release·완전한 자산·설치기/포뮬러 전환이 필요합니다. 소스 노트나 과거 [Unreleased 기록](unreleased.md)은 게시 증거가 아닙니다.

생성된 Wiki의 릴리스 상태는 GitHub의 실제 Release 목록과 모두 업로드된 자산으로 판단하며 문서 파일이나 태그만으로 게시 완료를 판단하지 않습니다. 이 탐색 문서는 실시간 API 상태표가 아니며 안정판 압축 파일의 실제 게시 증거도 아닙니다. 과거 0.1 계열의 **v0.1.5는 태그만 있고 공개 바이너리가 없습니다.**

## 게시와 과거 기록

새 릴리스는 정확한 릴리스 태그의 검토된 `docs/releases/vX.Y.Z.md`를 Wiki 버전 페이지와 새 GitHub Release 본문의 공통 원본으로 사용합니다. [게시 절차](publishing.md)와 [호환성 정책](policy.md)을 참고하세요.

v0.1.4–v0.1.11 태그에는 이 문서 트리가 없었습니다. 따라서 과거 노트는 당시 근거를 바탕으로 현재 소스에서 재구성한 문서이며, 과거 태그의 원본과 실제 Release를 연결합니다. 과거 태그·배포 파일·Release 본문을 다시 쓰지 않습니다. 과거 검증 내용은 당시 보고된 근거이지 이 문서 작업에서 새로 실행한 검증이 아닙니다.
