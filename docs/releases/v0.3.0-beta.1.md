## Changes beyond stable v0.2.0

- Native session Search trims the query and matches case-insensitive title/tab/workspace/agent/source names, full working directories and fallback names across retained visible observations. Search and status intersect before Stable/Name/Source ordering and the 128-card display cap. Running first is global across sources before sort/cap. Counts retain the full matching population; global status summary and reactions stay independent.
- Exact generation-qualified selection and in-memory drafts are retained. A hidden selected reply folds without deleting its draft; clearing Search does not reopen it. Search Enter/Command-Enter never sends. Escape cancels composition first, then clears a nonempty query, then leaves empty Search focus without collapsing the bubble. Sort/running-first save atomically; failed saves roll back controls and live options. Query/filter/selection/drafts are memory-only, and drafts do not survive restart.
- Either reply or Search composition defers structural attachment, mode, row-height and layout changes while live status/accessibility/send eligibility continue updating. Shared deferred reconciliation keeps latest intent. Guarded same-key/view attachment no longer changes row geometry or repairs an orphan during composition.
- Directory-name disambiguation walks borrowed suffix components only for colliding groups and retains the full naming universe before filtering/sorting/cap. The pre-integration canonical 100-agent protocol fixture measured 413,992,461 → 469,256 bytes peak extra Rust allocation; this historical source measurement is not a new beta RSS/latency benchmark.
- Release/Wiki generation uses actual definition/code boundaries, preserves nested links in undefined image ALT, handles empty-destination precedence, and clones mixed image references outside quote/list containers. Quoted bare filenames still resolve as paths, and an invalid next-line nested-parenthesis title leaves the valid destination-only definition active. Escapes, CRLF/UTF-16 positions and the existing adjacent angle/title inline dialect remain supported.
- Upstream native automation, bounded revision-aware pagination, primary menu-click Settings and rig bubble-attachment corrections are retained. Remote observation remains read-only; local replies require a compatible host API. Worktree removal remains destructive, single-request and without force/shell fallback or automatic retry.

These are source/package checks, **not** active/key-window Search IME, scheduled-timer attribution, simultaneous native owner or human pointer/keyboard acceptance.

The two additional Markdown preflight boundaries were reproduced through the real Release consumer before correction and observed rejecting the missing target after correction; Release/current/frozen Wiki regressions protect valid, missing and escaping paths. ## Install and test on the computer whose Desktop you will inspect

Use the separate rolling `hanbong5938/tap/herdr-desktop-pet-beta` formula only after `brew info` confirms `0.3.0-beta.1`, or use the verified manual archive. Do not use the stable formula/default installer to obtain this beta. Homebrew installs inside its prefix, not `/Applications`; its CLI is `herdr-desktop-pet-beta`.

Stop the existing daemon before replacement. Back up the actual profile, including preferences, lifecycle, imported characters and menu-bar icons. Stable and beta share their default profile/control namespace: isolate **both** config and state directories for concurrent comparison, and pass the same pair to start/status/stop. Verify the CLI version, then the running daemon's `status` `app_version` and executable path. CLI `--version` alone does not prove that an old daemon was replaced. The app launched on a remote Mac appears on that Mac's Desktop, not your local screen.
