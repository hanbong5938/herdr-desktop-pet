## Historical 0.3 source and publication evidence

v0.3.2 combines search/order, native CLI automation, conflict-aware dialogue drafts, eight-way bubble resizing, official character browser/explicit verified Download & Apply, installation-aware protocol-2 app updates and worker-only JIT decoding improvement, on top of the v0.2.1 Arin compatibility fix. The public v0.2.1 patch is a separate, frozen historical release; no old tag, binary, beta asset, artwork, rig format v5 or `default@0` is rewritten. See the [version note](v0.3.2.md) for behavioral and evidence limits.

v0.3.3 retains those capabilities and adds the focused single-official-card, remote 1024 × 1024 portrait within 4 MiB budgets, busy → idle Update/Remove/Restore control refresh, and completed-success character-pack operation summary fixes. See the [new bilingual note](v0.3.3.md). Stable [v0.3.3](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.3.3) and aligned [beta/0.3.3-beta.1](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.3-beta.1) were published with complete, independently verified archive/checksum assets; the beta remains a separate non-latest prerelease, not a stable installation.
v0.3.4 retains those fixes and adds side-owned eye apertures, ABI identity checks and external signed-byte provenance. Its [bilingual note](v0.3.4.md) distinguishes source intent from actual publication; the separate provenance sidecar does not enter the app archive or replace existing installer/updater checks.
v0.3.5 retains v0.3.4's rig/provenance contract and fixes stalled native pointer capture, attached bubble body placement and reply/IME viewport behavior. Its [bilingual note](v0.3.5.md) describes these changes without claiming a public binary from source alone.

**Observed v0.3.5 publication (historical):** the [Release and dependent Wiki run](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/38056425175) succeeded; at that observation, `releases/latest` selected v0.3.5. All four assets in each channel downloaded anonymously with matching GitHub sizes/digests, and each extracted signed app matched all 68 separate sidecar identities. Archive SHA-256: stable `13205c3bf5cb4055ef00fe6adf5720c833fdd168c7aa12284672b766a50f3664`; beta `d49824778dc0d898b4386cc04a4fbed34da40ebfe990148441d365984555d1aa`. Both formulas were published at [tap commit b32850c](https://github.com/hanbong5938/homebrew-tap/commit/b32850c11ce0c660c0b8e2cd5804ac8b3a8f4027), and actual Homebrew fetches accepted both archives/checksums. The unchanged pinned `--prebuilt` installer installed the public stable archive in a disposable checkout; its daemon reported 0.3.5, the exact installed executable and public binary hash, retained saved dialogue, applied native presentation and stopped normally. The downloaded beta's Homebrew-style symlink likewise started the expected 0.3.5-beta.1 daemon and stopped normally. Both failed tags and their source notes remain frozen; neither shipped binary assets.

## Historical upgrade to v0.3.5 from v0.2.1 or beta

Before replacing the stable app, stop its daemon: `start` may reuse an old process even when the new CLI reports `0.3.5`. Back up actual config **and** state, including `preferences.json`, `lifecycle.json`, installed `characters/`, `menu-bar-icons/` and updater state/reservations. Keep the same profile, imported revisions and saved dialogue; ephemeral drafts do not survive restart. Manual Arin imports still require app v0.2.1+. Protocol-1 reservations are not silently migrated or replayed; follow the existing protocol-2 status/recovery guidance in the [usage guide](../usage.md).

Only **after** v0.3.5's `.app`-only archive/checksums, separate rig-byte sidecar and stable formula/installer are published, stop the daemon, upgrade with a verified formula/pinned installer, check CLI `--version`, restart and inspect `status` for both `app_version: 0.3.5` and the expected executable. A manual archive download must match its public `.sha256`/`SHA256SUMS`; compare the separate sidecar to the extracted app if claiming byte-level provenance. Keep beta/stable config **and** state isolated when running concurrently, stop beta before moving a shared profile, and do not assume an older binary can read newer state. An existing selected character remains selected; the optional Chaerin pack is not installed or made default by the app upgrade.

[stable tap 커밋 c7be4b5](https://github.com/hanbong5938/homebrew-tap/commit/c7be4b5)은 위 정확한 태그 압축 파일 URL·검증된 SHA와 Tern 주의 사항으로 게시되었고 베타 포뮬러는 변경하지 않았습니다.

[tap 커밋 b32850c](https://github.com/hanbong5938/homebrew-tap/commit/b32850c11ce0c660c0b8e2cd5804ac8b3a8f4027)으로 두 포뮬러를 게시하고 실제 Homebrew fetch에서 두 압축 파일/체크섬을 수락했습니다. 변경 없는 고정 `--prebuilt` 설치기로 임시 체크아웃에 공개 안정판을 설치했으며 데몬의 0.3.5·설치 실행 경로·공개 바이너리 해시·저장 대사 보존·네이티브 표시 적용·정상 종료를 확인했습니다. 공개 베타의 Homebrew형 심볼릭 링크도 예상 0.3.5-beta.1 데몬 시작/종료를 확인했습니다. 기존 사용자 설치/프로필은 업그레이드하거나 변경하지 않았으며 격리된 프로그램 방식 소비자 근거이지 물리적 드래그/IME 인증은 아닙니다.

v0.3.0은 [두 번의 Release workflow](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37824652666)가 짧은 deadline fixture에서 자산 게시 전에 실패해 태그만 남았습니다. v0.3.2는 실행 중 앱의 deadline이나 재시도 동작을 바꾸지 않고 테스트의 status poll 여유와 deadline 이후 terminal 응답을 분리합니다. 테스트를 건너뛰거나 기존 태그를 덮어쓰지 않습니다.

v0.3.1에서는 수정된 dialogue-list 테스트가 통과했지만 인접 mutation deadline fixture에서 자산 게시 전에 실패했습니다. v0.3.2는 두 번째 fixture에도 같은 poll 여유·늦은 terminal 응답을 적용하며 두 실패 태그·동결 노트를 보존합니다.

### 과거 대응 베타와 더 오래된 베타 (안정판과 분리)

당시 안정판 v0.3.5와 대응한 [`beta/0.3.5-beta.1`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.5-beta.1)은 **이전의 공개된 별도 non-latest prerelease이며 새 v0.3.6 베타가 아닙니다.** 기능은 v0.3.5와 같고 자체 `HerdrDesktopPet-v0.3.5-beta.1-macos-arm64.tar.gz`·`.sha256`·`SHA256SUMS`·별도 rig 출처 사이드카를 게시했습니다. 순환 베타 포뮬러는 베타 압축 파일을 대상으로 Homebrew 접두 경로(`/Applications` 아님)에 `HerdrDesktopPetBeta.app`을 설치하고 `herdr-desktop-pet-beta`를 제공합니다. 안정판 `HerdrDesktopPet.app`·`herdr-desktop-pet`과 별도입니다. 베타의 **실제** 공개 자산과 tap 포뮬러 갱신을 확인하고 기존 데몬을 종료한 뒤 `brew update && brew upgrade herdr-desktop-pet-beta`를 실행하세요(미설치라면 베타 포뮬러 설치). 안정판 자산·기본 설치기나 베타 소스 매니페스트는 베타 게시/설치의 증거가 아닙니다. 이전에 [공개된 `beta/0.3.3-beta.1`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.3-beta.1)과 그 자산은 그대로 유지합니다.

변경 불가 [`beta/0.2.0-beta.3`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.3)은 현재 대응 베타나 안정판 기본 설치기가 아닌 과거 시험 릴리스입니다. beta1/2/3 변경 사항·체크섬·공개 증거·수동 점검은 [과거 beta3 안내](../migrations/unreleased.ko.md#선택형-수동-베타-테스트)에, 당시 채널 전환은 [과거 beta3 → 안정판 v0.2.0 이전 안내](../migrations/v0.1.11-to-v0.2.0.md#한국어)에 남아 있습니다. 옛 `beta/0.3.0-beta.2`도 과거 버전 그대로이며 옛 베타 태그·자산·증거는 변경하지 않습니다.

업그레이드 전 **기존 데몬을 먼저 종료**하고 실제 설정·상태 디렉터리의 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`, updater 기록/예약을 백업하세요. 기존 정렬·실행 중 우선 설정과 가져온 Arin 팩은 별도 변환이 필요하지 않으며 답장·편집기·검색 초안은 재시작 후 유지되지 않습니다. 이전 protocol-1 기록은 자동 이전하지 않으므로 예약을 임의 삭제하거나 불확실한 설치를 다시 실행하지 마세요. [CLI의 protocol-2 상태·복구](../cli.md#한국어)와 원본 증거를 확인하세요.

안정판 v0.3.5 사용 전 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 공개 앱 전용 압축 파일·체크섬·별도 rig 출처 사이드카와 포뮬러/설치기 갱신을 확인하세요. 기존 데몬을 종료하고 실제 설정·상태(캐릭터·업데이터 기록 포함)를 백업한 뒤 확인된 설치기로 업그레이드하고 `--version`, 재시작한 `status`의 `app_version: 0.3.5` 및 실행 경로를 확인하세요. 압축 파일은 공개 `.sha256`·`SHA256SUMS`로 검증하고 배포 바이트 출처를 주장할 때는 별도 사이드카와 추출된 앱을 대조하세요. 베타·안정판의 설정/상태 경로는 모두 분리하며 공유 프로필 이전 전 베타를 종료하세요. 구형 protocol-1 예약을 자동으로 재실행/삭제하지 않고 이전 바이너리로의 무조건적 되돌리기도 보장하지 않습니다. 선택형 채린 팩은 업그레이드로 자동 설치하거나 기본 캐릭터로 바꾸지 않습니다. [한국어 설치 안내](../../readme.ko.md)와 과거 [v0.1.11 → v0.2.0 이전 안내](../migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요.
