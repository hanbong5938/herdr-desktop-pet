v0.3.0 combines search/order, native CLI automation, conflict-aware dialogue drafts, eight-way bubble resizing, official character browser/explicit verified Download & Apply, installation-aware protocol-2 app updates and worker-only JIT decoding improvement, on top of the v0.2.1 Arin compatibility fix. The public v0.2.1 patch is a separate, frozen historical release; no old tag, binary, beta asset, artwork, rig format v5 or `default@0` is rewritten. See the [version note](v0.3.0.md) for behavioral and evidence limits.

## Upgrade from v0.2.1 or beta

Before replacing the stable app, stop its existing daemon: `start` may reuse an old process even when the CLI reports `0.3.0`. Back up the actual config **and** state directories, including `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/` and updater state/reservations. Retain the same profile, imported revisions and saved dialogue; reply/editor/search drafts are memory-only and do not survive restart. Existing session sort/running-first preferences need no migration. Existing manually imported Arin packs continue to require app v0.2.1 or later; 0.3.0 retains that fix. Protocol-1 updater records are deliberately **not** migrated: do not remove a retained reservation or replay an uncertain installation; use [protocol-2 status/recovery guidance](../cli.md#app-update-status-and-recovery) for new operations and investigate older evidence before any replacement.

Only **after** v0.3.0 assets and the stable formula/installer are published, stop the daemon, run `brew update && brew upgrade herdr-desktop-pet` if using Homebrew (or the corresponding verified pinned installer), then check CLI `--version`, restart and inspect `status` for both `app_version: 0.3.0` and the expected running executable. A manual download must match the public release archive and its `.sha256`/`SHA256SUMS`; a tag or this source note is insufficient. Keep beta and stable config **and** state isolated if running concurrently; stop beta before moving a shared profile and do not assume a rollback into old binaries can read newer state. The beta tags and rolling beta tap are not stable v0.3.0 installations. On a source build, `bash scripts/install.sh --source` builds only the checkout in hand and does not fetch or publish a release. See the [root install guide](../../readme.md) and historical [v0.1.11 → v0.2.0 migration](../migrations/v0.1.11-to-v0.2.0.md).

## 한국어 · v0.3 계열

v0.3.0은 **안정판 소스·기본/사전 빌드 대상**이며 문서·태그만으로 바이너리 게시를 주장하지 않습니다. 세션 검색·정렬·실행 중 우선, 네이티브 CLI 자동화, 충돌 인식 대사 초안, 8방향 말풍선 크기 조절, 공식 캐릭터 브라우저의 명시적 검증 다운로드·적용, 설치 출처별 protocol-2 업데이트와 디코더 worker 전용 JIT 개선이 포함됩니다. v0.2.1의 Arin 호환성 수정은 유지하며 예전 릴리스·베타·팩 v5·내장 `default@0`는 변경하지 않습니다. [한영 버전 노트](v0.3.0.md)를 참고하고 실제 공개 여부는 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)에서 완전한 자산으로 확인하세요.

업그레이드 전 **기존 데몬을 먼저 종료**하고 실제 설정·상태 디렉터리의 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`, updater 기록/예약을 백업하세요. 기존 정렬·실행 중 우선 설정과 가져온 Arin 팩은 별도 변환이 필요하지 않으며 답장·편집기·검색 초안은 재시작 후 유지되지 않습니다. 이전 protocol-1 기록은 자동 이전하지 않으므로 예약을 임의 삭제하거나 불확실한 설치를 다시 실행하지 마세요. [CLI의 protocol-2 상태·복구](../cli.md#한국어)와 원본 증거를 확인하세요.

안정판 포뮬러/설치기에서 v0.3.0을 쓰려면 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 공개 압축 파일·체크섬과 포뮬러/설치기 갱신을 확인한 뒤 `brew update && brew upgrade herdr-desktop-pet`(또는 검증된 고정 설치기)을 사용하세요. CLI `--version`만으로는 이미 실행 중인 옛 데몬을 교체할 수 없으므로 `start` 후 `status`의 `app_version: 0.3.0`과 실제 실행 경로를 확인하세요. 수동 압축 파일은 공개 `.sha256`·`SHA256SUMS`로 검증하세요. 베타·안정판 동시 실행에는 설정·상태 경로 **모두** 분리가 필요하고 공유 프로필 전환은 베타부터 종료하세요. 이전 바이너리로의 무조건적 상태 되돌리기는 보장되지 않습니다. `--source`는 현재 체크아웃만 빌드합니다. [한국어 설치 안내](../../readme.ko.md)와 과거 [v0.1.11 → v0.2.0 이전 안내](../migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요.
