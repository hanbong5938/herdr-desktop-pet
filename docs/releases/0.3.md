v0.3.5 retains v0.3.4's rig/provenance contract and fixes stalled native pointer capture, attached bubble body placement and reply/IME viewport behavior. Its [bilingual note](v0.3.5.md) describes these changes without claiming a public binary from source alone.

The first v0.3.0 publication attempt did not ship a binary: [both workflow attempts](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37824652666) failed while a 180ms deadline fixture required its first status poll to arrive before expiry. v0.3.2 retains the same runtime contract and gives that test a two-second poll window with a terminal response delayed beyond it. No test is skipped and no old tag is rewritten.

The dialogue-list repair passed in [v0.3.1's workflow](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37827243595), which instead failed at the adjacent mutation deadline fixture. v0.3.2 applies the same two-second poll window and late terminal response to that second fixture. Both failed tags and their source notes remain frozen; neither shipped binary assets.

## Paired beta and historical beta (separate from stable)

The paired `beta/0.3.5-beta.1` is a separate **target**, not proof of an uploaded prerelease; when published it must be non-latest, with stable v0.3.5 functionality and its own `HerdrDesktopPet-v0.3.5-beta.1-macos-arm64.tar.gz`, `.sha256`, `SHA256SUMS` and separate rig provenance sidecar. The beta formula installs `HerdrDesktopPetBeta.app` under Homebrew's prefix (not `/Applications`) and supplies `herdr-desktop-pet-beta`, separately from stable `HerdrDesktopPet.app` and `herdr-desktop-pet`. After confirming the beta's actual Release assets and updated rolling tap formula, stop the existing daemon before `brew update && brew upgrade herdr-desktop-pet-beta`, or install the formula if absent. Neither stable assets/default installer nor beta source manifests prove beta installation/publication. The earlier [published `beta/0.3.3-beta.1`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.3-beta.1) and its assets remain unchanged.

Immutable [`beta/0.2.0-beta.3`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.3) is a historical test release, not the current paired beta or stable default. Its beta1/2/3 changes, checksum, publication evidence and manual test guidance remain in the [historical beta3 guide](../migrations/unreleased.md#optional-manual-beta-test); the [historical beta3 → stable v0.2.0 migration](../migrations/v0.1.11-to-v0.2.0.md) covers the old channel transition. Older `beta/0.3.0-beta.2` remains historical and unchanged; neither old beta tag/assets nor their proof is rewritten.

## Upgrade from v0.2.1 or beta

Before replacing the stable app, stop its daemon: `start` may reuse an old process even when the new CLI reports `0.3.5`. Back up actual config **and** state, including `preferences.json`, `lifecycle.json`, installed `characters/`, `menu-bar-icons/` and updater state/reservations. Keep the same profile, imported revisions and saved dialogue; ephemeral drafts do not survive restart. Manual Arin imports still require app v0.2.1+. Protocol-1 reservations are not silently migrated or replayed; follow the existing protocol-2 status/recovery guidance in the [usage guide](../usage.md).

Only **after** v0.3.5's `.app`-only archive/checksums, separate rig-byte sidecar and stable formula/installer are published, stop the daemon, upgrade with a verified formula/pinned installer, check CLI `--version`, restart and inspect `status` for both `app_version: 0.3.5` and the expected executable. A manual archive download must match its public `.sha256`/`SHA256SUMS`; compare the separate sidecar to the extracted app if claiming byte-level provenance. Keep beta/stable config **and** state isolated when running concurrently, stop beta before moving a shared profile, and do not assume an older binary can read newer state. An existing selected character remains selected; the optional Chaerin pack is not installed or made default by the app upgrade.

## 한국어 · v0.3 계열

v0.3.5는 **안정판 소스·기본/사전 빌드 대상**이며 문서·태그만으로 바이너리 게시를 주장하지 않습니다. [v0.3.4](v0.3.4.md)의 눈 소유권·ABI·출처 기록, [v0.3.3](v0.3.3.md)의 카드·초상화·관리 동작·작업 요약 수정과 [v0.3.2](v0.3.2.md)의 검색·정렬·자동화·초안·말풍선 크기·공식 팩 브라우저·protocol-2 업데이트·worker JIT 및 v0.2.1 Arin 수정을 유지합니다. 포인터 캡처 복구·부착 말풍선·IME 답장 배치는 [v0.3.5 한영 노트](v0.3.5.md)를 참고하고 실제 공개 여부는 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)에서 확인하세요. 예전 릴리스·팩 v5·내장 `default@0`·별도 베타 자산은 변경하지 않습니다.

v0.3.0은 [두 번의 Release workflow](https://github.com/hanbong5938/herdr-desktop-pet/actions/runs/37824652666)가 짧은 deadline fixture에서 자산 게시 전에 실패해 태그만 남았습니다. v0.3.2는 실행 중 앱의 deadline이나 재시도 동작을 바꾸지 않고 테스트의 status poll 여유와 deadline 이후 terminal 응답을 분리합니다. 테스트를 건너뛰거나 기존 태그를 덮어쓰지 않습니다.

v0.3.1에서는 수정된 dialogue-list 테스트가 통과했지만 인접 mutation deadline fixture에서 자산 게시 전에 실패했습니다. v0.3.2는 두 번째 fixture에도 같은 poll 여유·늦은 terminal 응답을 적용하며 두 실패 태그·동결 노트를 보존합니다.

### 대응 베타와 과거 베타 (안정판과 분리)

안정판 v0.3.5와 기능이 같은 `beta/0.3.5-beta.1`은 별도 **출시 대상**으로, 문서·소스만으로 게시가 증명되지 않습니다. 게시되면 non-latest prerelease여야 하고 자체 `HerdrDesktopPet-v0.3.5-beta.1-macos-arm64.tar.gz`·`.sha256`·`SHA256SUMS`·별도 rig 출처 사이드카가 필요합니다. 순환 베타 포뮬러는 베타 압축 파일을 대상으로 Homebrew 접두 경로(`/Applications` 아님)에 `HerdrDesktopPetBeta.app`을 설치하고 `herdr-desktop-pet-beta`를 제공합니다. 안정판 `HerdrDesktopPet.app`·`herdr-desktop-pet`과 별도입니다. 베타의 **실제** 공개 자산과 tap 포뮬러 갱신을 확인하고 기존 데몬을 종료한 뒤 `brew update && brew upgrade herdr-desktop-pet-beta`를 실행하세요(미설치라면 베타 포뮬러 설치). 안정판 자산·기본 설치기나 베타 소스 매니페스트는 베타 게시/설치의 증거가 아닙니다. 이전에 [공개된 `beta/0.3.3-beta.1`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.3-beta.1)과 그 자산은 그대로 유지합니다.

변경 불가 [`beta/0.2.0-beta.3`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.3)은 현재 대응 베타나 안정판 기본 설치기가 아닌 과거 시험 릴리스입니다. beta1/2/3 변경 사항·체크섬·공개 증거·수동 점검은 [과거 beta3 안내](../migrations/unreleased.ko.md#선택형-수동-베타-테스트)에, 당시 채널 전환은 [과거 beta3 → 안정판 v0.2.0 이전 안내](../migrations/v0.1.11-to-v0.2.0.md#한국어)에 남아 있습니다. 옛 `beta/0.3.0-beta.2`도 과거 버전 그대로이며 옛 베타 태그·자산·증거는 변경하지 않습니다.

업그레이드 전 **기존 데몬을 먼저 종료**하고 실제 설정·상태 디렉터리의 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`, updater 기록/예약을 백업하세요. 기존 정렬·실행 중 우선 설정과 가져온 Arin 팩은 별도 변환이 필요하지 않으며 답장·편집기·검색 초안은 재시작 후 유지되지 않습니다. 이전 protocol-1 기록은 자동 이전하지 않으므로 예약을 임의 삭제하거나 불확실한 설치를 다시 실행하지 마세요. [CLI의 protocol-2 상태·복구](../cli.md#한국어)와 원본 증거를 확인하세요.

안정판 v0.3.5 사용 전 [Release 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases)의 공개 앱 전용 압축 파일·체크섬·별도 rig 출처 사이드카와 포뮬러/설치기 갱신을 확인하세요. 기존 데몬을 종료하고 실제 설정·상태(캐릭터·업데이터 기록 포함)를 백업한 뒤 확인된 설치기로 업그레이드하고 `--version`, 재시작한 `status`의 `app_version: 0.3.5` 및 실행 경로를 확인하세요. 압축 파일은 공개 `.sha256`·`SHA256SUMS`로 검증하고 배포 바이트 출처를 주장할 때는 별도 사이드카와 추출된 앱을 대조하세요. 베타·안정판의 설정/상태 경로는 모두 분리하며 공유 프로필 이전 전 베타를 종료하세요. 구형 protocol-1 예약을 자동으로 재실행/삭제하지 않고 이전 바이너리로의 무조건적 되돌리기도 보장하지 않습니다. 선택형 채린 팩은 업그레이드로 자동 설치하거나 기본 캐릭터로 바꾸지 않습니다. [한국어 설치 안내](../../readme.ko.md)와 과거 [v0.1.11 → v0.2.0 이전 안내](../migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요.
