# Herdr Desktop Pet v0.1.4 release notes

## Summary

This historical page is reconstructed from the published [v0.1.4 Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.1.4) and contemporaneous tagged documentation. The Release page is the authority for its published assets and publication information.

v0.1.4 brings persistent status indicators, validated outcome handling, accessible session cards, and native tracking/layout fixes to the Apple Silicon macOS app. Its prebuilt includes lifecycle settings, per-character Korean/English dialogue editing, and the **multiline message composer**. It does not have v0.1.6's on-demand inline replies.

## What's new and fixed

- Status icons and semantic colors are saved preferences: blue for running, amber for attention, green only for validated success, and red for failure. Plain `Done` or idle without an accepted result stays neutral. A pinned bubble summary remains visible alongside dialogue, and session cards expose their full title and status accessibly.
- Unchanged idle updates retain an accepted outcome. New activity, ambiguous identity, report loss, or disconnection revokes it; resolving ambiguity does not re-approve the same cached report. New sources stay Offline until their first coherent snapshot, including an empty one. The summary shows success only when all observed sessions have validated successful results, independent of the card filter/display limit.
- Single-pass card rendering avoids duplicate string updates. Bubble content and placement changes deferred during native dropdown, scrolling, or drag tracking drain after tracking ends with the latest settings. Indicator toggles relayout even at unchanged bubble size and preserve selection, filters, and drafts.
- Lifecycle settings separate `auto_start` from `exit_with_herdr`. New profiles default to on/on; existing profiles migrate boolean `enabled` to `auto_start`, preserving false, and default an absent exit setting to off. `lifecycle.json` owns both settings; malformed data or failed saves produce errors rather than resetting policy.
- Dialogue overrides live in `preferences.json`, not character packs, with per-character Korean/English entries and a 2048 UTF-8-byte limit per event. Only saved dialogue survives restart; empty overrides restore the existing fallback.

## Composer behavior and upgrading

Expand the bubble and explicitly select a local agent session; **All** is not a message destination, and remote cards are read-only. **Enter inserts a newline**; **Command+Enter** or **Send** submits. IME composition never submits. **Escape** first cancels composition, otherwise collapses the bubble. Per-session drafts survive collapse in memory, not app restart; a successful submission clears only the matching draft, while failure preserves it.

Prompts use only the selected local source's `agent.prompt` API, not a shell, SSH, global CLI, or raw pane input. Offline, excluded, stale, unready, or unsupported targets cannot send. An ACK means Herdr accepted the prompt, **not** that the agent finished. Check uncertain delivery before resending; there is no automatic retry. The host API lacks an atomic expected-session guard, so a pane's occupant can change at the instant of submission. Handle approvals/questions in the actual terminal.

For the keyboard and draft changes when moving to inline replies, see [v0.1.4 → v0.1.6 migration](../migrations/v0.1.4-to-v0.1.6.md) and [v0.1.6 notes](v0.1.6.md). [v0.1.5](v0.1.5.md) is a tag without a published binary, not an intermediate download.

## Compatibility and limits

- Native distribution: Apple Silicon macOS 13+, not Intel Mac, Windows, or Linux. Bundles are ad-hoc signed, not Developer ID signed or notarized; macOS may require explicit approval.
- Local observation supports Herdr 0.9.0+. `agent.prompt` was reported verified with Herdr 0.9.2; the observation baseline does not guarantee prompt support. Remote observation additionally requires a compatible saved-machine forwarding CLI (documented in Herdr 0.9.2) and remote server.
- Client-attach auto-start requires **official Herdr 0.9.3 source with the supplied patch applied and built**, or an actual future host release advertising `client.attached`. Stock 0.9.0/0.9.3 do not implement that hook. The app release and manifest minimum do not publish or prove a new Herdr host capability. Inspect plugin-link warnings and accepted subscription; follow the [host integration guide](../../integrations/herdr/README.md).
- Linking/enabling on an already-running host does not itself launch the app: start manually or wait for a qualifying attach with auto-start on. Stop/Quit ends this run, not future auto-start; exit-with-Herdr uses a 30-second grace after loss of the last healthy server, canceled by healthy reconnection.
- Remote profiles are opt-in observation only and poll about every five seconds; short transitions may be missed. Disconnected cards show last-known data, not live state. Recovery starts a fresh baseline rather than replaying old reactions. The pet does not perform interactive SSH setup or fall back to Local on remote errors.
- Alpha click-through uses pointer polling; leave it off if a click-routing race is unacceptable. Opening settings requests activation, not a guaranteed OS-granted keyboard-focus transfer.

## Artwork and pack boundaries

Rubelia is the only bundled character (`default@0`), with ten independent native rig poses and upper-thigh framing. Its shared-world-canon identity is used with the owner's authorization; AI/model provenance travels with the pack. The later approved redraw first published in v0.1.6 is not backported to this binary. Imported PNG/rig packs remain supported, and optional Aurora, Coding Cat, and Rubelia outfits live in [herdr-characters](https://github.com/hanbong5938/herdr-characters).

Software MIT terms do not relicense artwork. Retain the tagged [Rubelia license](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.4/assets/rubelia-default/LICENSE.txt), [attribution](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.4/assets/rubelia-default/ATTRIBUTION.txt), and [source records](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.4/assets/rubelia-default/source-record.json), and preserve imported packs' own notices. The [repository notice](https://github.com/hanbong5938/herdr-desktop-pet/blob/v0.1.4/LICENSE.txt) retains the original Coding Cat notice; it is not a blanket license for every component.

## Historical evidence appendix

These are reported historical results, **not checks rerun for this reconstruction**:

- The published Release reports **241 native tests**, TypeScript checks, and **5 Bun tests** passing locally before publication.
- Real AppKit with an isolated Unix RPC fixture reportedly exercised cached-report revocation, idle preservation, startup Offline behavior, post-tracking drain, and latest-setting/draft preservation.
- A 128-card event reportedly performed **384 string updates instead of 768**; pending-result drain was measured **58 ms after tracking unlock**. These are scoped measurements, not a general performance guarantee or physical-keyboard IME certification.
- The Release links the changes through [PR #8](https://github.com/hanbong5938/herdr-desktop-pet/pull/8).
