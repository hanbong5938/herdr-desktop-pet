# Herdr Desktop Pet v0.2.1 release notes

[Versions](README.md) · [0.2 line](0.2.md) · [v0.2.0 stable notes](v0.2.0.md) · [English/한국어 upgrade guide](../migrations/v0.1.11-to-v0.2.0.md)

v0.2.1 is a user-approved compatibility **patch of the public v0.2.0 stable source**, not a promotion of the unrelated, unreleased features on `main`. The isolated release source starts from the v0.2.0 tag (`b8b7b8c`). The fix resolves a child layer's geometry before dropping a `meshSource` link to a reference-only parent excluded from the final rig layers. The actual public v0.2.0 binary failed to validate the Arin pack source with `RIG_INVALID`: deformation layer `handwear_1` referenced unknown `meshSource` `handwear_3`. The native validator is **not** relaxed; links to retained parents remain. This is an app compatibility fix, not a new character-pack format or pack release.

Arin archive import/validation requires **Herdr Desktop Pet v0.2.1 or newer**. Stable v0.2.1 imports downloaded character archives manually; it does **not** include `main`'s unreleased Download & Apply browser, automation, search/sort, resizing or draft changes. The character artwork, rig overrides, motion, bundled Rubelia `default@0`, v5 pack format, licensing and attribution remain unchanged. The separate character-pack downloads are published independently; this app patch does not publish them.

## Install or upgrade safely

Apple Silicon macOS 13+ is required. Stop the running stable daemon **before** upgrading: `start` may reuse an older running daemon. Once the v0.2.1 Release and stable Homebrew formula are actually available, upgrade with:

```sh
herdr-desktop-pet stop
brew update && brew upgrade herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status
```

Check that the CLI reports `0.2.1` and the restarted daemon's `status` reports `app_version: 0.2.1` and the expected executable. New installations use `brew install hanbong5938/tap/herdr-desktop-pet` after the formula is updated; Homebrew installs under its own prefix, not `/Applications`. For a manual download, obtain `HerdrDesktopPet-v0.2.1-macos-arm64.tar.gz`, [`HerdrDesktopPet-v0.2.1-macos-arm64.tar.gz.sha256`](https://github.com/hanbong5938/herdr-desktop-pet/releases/download/v0.2.1/HerdrDesktopPet-v0.2.1-macos-arm64.tar.gz.sha256) and [`SHA256SUMS`](https://github.com/hanbong5938/herdr-desktop-pet/releases/download/v0.2.1/SHA256SUMS) from the [v0.2.1 GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.2.1), verify the archive checksum before unpacking, and use the root [runtime guide](../../readme.md) / [한국어](../../readme.ko.md). These links identify intended assets; a note or tag does **not** establish that they have been uploaded. If migrating from beta, stop its daemon first and keep both config **and** state directories isolated if running stable and beta side by side; back up `preferences.json`, `lifecycle.json`, `characters/`, and `menu-bar-icons/` before replacing either app. The app is ad-hoc signed, not notarized; macOS Gatekeeper may require approval.

## Pre-tag verification and limits

In the isolated v0.2.1 source, TypeScript and **40 Bun tests / 348 expectations** passed; native Rust release tests passed **343 tests across two suites**. The app was built and packaged with ad-hoc signing, not notarization. Actual isolated CLI validation of the Arin pack source returned `prepared: true`, `backend: rig`, 1024×1024, and content digest `196bf02e0a07755b4287ea6c95b5b56cb6bd7a6835d3e7b4f3023a65dc79e7ab`. Regression coverage checks missing-parent link removal, retained-parent links, child pixel colors and transparent reference-only artwork. These local pre-tag results do **not** prove public v0.2.1 downloads, Homebrew consumer installation or physical GUI interaction. Verify public assets/checksums and consumer upgrade separately after publication; historical v0.2.0 and beta results retain their original scope.

The actual fixed v0.2.1 native pack preview rendered Arin `--pose head-pet --time-ms 700` and `--pose head-tap --time-ms 350` to 1024×1024 rig PNGs; both images were visually inspected as complete renders. The local app bundle passed `codesign --verify --deep --strict`, and its binary was confirmed arm64 by `lipo`. These source-bundle checks are not physical GUI/pointer/IME acceptance or proof of a public archive.

## 한국어 · v0.2.1 패치 안내

v0.2.1은 사용자가 승인한 **공개 v0.2.0 안정판 소스 기반 호환성 패치**이며 `main`의 미공개 기능을 함께 승격하지 않습니다. 실제 공개 v0.2.0 바이너리로 Arin 팩 소스를 검증했을 때 `handwear_1`이 제외된 `handwear_3`을 `meshSource`로 참조해 `RIG_INVALID`가 발생했습니다. 이제 자식 형상을 먼저 확정한 후 제외된 참조 전용 부모의 링크만 제거합니다. 남아 있는 부모의 링크와 네이티브 검증 기준은 유지합니다. Arin 압축 팩을 가져오기·검증하려면 **앱 v0.2.1 이상**이 필요합니다. `main`의 미공개 다운로드 브라우저·자동화·검색/정렬·크기 조정·초안 기능은 포함되지 않습니다. 그림·rig override·motion·내장 `default@0`·팩 v5·라이선스·출처는 그대로이며 캐릭터 팩 게시도 별도입니다.

Apple Silicon macOS 13+에서 v0.2.1 공개 릴리스와 안정판 Homebrew 포뮬러 갱신을 확인한 뒤 **실행 중인 안정판 데몬을 먼저** `herdr-desktop-pet stop`으로 종료하고 `brew update && brew upgrade herdr-desktop-pet`을 실행하세요. CLI `--version`이 `0.2.1`인지 확인한 후 `start`, `status`로 새 데몬의 `app_version: 0.2.1`과 실행 파일을 확인하세요. 실행 중인 이전 데몬을 `start`가 재사용할 수 있습니다. 수동 설치는 위 [v0.2.1 GitHub Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.2.1)의 압축 파일·`.sha256`·`SHA256SUMS`를 내려받아 체크섬을 검사하세요. 문서나 태그만으로 자산 업로드를 단정하지 마세요. 베타에서 옮길 때 베타 데몬도 먼저 종료하고, 동시 사용하려면 설정·상태 디렉터리를 **모두** 분리하세요. 교체 전 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`를 백업하세요. ad-hoc 서명이며 공증되지 않아 Gatekeeper 승인이 필요할 수 있습니다.

격리된 v0.2.1 태그 고정 전 소스에서 TypeScript, Bun **40개/기대값 348개**, Rust release 테스트 **두 모음 합계 343개**가 통과했고 앱 빌드·패키징도 성공했습니다. 실제 Arin CLI 검증은 `prepared: true`, `backend: rig`, 1024×1024와 위 content digest를 반환했습니다. 회귀 검사는 사라진 부모 링크 제거, 유지되는 부모 링크, 자식 픽셀 색상과 참조 전용 그림의 투명성을 확인합니다. 이는 **로컬 태그 고정 전 결과**로, 공개 다운로드·Homebrew 소비자 업그레이드·공증·실제 GUI 조작 검증이 아닙니다. 게시 후 실제 Release 자산·체크섬과 소비자 업그레이드를 별도로 확인해야 합니다.

실제 수정된 v0.2.1 네이티브 팩 미리보기에서 Arin `--pose head-pet --time-ms 700`과 `--pose head-tap --time-ms 350`을 각각 1024×1024 rig PNG로 렌더링했고 두 이미지의 완전한 표시를 육안 확인했습니다. 로컬 앱 번들은 `codesign --verify --deep --strict`를 통과했고 `lipo`로 arm64 바이너리를 확인했습니다. 이는 소스 번들 검사이지 실제 GUI·포인터·IME 조작이나 공개 압축 파일의 증거는 아닙니다.
