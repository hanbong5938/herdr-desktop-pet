# Herdr Desktop Pet 0.3.5-beta.1 / 시험판 0.3.5-beta.1

Tag: `beta/0.3.5-beta.1`. This beta inherits stable v0.3.5 functionality from source `a765027`; only distribution version and beta documentation differ. It is a separate non-latest prerelease with `HerdrDesktopPetBeta.app` and Homebrew CLI `herdr-desktop-pet-beta`. Old tags/assets remain immutable. The default installer stays on stable v0.3.5; do not use the stable installer or `--prebuilt` for this beta.

태그는 `beta/0.3.5-beta.1`이며 안정판 v0.3.5 소스 `a765027`과 기능이 같습니다. 배포 버전·베타 안내만 다릅니다. `HerdrDesktopPetBeta.app`과 Homebrew `herdr-desktop-pet-beta`를 사용하는 별도 non-latest prerelease이며 옛 태그·자산은 유지합니다. 기본 설치기는 안정판 v0.3.5용이므로 베타에 안정판 설치기·`--prebuilt`를 사용하지 마세요.

## Matched changes / 동일 반영 변경

- Recover interrupted native left-button captures without false taps or stale-event takeover. / 가짜 탭이나 오래된 이벤트의 제스처 탈취 없이 유실된 좌버튼 캡처를 복구합니다.
- Keep attached bubble bodies outside stable character bounds and preserve the current safe auto-placement side during reflow; use bounded tailless fallback when no side fits. / 부착 말풍선 본문을 안정적인 캐릭터 경계 밖에 두고 갱신 중에도 안전한 자동 배치 방향을 유지하며 공간이 없을 때 화면 내 꼬리 없는 대체 배치를 사용합니다.
- Lay out replies before focus and preserve native editor drafts, selection and IME composition during deferred reflow. / 답장 포커스 전에 배치하고 지연된 갱신 중 네이티브 편집기 초안·선택·IME 조합을 유지합니다.
- Retain v0.3.4 eye ownership, rig ABI checks, sealed motion bytes and post-signing provenance, protocol-2 updates, worker-only JIT, pack v5 and bundled `default@0`. Artwork, licensing and authored motions are unchanged. / v0.3.4 눈 소유권·rig ABI·봉인된 motion·서명 후 출처 기록, protocol-2 업데이트·worker 전용 JIT·팩 v5·내장 `default@0`를 유지하며 그림·라이선스·원본 모션은 바꾸지 않습니다.

## Download and safe upgrade / 다운로드·안전한 이전

Apple Silicon/arm64, macOS 13+. Obtain `HerdrDesktopPet-v0.3.5-beta.1-macos-arm64.tar.gz`, its `.sha256`, `SHA256SUMS` and separate `HerdrDesktopPet-v0.3.5-beta.1-rig-native.json` from the actual [beta Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.5-beta.1). Verify the archive checksum before extracting; it contains only `HerdrDesktopPetBeta.app`. Compare the separate sidecar to extracted signed `Contents` files. The app includes the standalone protocol-2 coordinator and rig decode worker. Ad-hoc signed, not Developer ID signed or notarized.

Apple Silicon/arm64·macOS 13 이상 전용입니다. 실제 베타 Release에서 위 앱 전용 압축 파일·개별 체크섬·`SHA256SUMS`·별도 출처 사이드카를 받고 SHA-256을 대조한 뒤 압축을 해제하세요. 별도 사이드카는 추출한 서명 후 `Contents` 파일 해시와 비교합니다. 독립 protocol-2 코디네이터와 rig worker가 포함되며 ad-hoc 서명이지 Developer ID 서명·Apple 공증은 아닙니다.

Once the rolling beta formula targets `0.3.5-beta.1`, use `brew install hanbong5938/tap/herdr-desktop-pet-beta` or `brew update && brew upgrade herdr-desktop-pet-beta`. Stop the old daemon and back up both actual config and state, including characters, dialogue and updater records. Stable/beta normally share a namespace: do not run concurrently unless both config and state are isolated. Use the same explicit directory pair for start/status/stop. Check CLI `--version` and restarted `status` for `app_version: 0.3.5-beta.1` and the expected beta executable. Preserve uncertain updater reservations.

순환 베타 포뮬러가 `0.3.5-beta.1`을 가리킨 뒤 위 명령으로 설치·업그레이드하세요. 기존 데몬을 종료하고 캐릭터·대사·업데이터 기록을 포함한 실제 설정/상태를 백업하세요. 동시 실행에는 설정·상태 모두 격리가 필요하며 시작/상태/종료에 같은 디렉터리 쌍을 지정하세요. CLI 버전과 재시작한 `status`의 앱 버전·베타 실행 경로를 함께 확인하고 결과 불명 업데이트 예약을 보존하세요.

For this beta checkout: `bun run build:native && HERDR_PET_APP_NAME=HerdrDesktopPetBeta.app bun run package:native`. / 이 베타 체크아웃의 빌드에는 명시적 베타 앱 이름을 지정한 위 명령을 사용하세요.

## Verified beta candidate / 베타 후보 검증

The final beta passed TypeScript, locked release build/package, 621 main native tests plus an isolated FIFO child (one ignored), and the real main-thread AppKit composer. All 68 deployed file hashes matched the signed beta bundle; deep strict signature verification passed. Its isolated daemon reported `app_version: 0.3.5-beta.1`, the expected beta executable and UI/control readiness, stable attached-bubble geometry, successful preferences/dialogue reads and normal stop. Backend absence was intentional and `exit_with_herdr` was disabled for this smoke check. These local checks are not public asset, Homebrew consumer-upgrade or physical drag/IME certification; publication requires an actual non-draft prerelease and complete verified uploaded assets.

최종 베타의 TypeScript·잠금 release 빌드/패키징, 네이티브 주 검사 621개와 FIFO 자식 1개(ignored 1개), 실제 메인 스레드 AppKit 편집기가 통과했습니다. 서명된 베타 번들의 배포 파일 68개 해시와 deep strict 서명을 확인했습니다. 격리 데몬의 앱 버전·예상 베타 실행 경로·UI/control 준비, 안정적인 부착 말풍선 배치·환경 설정/대사 읽기·정상 종료를 확인했습니다. 의도적으로 백엔드가 없고 이 점검에서 `exit_with_herdr`를 껐습니다. 로컬 검사는 공개 자산·사용자 Homebrew 업그레이드·물리적 드래그/IME 인증이 아니며 실제 비초안 prerelease와 완전한 검증된 업로드 자산으로 게시 여부를 판단합니다.
