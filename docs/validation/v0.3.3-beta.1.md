# Herdr Desktop Pet 0.3.3-beta.1 / 시험판 0.3.3-beta.1

Tag: `beta/0.3.3-beta.1`. This beta inherits the functional stable v0.3.3 source at `6f1935301335a13f01ac40b76b8e579bab37c426`; only distribution version, beta guidance and this note differ. It is a separate non-latest prerelease with `HerdrDesktopPetBeta.app` and the `herdr-desktop-pet-beta` Homebrew CLI. Earlier tags/assets remain immutable. The stable default installer stays on v0.3.3; do not use the stable installer or `--prebuilt` to install this beta. Source metadata alone does not prove published assets.

태그는 `beta/0.3.3-beta.1`입니다. 위 v0.3.3 안정판 소스와 기능이 같으며 배포 버전·베타 안내·이 기록만 다릅니다. `HerdrDesktopPetBeta.app`과 Homebrew `herdr-desktop-pet-beta`를 사용하는 별도 non-latest prerelease이며 기존 태그·자산은 유지합니다. 기본 설치기는 안정판 v0.3.3을 유지하므로 베타에 안정판 설치기·`--prebuilt`를 사용하지 마세요. 소스 버전만으로 공개 자산을 주장하지 않습니다.

## Matched changes / 동일 반영 변경

- One installed official character card across All, Installed and Official Catalog; no duplicate local card. / 전체·설치됨·공식 카탈로그에서 설치된 공식 캐릭터를 카드 하나로 표시합니다.
- Published 1024×1024 remote portraits accepted within existing 4 MiB budgets. / 기존 4 MiB 제한 안에서 게시된 1024×1024 공식 미리보기를 허용합니다.
- Update/Remove/Restore enabled states recover after busy changes on the same installed card/generation, while Inspect remains available. / 같은 설치 카드·세대에서 작업 상태에 맞게 업데이트·삭제·복원을 갱신하며 조회는 유지합니다.
- Successful completed character-pack operation summaries are hidden; session success status is unchanged. / 성공 완료한 캐릭터 팩 작업 요약을 숨기며 세션 성공 상태는 변경하지 않습니다.
- Existing 0.3 automation, dialogue conflicts, bubble resizing, protocol-2 installation-aware updates/recovery and worker-only JIT are retained. Pack v5, bundled `default@0`, artwork and licensing are unchanged. / 기존 0.3 자동화·대사 충돌·말풍선 크기·protocol-2 업데이트/복구·worker 전용 JIT, 팩 v5·`default@0`·그림·라이선스를 유지합니다.

## Download and safe upgrade / 다운로드·안전한 이전

Apple Silicon/arm64, macOS 13+. Obtain `HerdrDesktopPet-v0.3.3-beta.1-macos-arm64.tar.gz`, its `.sha256` and `SHA256SUMS` from the actual [beta Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.3-beta.1). Verify the downloaded archive SHA-256 before extracting. It must contain the actual arm64 `HerdrDesktopPetBeta.app/Contents/MacOS/herdr-desktop-pet`, the standalone protocol-2 helper and rig decode worker. Ad-hoc signed, not Developer ID signed or notarized.

Apple Silicon/arm64·macOS 13 이상 전용입니다. 실제 베타 Release에서 위 압축 파일·개별 체크섬·`SHA256SUMS`를 받고 SHA-256을 대조한 뒤 압축을 해제하세요. 실제 arm64 번들 실행 파일·protocol-2 독립 도우미·rig decode worker가 포함됩니다. Ad-hoc 서명이며 Developer ID 서명·Apple 공증은 아닙니다.

Once the rolling beta formula reports `0.3.3-beta.1`, use `brew install hanbong5938/tap/herdr-desktop-pet-beta` or `brew update && brew upgrade herdr-desktop-pet-beta`. Stop the old daemon first and back up both actual config and state, including character revisions, preferences, dialogue and updater records. Stable and beta normally share a namespace: never run them concurrently unless both config and state are isolated. Use the same explicit directory pair for start, status and stop. CLI `--version` is insufficient: restarted `status` must report `app_version: 0.3.3-beta.1` and the expected beta bundle executable. Do not replay or delete uncertain updater reservations.

베타 포뮬러가 `0.3.3-beta.1`을 가리키는지 확인한 뒤 위 설치·업그레이드 명령을 사용하세요. 기존 데몬을 먼저 종료하고 실제 설정·상태 두 디렉터리의 캐릭터 리비전·설정·대사·updater 기록을 백업하세요. 안정판·베타 동시 실행에는 설정과 상태 모두 격리가 필요하며 시작·상태·종료에 같은 디렉터리 쌍을 지정하세요. CLI 버전뿐 아니라 재시작한 `status`의 앱 버전과 베타 번들 실행 경로를 확인하세요. 결과 불명 updater 예약은 임의로 삭제·재실행하지 않습니다.

For this beta source only: `bun run build:native && HERDR_PET_APP_NAME=HerdrDesktopPetBeta.app bun run package:native`. The inherited stable installation guide does not turn its installer into a beta installer.

이 베타 소스의 빌드는 위 명시적 beta 앱 이름 패키징 명령을 사용하세요. 상속된 안정판 설치 안내가 베타 설치기로 바뀌는 것은 아닙니다.
