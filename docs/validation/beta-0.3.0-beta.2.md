## Changes since beta/0.3.0-beta.1 / 이전 시험판 대비 변경

- Drag the grip inside the bubble's bottom-right corner to resize width and height independently in compact or expanded mode, attached or standalone. Requested sizes are saved per mode; **Restore automatic size / 자동 크기로 복원** clears both manual overrides. Screen clamping affects displayed size, not the saved request. Native input and drafts remain protected during IME composition and drag deferral. / 말풍선 본문 오른쪽 아래 조절점으로 접힌/펼친·연결/단독 상태의 너비와 높이를 각각 조절합니다. 요청 크기는 모드별로 저장되고 **자동 크기로 복원**은 두 수동 크기 설정만 지웁니다. 화면 제한은 표시 크기에만 적용됩니다. 입력기 조합·드래그 보류 중 네이티브 입력과 초안을 보호합니다.
- Native character browser for installed characters and an official catalog, with an **explicit** verified official **Download & Apply** action; browsing does not silently install characters. Rubelia remains the only bundled character. This describes the feature, **not** a claim that a live official download was exercised. / 설치 캐릭터와 공식 카탈로그용 네이티브 브라우저 및 **명시적으로** 실행하는 검증된 공식 **다운로드 및 적용** 동작을 추가했습니다. 목록 열기만으로 캐릭터를 설치하지 않습니다. 기본 제공 캐릭터는 루벨리아 하나입니다. 이 기능 설명은 실제 공식 다운로드를 실행했다는 주장이 아닙니다.
- **Running first / 실행 중 우선** moved from a separate checkbox into the **Sort / 정렬** menu, below Stable/Name/Source (기본순/이름순/출처순); it remains an independent choice and the closed title shows both choices. / 별도 체크박스였던 **실행 중 우선**을 **정렬** 메뉴의 세 기준 아래로 옮겼습니다. 독립 선택이며 닫힌 메뉴 제목에도 두 선택이 표시됩니다.
- Rig bubble attachment now uses coherent native snapshots and keeps a compatible last valid visual anchor through temporary renderer unavailability. Character clicks/reactions no longer cause continuous attachment drift; intentional movement and scale or renderer changes still reposition it. / rig 말풍선 부착은 일관된 네이티브 스냅샷을 사용하고 렌더러가 일시적으로 미준비일 때 호환되는 마지막 정상 시각 기준점을 유지합니다. 캐릭터 클릭·반응 중 기준점의 지속적인 흔들림을 줄이되 의도적 이동·배율·렌더러 변경 시에는 다시 배치합니다.
- Validation checklists are separate from Wiki source documents, preventing release/Wiki documentation processing from treating manual checklists as Wiki pages. / 수동 검증 점검표와 Wiki 원본 문서를 분리하여 릴리스·Wiki 문서 처리에서 점검표를 Wiki 페이지로 취급하지 않습니다.

Beta1's native session Search, Status filter, Sort and cross-source Running first remain: search and filter intersect before sorting and the 128-card display cap; Search does not send replies, and hidden selected drafts remain in memory without automatically reopening. Native automation and conflict-aware dialogue drafts also remain. See the [source behavior and limitations](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.3.0-beta.2/docs/releases/unreleased.md) and [English](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.3.0-beta.2/readme.md) / [한국어](https://github.com/hanbong5938/herdr-desktop-pet/blob/beta%2F0.3.0-beta.2/readme.ko.md) runtime guides. / beta1의 네이티브 세션 검색·상태 필터·정렬·전체 출처 대상 실행 중 우선은 유지됩니다. 검색·필터는 정렬과 128개 표시 제한 전에 함께 적용됩니다. 검색창은 답장을 전송하지 않으며 숨겨진 선택 카드의 초안은 메모리에 남지만 자동으로 다시 열리지 않습니다. 네이티브 자동화와 충돌을 고려한 대사 초안도 유지합니다. 자세한 동작·제한은 위 태그 고정 문서를 참고하세요.

## Download and safe upgrade / 다운로드와 안전한 이전

Apple Silicon (arm64), macOS 13 or later only. From the actual [beta2 Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.0-beta.2), obtain `HerdrDesktopPet-v0.3.0-beta.2-macos-arm64.tar.gz` and `HerdrDesktopPet-v0.3.0-beta.2-macos-arm64.tar.gz.sha256` (or `SHA256SUMS` if provided). Compare the downloaded archive SHA-256 with the published checksum **before** extracting. The archive should contain `HerdrDesktopPetBeta.app` with an actual arm64 bundle executable at `HerdrDesktopPetBeta.app/Contents/MacOS/herdr-desktop-pet`, **not a bare symlink** standing in for the executable. The app is ad-hoc signed, **not signed with a Developer ID and not notarized**; do not mistake this for Apple notarization. Do not use the stable installer, `--prebuilt`, stable tap formula, or historical rolling beta formula as a way to fetch this exact beta2 artifact.

Apple Silicon(arm64)·macOS 13 이상 전용입니다. 실제 [beta2 Release](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.3.0-beta.2)에서 `HerdrDesktopPet-v0.3.0-beta.2-macos-arm64.tar.gz`와 `HerdrDesktopPet-v0.3.0-beta.2-macos-arm64.tar.gz.sha256`(제공된다면 `SHA256SUMS`도 가능)을 받고 **압축 해제 전에** 게시된 체크섬과 다운로드 파일의 SHA-256을 대조하세요. 아카이브에는 `HerdrDesktopPetBeta.app` 및 단순 symlink가 **아닌 실제 arm64 번들 실행 파일** `HerdrDesktopPetBeta.app/Contents/MacOS/herdr-desktop-pet`이 있어야 합니다. 앱은 ad-hoc 서명이며 **Developer ID 서명이나 Apple 공증을 받지 않았습니다**. 안정판 설치기·`--prebuilt`·안정판 tap 포뮬러·과거 순환 베타 포뮬러로 이 정확한 beta2 자산을 받을 수 있다고 가정하지 마세요.

**Before starting:** quit the existing app, stop its running daemon and any host that can automatically restart it, and back up **both** the actual config and state directories. Include `preferences.json`, `lifecycle.json`, `characters/`, and `menu-bar-icons/` in the config backup. Stable and beta normally share profile/control namespaces: never run both against the same paths. For an isolated beta, use *the same pair* of `--config-dir` and `--state-dir` paths on **stop, start and status**; isolate both paths separately for any concurrently running stable app. Injected environment paths can take precedence, so inspect them as well. For example, after extracting into a trusted location, set `BETA` to that bundle's real CLI and choose private absolute directories:

**시작 전:** 기존 앱과 데몬, 이를 자동 재시작할 수 있는 호스트를 종료하고 실제 **설정과 상태 디렉터리 두 곳 모두** 백업하세요. 설정 백업에는 `preferences.json`, `lifecycle.json`, `characters/`, `menu-bar-icons/`를 포함하세요. 안정판과 베타는 보통 프로필·제어 네임스페이스를 공유하므로 같은 경로에서 동시 실행하지 마세요. 격리 베타의 **종료·시작·상태 확인**에 `--config-dir`·`--state-dir` **같은 두 경로**를 매번 지정하고, 동시 실행하는 안정판도 양쪽 경로를 별도로 분리하세요. 주입된 환경 경로가 우선할 수 있으므로 함께 확인하세요. 다음 예시는 신뢰할 수 있는 위치에 압축을 푼 뒤 실제 번들 CLI와 개인용 절대 경로를 사용합니다.

```sh
BETA="/absolute/path/to/HerdrDesktopPetBeta.app/Contents/MacOS/herdr-desktop-pet"
CONFIG="/absolute/private/path/to/beta2-config"
STATE="/absolute/private/path/to/beta2-state"
"$BETA" --config-dir "$CONFIG" --state-dir "$STATE" stop
"$BETA" --version
"$BETA" --config-dir "$CONFIG" --state-dir "$STATE" start
"$BETA" --config-dir "$CONFIG" --state-dir "$STATE" status
# Later, using the same paths / 나중에도 같은 경로 사용:
"$BETA" --config-dir "$CONFIG" --state-dir "$STATE" stop
```

Stop an already running **shared-profile** daemon with its existing CLI and actual shared paths **before** the isolated example; isolated `stop` cannot stop a daemon in another namespace. Expect `0.3.0-beta.2` from `--version`, then check `status` for `app_version: 0.3.0-beta.2` **and the actual running executable path** pointing at this beta bundle; `start` may reuse an old daemon and `--version` alone proves only the CLI. Do not replace the live stable profile with an unbacked beta profile. For rollback, stop beta and restore the matching pre-beta config **and state** backups before restarting the previous app. / 위 격리 예시를 실행하기 **전에** 공유 프로필의 기존 데몬은 기존 CLI와 실제 공유 경로로 종료하세요. 격리 경로의 `stop`은 다른 네임스페이스의 데몬을 종료하지 않습니다. `--version`의 `0.3.0-beta.2`와 함께 `status`의 `app_version: 0.3.0-beta.2` 및 이 베타 번들을 가리키는 **실제 실행 파일 경로**를 확인하세요. `start`는 기존 데몬을 재사용할 수 있어 `--version`만으로는 교체를 증명하지 못합니다. 백업 없이 베타로 안정판 실사용 프로필을 덮어쓰지 마세요. 되돌릴 때는 베타를 종료하고 베타 사용 전의 짝이 맞는 **설정·상태** 백업을 복원한 뒤 이전 앱을 시작하세요.
