# Herdr Desktop Pet

[Herdr](https://herdr.dev)용 네이티브 macOS 데스크톱 캐릭터입니다. 기본 캐릭터인 루벨리아가 데스크톱에서 터치에 반응하고, 말풍선으로 관측된 Herdr 세션 상태를 표시하며 선택한 에이전트 세션에 메시지를 제출할 수 있습니다.

[English](readme.md) · **한국어** · [버전 문서](docs/releases/README.ko.md) · [릴리스](https://github.com/hanbong5938/herdr-desktop-pet/releases)

> **안정판 v0.2.0은 현재 릴리스와 기본/사전 빌드 설치 대상이며, 이 체크아웃에는 아래 미출시 변경도 있습니다.** 배포된 네이티브 기능에는 캐릭터·말풍선 독립 표시, 간결한 관찰 설정, 단독·원격 전용 watcher 시작, 문맥 설정, 선택 가능한 메뉴 막대 표시·이미지, 연결 워크트리 삭제, 답장 배치·클립보드 및 잘못된 링크 스캐너 수정이 포함됩니다. 이전 v0.1.11 바이너리와 변경 불가한 beta1/2/3 릴리스는 별도의 과거 채널입니다. [v0.2.0 릴리스 기록](docs/releases/v0.2.0.md) · [이전 안내](docs/migrations/v0.1.11-to-v0.2.0.md#한국어) · [과거 로컬 프리뷰 안내](docs/migrations/unreleased.ko.md)를 참고하세요. 실제 사전 빌드 공개 여부는 이 소스 안내가 아닌 릴리스 목록의 자산으로 확인하세요.

## 주요 기능

- 메뉴 막대에서 제어하는 네이티브 데스크톱 캐릭터
- 유휴·실행 중·입력 대기·상태 불명에 대응하는 캐릭터 상태
- 작업 제목·작업 공간·탭 정보와 관찰 대상을 표시하고 별도 상태 표시로 구분하는 세션 카드
- 펼친 말풍선의 로컬 에이전트 카드 아래 한 줄 답장칸(v0.1.6부터 배포); 원격 카드는 읽기 전용. [v0.1.4 → v0.1.6 이전 안내](docs/migrations/v0.1.4-to-v0.1.6.md#한국어)를 참고하세요.
- 머리·몸통 탭 반응, 머리 쓰다듬기, 이동 및 크기 조절
- 말풍선 위치·표시 여부와 로컬·원격 관찰 대상 설정; 이 미출시 체크아웃에서는 드래그로 말풍선 크기를 독립 조절
- 설정에서 켜고 끄는 상태 아이콘·색상 표시와 대사에 가려지지 않는 상태 요약
- 전체 창 또는 투명 영역 클릭 통과
- 영어·한국어 UI
- PNG·rig 캐릭터 팩 가져오기 및 리비전 관리; 미출시 소스 체크아웃에서는 네이티브 캐릭터 브라우저의 설치·공식 카탈로그 검색과 명시적 다운로드·적용
- 캐릭터 팩을 수정하지 않는 캐릭터별 한국어·영어 대사 편집
- 캐릭터·말풍선 독립 표시와 단독 말풍선, 항상 표시(기본)/복구 시 표시 메뉴 막대 아이콘 및 사용자 지정 PNG
- 간결한 로컬·원격 관찰 설정, 명령 복사만 제공하는 재연결 UI와 단독 원격 전용 watcher 시작
- 문맥 설정과 적격 로컬 연결 워크트리 삭제(무시된 파일도 삭제)

기본 제공 캐릭터는 루벨리아(`default@0`) 하나입니다. 추가 캐릭터와 의상 팩은 [별도 캐릭터 저장소](https://github.com/hanbong5938/herdr-characters)에서 관리합니다. 공개 v0.2.0에서는 직접 가져와야 하며, 이 미출시 소스 체크아웃의 캐릭터 브라우저에서는 공식 카탈로그에 게시된 지원 팩을 명시적으로 다운로드하고 적용할 수 있습니다. 말풍선은 관측된 Herdr 세션 상태를 표시하고, 제공자의 결과를 추측하지 않습니다. 메시지 제출 성공은 Herdr가 요청을 접수했다는 뜻이지 에이전트가 처리를 마쳤다는 뜻이 아닙니다.

세션 카드는 관측된 터미널 제목, 이름이 지정된 탭, 작업 공간·디렉터리 정보 순서로 이름을 선택합니다. 이름이 없으면 대체 이름을 표시하고, 동명이면 구분자를 추가합니다. 카드에 마우스를 올리면 전체 제목·작업 경로·내부 ID를 확인할 수 있습니다. 제목이 바뀌어도 선택·스크롤은 유지되며, 연결이 끊기면 마지막 제목과 오프라인 상태를 표시합니다.

메뉴바 설정 패널을 열 때 최신 macOS API로 앱 활성화를 요청하며, macOS 13용 호환 경로도 유지합니다. 활성화 허용 여부는 macOS가 결정하므로, 패널을 열어도 다른 앱의 키보드 포커스가 반드시 이동하는 것은 아닙니다.

### 세션 목록 검색·정렬 (미출시 소스 체크아웃 전용)

펼친 말풍선의 새 네이티브 목록 조작 기능은 **안정판 v0.2.0 또는 변경 불가한 beta1·beta2·beta3 바이너리에 없습니다**. 이 체크아웃을 `--source`로 명시적으로 빌드해야 합니다. 공개 기본/사전 빌드 설치기는 안정판 v0.2.0을 설치합니다. 아래 인라인 답장은 기존 출시 버전에서도 사용할 수 있습니다. 이 안내는 `beta/0.3.0-beta.1` 자산 공개나 실제 GUI·IME 시험 통과의 근거가 아닙니다.

**검색**에는 제목·탭·작업 공간·에이전트 이름·관찰 대상 표시 이름·전체 작업 디렉터리·대체 이름의 일부를 입력하세요(대소문자 무시, 앞뒤 공백 제거). ID·소켓 경로는 검색 대상이 아닙니다. **상태** 필터와 검색은 동시에 적용되며 전체 관측 상태 요약·반응은 바뀌지 않습니다. **정렬 → 기본순**(기존 순서)·**이름순**·**출처순**을 선택할 수 있습니다. 별도 스위치인 **실행 중 우선**을 켜면 모든 관찰 대상의 실행 중 카드를 다른 카드보다 먼저 묶은 다음, 선택한 정렬을 각 묶음에 적용합니다. GUI는 필터·정렬 뒤 최대 128개 카드를 표시하며 일치·생략 수는 전체 일치 카드와 표시 한도 밖의 카드를 각각 셉니다. GUI 표시 한도와 달리 미출시 CLI의 `sessions list --limit`는 페이지 크기이며 일관된 전체 페이지를 수집합니다.

처음에는 빈 검색어, **전체**, **기본순**, **실행 중 우선** 꺼짐 상태입니다. 정렬·실행 중 우선은 저장 성공 시에만 재실행 후에도 유지되고, 저장에 실패하면 조작 상태가 이전으로 돌아갑니다. 검색어와 상태 필터는 메모리에만 유지됩니다. 검색·필터로 선택한 답장 카드가 숨겨지면 답장칸은 접히지만 해당 세션 초안은 메모리에 남고, 검색을 지워도 자동으로 다시 열리지 않습니다. 검색창에 포커스가 있으면 **Enter**·**Command+Enter**로 답장이 전송되지 않습니다. **Escape**는 검색 입력기(IME) 조합을 먼저 취소하고, 그다음 검색어를 지우고, 빈 검색창에서는 말풍선을 접지 않은 채 포커스를 끝냅니다. 검색창·답장칸의 조합은 각각 목록 구조 변경을 조합 종료까지 보류하지만 실시간 상태는 계속 갱신됩니다.

### 카드별 인라인 답장

카드별 답장은 v0.1.6부터 배포되었고 안정판 v0.2.0에는 글자 잘림을 고친 네이티브 배치와 Command-A/C/X/V 클립보드 단축키가 포함됩니다. 실제 키보드·IME 동작은 앱을 실행한 GUI 세션에서 확인해야 하며 AppKit 프로그램 시험만으로 물리적 입력을 인증하지 않습니다.

말풍선을 펼치면 세션 카드가 보이고 답장칸은 처음에는 숨겨져 있습니다. **전체** 보기에도 답장칸은 없습니다. 로컬 에이전트 세션 카드를 누르면 해당 카드 아래에 한 줄 답장칸이 열리고, 다른 세션을 누르면 이전 답장칸을 접고 새 카드에 엽니다. 원격 카드에는 답장칸이나 보내기 버튼 대신 읽기 전용 안내만 표시합니다. 타이핑·붙여넣기·텍스트 가져오기를 포함한 모든 확정 입력의 줄바꿈은 공백으로 바꾸어 한 줄 답장칸에 표시하며, 입력기(IME)의 미확정 조합 문자는 확정될 때까지 그대로 둡니다. **Enter**·**Command+Enter** 또는 **보내기**로 제출합니다. 입력기 조합 중에는 제출되지 않습니다. **Escape**는 조합 중이면 먼저 조합을 취소하고, 아니면 답장칸만 접습니다. 말풍선 밖을 눌러도 답장칸만 접지만 조합 중에는 접히지 않습니다. 말풍선 내부에서 답장칸 밖을 누르는 것만으로는 자동으로 접히지 않으며, 어느 동작도 말풍선을 접지 않습니다. 초안은 답장칸이나 말풍선을 접어도 세션별로 메모리에 유지되지만 앱을 다시 실행하면 복원되지 않습니다. 전송에 성공하면 현재 입력과 일치하는 답장만 지우고 답장칸을 접습니다. 전송 중 내용을 수정하거나 다른 세션을 선택했다면 새 초안이나 열린 답장칸은 유지합니다. 실패하거나 전달 여부를 알 수 없는 경우에는 초안과 답장칸 상태를 보존합니다.

입력기 조합 중에는 조합 문자를 버리지 않고 카드 선택·필터 변경·행 교체를 보류합니다. 조합이 끝나면 마지막 필터와 여전히 표시되는 유효한 세션 선택만 적용하며, 확정된 문자는 원래 세션과 연결 세대의 초안으로 유지합니다. 선택 이동이 보류되어도 실시간 상태와 전송 가능 여부는 계속 갱신됩니다.

답장칸은 입력 영역을 구분하는 테두리와 말풍선 팔레트에서 혼합한 불투명 배경을 사용합니다. 작은 네이티브 보내기 버튼은 기존 전송 가능 여부를 따르며, 테마를 바꿔도 초안과 입력기 조합 내용은 유지됩니다.

### 메시지 전달 (사전 빌드·소스 빌드 공통)

메시지는 선택한 로컬 Herdr 소스의 `agent.prompt` API로만 전달하며 전역 CLI·셸·SSH·터미널 패널 직접 입력으로 대신 보내지 않습니다. 로컬 관찰을 끄거나 소스가 오프라인이거나 세션이 오래되었거나 준비되지 않았거나 서버가 이 메서드를 지원하지 않으면 보낼 수 없습니다. 원격 소스는 마지막으로 관측된 카드가 남아 있어도 읽기 전용이며 메시지를 전송할 수 없습니다. `unsupported_method` 응답은 지원 불가로 알리며 다른 경로로 우회하지 않습니다. 승인·질문 UI는 실제 터미널에서 처리해야 합니다. Herdr 0.9.2에서 이 API가 확인되었으며 로컬 관찰에 필요한 0.9.0만으로 실행 중인 서버의 `agent.prompt` 지원을 보장하지는 않습니다. 전달 여부를 알 수 없는 경우에는 확인 없이 수동으로 다시 보내지 마세요. 앱은 자동 재시도하지 않습니다. 현재 API는 패널의 현재 에이전트를 대상으로 하며 예상 세션을 원자적으로 검증하는 기능이 없으므로 제출 순간 패널의 에이전트·세션이 바뀌는 경합은 배제할 수 없습니다.

## 요구 사항

| 항목 | 요구 사항 |
| --- | --- |
| 플랫폼 | Apple Silicon Mac, macOS 13 이상 |
| 이번 실행 관리 기능의 Herdr | **공식 Herdr 0.9.3 소스에 [제공된 client-attach 패치](integrations/herdr/client-attached.patch)를 적용해 빌드한 호스트** (또는 추후 실제로 이 훅 지원을 명시한 호스트 릴리스) |
| 앱 | 고정된 안정판 v0.2.0 사전 빌드(플러그인 설치 프로그램 또는 Homebrew, 빌드 도구 불필요) 또는 이 체크아웃의 소스 빌드: Rust/Cargo, Bun, Node.js/npm, Xcode Command Line Tools |

**클라이언트 attach 자동 실행에는 제공된 패치가 필수입니다.** 순정 Herdr 0.9.0과 0.9.3에는 `client.attached`가 없습니다. 매니페스트의 최소 버전만으로 훅 지원이 보장되지 않습니다. 공식 0.9.3 소스에 패치를 적용하고 해당 호스트의 빌드 안내에 따라 빌드·실행한 뒤, 플러그인 연결 경고와 `client.attached` 구독 수락 여부를 확인하세요. 알 수 없는 훅 경고는 성공으로 간주하지 마세요. Intel Mac·Windows·Linux용 네이티브 배포는 지원하지 않습니다.

## Herdr 플러그인으로 설치 (권장)

다른 Herdr 플러그인과 같은 방식으로 공개 [플러그인 저장소](https://github.com/hanbong5938/herdr-desktop-pet)에서 설치합니다.

```sh
herdr plugin install hanbong5938/herdr-desktop-pet
herdr plugin action invoke start --plugin desktop-pet
```

Herdr는 저장소를 플러그인 디렉터리에 클론하고 매니페스트의 `[[build]]` 단계인 `bash scripts/install.sh`를 실행합니다. 설치 프로그램은 매니페스트 `version`에 고정된 릴리스(v0.2.0)를 `curl`로 HTTPS를 통해 익명으로 내려받아 SHA-256 체크섬·아카이브 경로 및 항목 유형·arm64 아키텍처·코드 서명·기본 캐릭터를 검증한 뒤 플러그인 디렉터리의 `dist/`에 설치합니다. 일반적으로 GitHub 로그인이나 빌드 도구가 필요하지 않으며 플러그인 디렉터리 밖에는 설치하지 않습니다. 고정된 사전 빌드를 사용할 수 없거나 검증에 실패하면 안내를 출력하고 소스 빌드로 전환하며 이때는 위의 소스 빌드 도구가 필요합니다. 앱은 **ad-hoc 서명·미공증**이며 브라우저·cask 대신 `curl`로 받으므로 격리 속성이 붙지 않아 macOS Gatekeeper 확인 창이 뜨지 않습니다. 클라이언트 attach 자동 실행에는 위의 패치된 Herdr 호스트로 명령을 실행하세요.

저장소에 `herdr-plugin` 토픽을 지정해 [Herdr 마켓](https://herdr.dev/plugins/) 자동 수집 대상으로 등록했습니다. 인덱스는 30분마다 갱신되며 Herdr의 심사를 거친 목록은 아닙니다.

## Homebrew로 설치

[개인 tap](https://github.com/hanbong5938/homebrew-tap)의 안정판 v0.2.0 포뮬러로 사전 빌드 앱과 `herdr-desktop-pet` CLI를 설치합니다. 사전 빌드 사용 전 [릴리스 목록](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/v0.2.0)에서 자산 공개 여부를 확인하세요.

```sh
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status
```

기존 안정판 사용자는 먼저 **실행 중인 데몬을 종료**하세요. `start`는 기존 데몬을 재사용하므로 CLI `--version`만으로 교체를 확인할 수 없습니다.

```sh
herdr-desktop-pet stop
brew update && brew upgrade herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status
```

`--version`이 `0.2.0`이고 `status`의 `app_version` 및 실행 파일이 이전 바이너리가 아닌 안정판 v0.2.0인지 확인하세요. Homebrew에서 포뮬러 로딩을 거부할 때만 `brew trust --formula hanbong5938/tap/herdr-desktop-pet`으로 해당 포뮬러에만 신뢰를 부여하세요. 포뮬러는 `HerdrDesktopPet.app`을 `/Applications`가 아닌 Homebrew 접두 경로에 두고 CLI를 `PATH`에 추가합니다. 앱만 설치하고 Herdr 플러그인이나 패치된 호스트는 설치하지 않습니다. 시작 훅에는 위 플러그인 설치, client-attach 자동 실행에는 호스트 패치가 필요합니다. 앱은 ad-hoc 서명·미공증이며 포뮬러 설치에는 격리 속성이 붙지 않습니다. `brew uninstall herdr-desktop-pet`은 캐릭터 팩·설정·실행 관리 상태를 보존합니다. [이전·되돌리기 안내](docs/migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요.

이전 버전은 앱을 `/Applications`에 복사하는 Homebrew cask로 배포했습니다. 기존 cask 설치는 제거한 뒤 포뮬러를 설치해 옮기세요(데이터는 유지됩니다).

```sh
brew uninstall --cask herdr-desktop-pet
brew install hanbong5938/tap/herdr-desktop-pet
```

## 과거 베타 채널 (안정판 설치 아님)

Apple Silicon·macOS 13 이상용 변경 불가한 [`beta/0.2.0-beta.3`](https://github.com/hanbong5938/herdr-desktop-pet/releases/tag/beta%2F0.2.0-beta.3)과 별도의 순환 베타 Homebrew 포뮬러는 안정판 v0.2.0·기본 설치 프로그램과 다른 **과거 시험 채널**입니다. beta1에는 답장 글자 잘림이 있고 beta2는 글자 잘림·잘못된 링크 스캐너를 수정했지만 답장 Command-A/C/X/V 연결은 없습니다. beta3에는 클립보드 수정도 포함되며 안정판 v0.2.0은 beta3의 네이티브 수정을 포함합니다. beta3에서 안정판으로 옮길 때는 베타를 종료하고 공유 프로필을 백업한 뒤 **베타 포뮬러가 아닌 안정판 포뮬러**를 설치/업그레이드하세요. [이전 안내](docs/migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요. AppKit 프로그램 입력 시험은 물리적 키보드·IME·이미지 선택·확인 창 키·포인터·VoiceOver 인증이 아닙니다.

과거 베타 포뮬러는 `HerdrDesktopPetBeta.app`을 `/Applications`가 아닌 Homebrew 접두 경로에 설치하며 `herdr-desktop-pet-beta`는 안정판 CLI와 별도입니다. 공유 프로필에서 beta3을 실행 중이라면 안정판 설치·시작 전에 먼저 베타를 종료하세요.

```sh
herdr-desktop-pet-beta stop
brew install hanbong5938/tap/herdr-desktop-pet
herdr-desktop-pet --version
herdr-desktop-pet start
herdr-desktop-pet status
```

안정판 포뮬러가 이미 설치됐다면 기존 안정판 데몬도 종료하고 `brew install` 대신 `brew update && brew upgrade herdr-desktop-pet`을 실행하세요. 실제 설정·상태 디렉터리를 **둘 다** 백업하고 `preferences.json`, `lifecycle.json`, `characters/`, 관리되는 `menu-bar-icons/`를 포함하세요. 베타 격리 프로필은 종료·시작에 같은 경로를 사용합니다. 양쪽의 설정과 상태를 모두 격리하지 않으면 동시 실행하지 마세요. 변경 불가 beta3 아카이브 SHA-256 `14bf452aa492fa520a4979ca3e18711e505c52c178c1e1e2edb355b2b07b0920`과 공개·설치 증거는 안정판 체크섬/증거가 아니라 [과거 베타 안내](docs/migrations/unreleased.ko.md#선택형-수동-베타-테스트)에 있습니다. 수동 다운로드한 베타 앱은 ad-hoc 서명으로 Gatekeeper 승인이 필요할 수 있습니다. 필요 없다면 `brew uninstall herdr-desktop-pet-beta`로 베타만 제거하고 워크트리 삭제 시험에는 폐기 가능한 연결 체크아웃만 사용하세요.

## 이 체크아웃 설치: 소스 빌드

개발 체크아웃에서는 `plugin link`가 매니페스트 `[[build]]`를 실행하지 않으므로 직접 빌드해야 합니다. 현재 공개 `main`은 아래 안정판 v0.2.0 네이티브 기능을 포함하며 `--source`는 다른 릴리스가 아닌 실제 체크아웃을 빌드합니다. 클라이언트 attach 자동 실행은 [패치된 호스트의 격리된 XDG 프로필 안내](integrations/herdr/README.md)에 따라 실행하고 `PATH`의 순정 `herdr` 대신 안내의 `PATCHED_HERDR` 바이너리를 명시적으로 사용하세요.

```sh
bash scripts/install.sh --source
"$PATCHED_HERDR" plugin link "$PWD" --enabled
"$PATCHED_HERDR" plugin action invoke start --plugin desktop-pet
```

소스 설치 프로그램은 고정된 JavaScript 의존성을 설치하고 Rust 실행 파일을 빌드하며 네이티브 rig 런타임·캐릭터 제작 리소스를 패키징한 뒤 앱을 검증합니다. 이미 실행 중인 서버에서 플러그인을 연결·활성화하는 것만으로는 캐릭터가 바로 실행되지 않습니다. `start`를 한 번 실행하거나 `auto_start`가 켜졌다면 이후 정상적인 shell/terminal 클라이언트 attach를 기다리세요. 서버 시작 시에도 자동 `ensure`가 실행됩니다. 연결 중 알 수 없는 `client.attached` 훅 경고가 뜨면 호스트에 필수 패치가 없는 것입니다. 플러그인 액션은 실행 중인 활성화된 Herdr 호스트가 필요하며 아래 네이티브 설정 명령은 호스트 없이도 동작합니다.

미출시 자동화 명령은 사전 빌드나 구형 데몬이 아닌 방금 빌드한 체크아웃 실행 파일 `./dist/HerdrDesktopPet.app/Contents/MacOS/herdr-desktop-pet`을 사용하세요. 기존 데몬을 먼저 종료하거나 `start`·후속 명령·`stop`에서 설정과 상태 경로를 모두 격리해 일치시키세요. 바이너리 버전이 둘 다 `0.2.0`일 수 있으므로 의도한 데몬 시작 후 이 소스 실행 파일의 `status`에서 실제 데몬 실행 파일을 확인하세요.

### 과거 로컬 프리뷰 출처

단독·원격 전용 watcher, 독립 표시, 간결한 관찰 설정, 문맥 설정·조건부 복구는 이전 로컬 `worktree/rapid-harbor-d2a6`의 네 커밋(`078f5c2`, `e828c77`, `f638f0c`, `bf23ced`)에서 시작됐습니다. 이후 메뉴 막대 모드·이미지와 워크트리 삭제는 `bf23ced`에는 없었습니다. 이 기능은 beta3에 포함되었고 이제 안정판 v0.2.0 `main`에도 있으므로 특별한 로컬 브랜치·로컬 전용 가져오기 안내는 필요하지 않습니다. 과거 `bf23ced` 체크아웃만 있으면 원래 조건부 복구 동작을 사용하며 이후 추가 기능은 없습니다. [과거 프리뷰 기록](docs/migrations/unreleased.ko.md)을 참고하세요.

### 공통 설치 프로그램 동작

`bash scripts/install.sh --prebuilt`는 이 체크아웃의 `herdr-plugin.toml`에 고정된 버전을 git `origin` 저장소(없으면 `HERDR_PET_REPOSITORY`, 그다음 `hanbong5938/herdr-desktop-pet`)에서 `curl`로 HTTPS를 통해 익명으로 내려받습니다(GitHub 로그인 불필요). SHA-256·아카이브 경로 및 항목 유형·arm64·코드 서명·기본 캐릭터를 검증하며 **소스 빌드로 전환하지 않습니다**. 사전 빌드 실행에는 빌드 도구가 필요하지 않지만 client-attach 자동 실행에는 패치된 호스트가 필요합니다. 옵션 없는 설치는 고정된 사전 빌드를 사용하고 사용할 수 없거나 유효하지 않을 때만 소스로 전환합니다. 로컬 변경을 빌드하려면 `--source`를 명시하세요. 앱은 **ad-hoc 서명이며 Developer ID 서명·공증은 없습니다**. 설치 프로그램의 `curl`·git·Homebrew formula 설치는 격리 속성을 설정하지 않습니다. 브라우저로 내려받은 아카이브는 앱 실행을 명시적으로 승인해야 할 수 있습니다.

버전별 변경과 과거 그림의 한계는 [릴리스 기록](docs/releases/README.ko.md)에서 관리합니다. 이전 여러 줄 입력창의 Enter·Escape 변경은 [v0.1.4 → v0.1.6 이전 안내](docs/migrations/v0.1.4-to-v0.1.6.md#한국어)를 참고하세요.

| 대화창 배경·카드 헤더 우클릭 / Control-click | **대화창 닫기**는 대화창만 숨김; **자동 크기로 복원**은 접힌·펼친 모드의 사용자 크기를 모두 해제 |
| 전체 창 클릭 통과 | 캐릭터와 말풍선 창 모두 클릭을 통과시켜 상호작용 비활성화 |
| 투명 영역 클릭 통과 | 캐릭터 그림의 투명 영역만 클릭 통과; 말풍선은 계속 조작 가능 |

접힌·펼친 말풍선 크기는 각각 저장되며 캐릭터 연결·단독 상태에서 같은 값을 사용합니다. 조절점은 캐릭터 배율이나 글자 크기를 바꾸지 않습니다. 펼친 모드의 메시지·카드 스크롤 영역은 자동 배치의 높이 제한 대신 확보한 공간을 사용합니다. 작은 화면에서는 표시 크기만 제한하고 요청한 크기는 보존하므로, 충분한 화면 공간이 생기면 복원할 수 있습니다.

입력기(IME) 조합 중에는 크기 조절이나 **자동 크기로 복원**을 시작할 수 없습니다. 누른 뒤 조합이 시작되면 미리보기를 멈추고, 손을 놓거나 네이티브 취소가 일어나면 포인터 추적을 해제하되 조합이 안전하게 끝나고 추적도 종료될 때까지 저장과 보류된 갱신을 미룹니다. 그동안 표시된 카드와 답장 초안은 유지합니다. 마지막 크기 후보는 최신 내용·언어·배치와 화면 제한을 반영하고 조작 종료 시 한 번만 저장합니다. 저장 실패 시 이전 요청 크기, 단독 상태의 이전 실제 위치, 저장 대기 상태를 복구하며 후속 유령 저장은 하지 않습니다. 다만 최신 내용의 최소 크기에 따라 화면 배치가 달라질 수 있으므로 이전 픽셀 크기를 그대로 복구한다는 뜻은 아닙니다. **자동 크기로 복원**은 위치·표시 여부·현재 모드·답장 초안을 유지합니다. 위치 초기화·색상 초기화는 사용자 크기를 지우지 않습니다.

대화창 우클릭 메뉴를 취소하면 카드 선택과 초안은 유지됩니다. 텍스트 영역은 기존 복사·붙여넣기 메뉴를 사용하며 버튼·드롭다운·스크롤바의 네이티브 동작도 유지합니다. 입력기(IME) 조합 중에는 **대화창 닫기**가 비활성화되므로 조합을 마친 뒤 메뉴를 다시 열어 닫으세요. 메뉴바 패널의 **말풍선 → 말풍선 표시 여부**를 켜면 다시 열 수 있습니다. 닫기는 기존 말풍선 표시 설정에 저장되며, 답장 초안은 현재 앱 실행 중 메모리에 유지됩니다.

답장에 입력기(IME) 미확정 문자가 있는 동안에는 메뉴 막대 아이콘에서 설정 패널을 직접 열 수 없습니다. 조합을 마친 뒤 사용하세요. 설정 패널은 기존처럼 Escape나 패널 밖 클릭으로 닫을 수 있습니다.

### 독립 표시와 메뉴 막대 복구

안정판 v0.2.0에는 독립 표시와 문맥 메뉴 진입이 포함됩니다. 캐릭터 또는 대화창 배경·카드 헤더를 우클릭/Control-click하여 **설정…**으로 전체 3탭 패널을 엽니다. 앱 활성화는 요청할 뿐 보장하지 않습니다. 대화창 메뉴에는 숨겨진 **캐릭터 표시**도 있습니다. 설정과 관리 아이콘 파일 보존 방법은 [이전 안내](docs/migrations/v0.1.11-to-v0.2.0.md#한국어)를 참고하세요.

캐릭터 표시(`show`/`hide`/`toggle`)와 **설정 → 말풍선 → 말풍선 표시 여부**(`show_bubble`/`hide_bubble`)는 서로 독립적입니다.

| 캐릭터 표시 | 말풍선 표시 | 결과 |
| --- | --- | --- |
| 켜짐 | 켜짐 | 말풍선이 캐릭터에 붙음 |
| 켜짐 | 꺼짐 | 캐릭터만 표시 |
| 꺼짐 | 켜짐 | 꼬리 없는 이동 가능한 단독 말풍선; 세션 카드와 답장도 사용 가능, 대화창 우클릭 메뉴의 **캐릭터 표시**로 복원 |
| 꺼짐 | 꺼짐 | 두 창 모두 숨김; 앱과 Herdr 세션은 계속 실행하며 어느 아이콘 표시 모드에서나 메뉴 막대 아이콘을 좌클릭해 설정을 바로 열거나 우클릭/Control-click해 복구 메뉴를 열 수 있음 |

캐릭터를 숨겨도 저장된 말풍선 표시 설정은 바뀌지 않습니다. 저장된 단독 위치가 없을 때 처음 분리될 위치는 계산만 하고 표시하지 않은 배치가 아니라 **실제로 적용된 부착 말풍선 본문 위치**에서 가져옵니다. 단독 위치는 캐릭터 위치와 별도로 저장하며 이후 분리에서는 저장된 위치를 우선합니다(입력기 조합 중에도 동일). 배경 드래그는 말풍선만 이동합니다. 다시 캐릭터를 표시하면 말풍선이 붙고 숨기면 단독 위치로 돌아옵니다. 작은 보기·펼친 보기, 답장, 크기 재계산에서는 화면 범위 조정이 필요한 경우 외에 위치를 유지하며 디스플레이 배치 변경으로 화면 밖에 놓이면 남은 화면 안으로 복구합니다. 캐릭터 숨김·표시 중에도 실행 중 카드 선택·보기/답장 상태·초안을 유지하지만 초안은 재시작 후 복원되지 않습니다. 단독 상태에서 바꾼 배치 설정은 단독 위치를 옮기지 않고 다시 부착할 때 적용합니다. **초기화**(`reset`)는 표시 설정을 유지하고 기존 단독 위치를 지우며 필요한 경우 새로 적용된 부착 배치에서 다시 설정합니다. 캐릭터 좌표를 복사하지 않습니다.

캐릭터가 처음부터 숨겨져 저장된 단독 위치가 없다면 일반 부착 배치를 대체 위치로 계산합니다. 답장에 미확정 문자가 있으면 숨김·표시·배치·초기화 중 단독 위치 저장을 조합 종료까지 보류하며, 나중의 초기화는 예전 저장 위치보다 우선합니다. 실제 입력창의 AppKit 콜백에서는 해당 전환 뒤 조합 문자·확정 초안·선택 위치가 유지됐지만 물리적인 입력기 조작이나 키보드 포커스를 확인한 것은 아닙니다.

원래 `bf23ced` 로컬 프리뷰에서는 두 창이 숨겨지거나 전체 창 클릭 통과가 켜졌을 때만 복구 아이콘을 표시했습니다. **안정판 v0.2.0은 항상 표시가 기본값**입니다. **설정 → 메뉴 막대 아이콘**에서 **항상 표시** 또는 **복구가 필요할 때만 표시**를 선택하세요. 캐릭터·말풍선 표시와 별개입니다.

| 안정판 v0.2.0 상태 | 항상 표시 | 복구가 필요할 때만 표시 |
| --- | --- | --- |
| 캐릭터만·단독 말풍선만·두 창 모두 표시하며 조작 가능 | 아이콘 표시 | 아이콘 없음 |
| 캐릭터와 말풍선 모두 숨김 | 아이콘 표시 | 아이콘 표시 |
| 전체 창 클릭 통과 켜짐(표시 상태 무관) | 아이콘 표시 | 아이콘 표시 |
| 투명 영역 클릭 통과만 켜짐 | 아이콘 표시 | 두 창 모두 숨겨지지 않았다면 아이콘 없음 |

기본 상태 아이콘은 템플릿 발바닥 그림이며, 사용자 지정 이미지는 상태 아이템의 그림만 바꿉니다. 이 체크아웃에서는 좌클릭으로 기존 3탭 패널을 바로 열고 우클릭/Control-click으로 **설정…**과 **종료**, 복구가 필요할 때만 **캐릭터 표시·조작 복구**가 있는 네이티브 메뉴를 엽니다. 복구가 필요한 경우는 두 창 모두 숨김 또는 전체 창 클릭 통과 켜짐입니다. 복구는 캐릭터를 표시하고 전체 창 클릭 통과를 끄되 말풍선 표시 여부와 투명 영역 클릭 통과 설정은 유지합니다. 표시된 말풍선은 다시 붙고 숨긴 말풍선은 숨긴 채로 남습니다. 복구 후 **항상 표시**는 아이콘을 유지하고 **복구가 필요할 때만 표시**는 메뉴가 닫히면 아이콘을 제거합니다. 종료 중에는 어느 모드에서도 아이콘이 나타나지 않습니다. 투명 영역 클릭 통과의 포인터 폴링만으로 복구 조건이 바뀌지 않습니다. CLI `show`는 여전히 말풍선을 켜지 않고 캐릭터만 표시합니다.

네이티브 `preferences.json`의 `menu_bar_mode` 키에 `always` 또는 `recovery_only`를 저장합니다. 새 프로필이나 이 키가 없는 이전 프로필(원래 조건부 아이콘 프리뷰 포함)은 **항상 표시**를 사용하며, 과거의 조건부 동작을 저장된 사용자 선택으로 추정하지 않습니다. 저장에 성공한 선택은 즉시 적용되고 재시작·다른 환경설정 저장 후에도 유지되며 알 수 없는 환경설정 필드도 보존합니다. 저장에 실패하면 이전에 선택된 모드와 아이콘 상태가 유지됩니다. 모드를 바꿔도 창 표시 여부, 전체 창·투명 영역 클릭 통과, 캐릭터·말풍선 위치, 답장 초안, 실행 관리 설정은 바뀌지 않습니다.

안정판 v0.2.0의 **설정 → 메뉴 막대 아이콘 → 이미지 선택…**으로 정적 PNG(인코딩 최대 4 MiB, 디코딩 후 최대 100만 픽셀)를 가져오거나 **기본 아이콘 복원**으로 템플릿 발바닥으로 돌아갑니다. 애니메이션·손상·잘림·완전 투명 이미지는 거부합니다. 사용자 지정 이미지는 원래 색을 유지하고 18 pt 안에 비율에 맞게 배치하며 1×/2× Retina 표현을 제공합니다. 가져오기에 성공하면 설정 디렉터리 `menu-bar-icons/`에 관리 사본을 저장하고 선택적인 `preferences.json`의 `menu_bar_icon.asset`에 기록하므로 외부 원본을 옮기거나 삭제해도 유지됩니다. `preferences.json`, `lifecycle.json`, `characters/`와 함께 `menu-bar-icons/`를 백업하세요. 실패 시 이전 선택을 유지하고 관리 이미지가 없거나 손상되면 오류와 기본 아이콘을 표시하되 메타데이터는 보존합니다. 복원은 이미지만 바꾸고 모드·창 표시·클릭 통과·위치·초안·실행 관리는 유지합니다.

PNG를 네이티브 디코딩하기 전에 **모든 청크의 CRC**(투명도·무시하는 보조 청크·`IEND` 포함)와 `IDAT`의 zlib Adler-32를 확인합니다. 압축 해제한 `IDAT` 크기는 원래 색상 형식·비트 깊이의 스캔라인 크기 또는 Adam7의 실제 7개 패스 크기로 제한합니다. 기존 4 MiB·100만 픽셀 제한과 정적 PNG·색상 처리 방식은 그대로입니다.

새 관리 사본은 대상 이름이 없을 때만 원자적으로 게시하므로 중단돼도 새 최종 파일에 두 이름의 하드 링크가 남지 않으며 기존·안전하지 않은 대상 파일을 덮어쓰지 않습니다. 이전 방식에서 중단되어 관리 최종 파일과 앱 소유의 접근 제한된 관리 디렉터리 안의 레거시 `.icon` 임시 파일이 **같은 inode의 링크 수 2인 하드 링크**로 확인된 경우에만 **동일한 정상 PNG를 명시적으로 다시 가져와** 해당 임시 링크를 복구할 수 있습니다. 시작할 때 자동 정리·삭제하지 않으며 다른 링크나 파일은 삭제하지 않습니다. 관리 이미지가 없어 기본 그림과 오류가 표시돼도 기존 프로필·사용자 지정 아이콘 메타데이터를 유지하므로 강제 초기화 대신 필요한 경우 이 제한된 재가져오기를 사용하세요.

과거 beta3 관리 이미지 시작·보호된 복원 콜백 관찰은 [프리뷰 증거](docs/releases/unreleased.md)에 기록되어 있으며 안정판 릴리스 검증이나 실제 이미지 선택·VoiceOver 인증이 아닙니다.

대화창 우클릭 메뉴를 취소하면 카드 선택과 초안은 유지됩니다. 텍스트 영역은 기존 복사·붙여넣기 메뉴를 사용하며 버튼·드롭다운·스크롤바의 네이티브 동작도 유지합니다. 입력기(IME) 조합 중에는 대화창의 **설정…**과 **대화창 닫기**가 비활성화되고, 선택 시에도 조합 상태를 다시 확인합니다. 조합을 마친 뒤 메뉴를 다시 열어 사용하세요. 닫힌 대화창은 캐릭터 우클릭 → **설정…** → **말풍선 → 말풍선 표시 여부**를 켜서 다시 열 수 있습니다. 두 창 모두 숨겨졌다면 메뉴 막대 아이콘의 **설정…**에서 같은 설정을 사용하세요. 닫기는 기존 말풍선 표시 설정에 저장되며, 답장 초안은 현재 앱 실행 중 메모리에 유지됩니다.

### 안정판 v0.2.0: 적격 연결 워크트리 삭제

펼친 말풍선의 **카드 헤더**를 우클릭 또는 Control-click하여 **워크트리 삭제…**를 선택하면 현재 선택된 카드가 달라도 클릭한 카드를 대상으로 합니다. **말풍선 배경**에서 같은 메뉴를 열면 메뉴를 연 순간의 선택된 카드가 대상이며, 적합한 카드가 선택되지 않았다면 항목이 없습니다. 메뉴에 대상 이름이 표시됩니다. 텍스트 입력 영역의 기본 메뉴와 버튼·드롭다운·스크롤바의 기본 동작은 그대로입니다. **대화창 닫기**는 별개로 말풍선만 숨기며 체크아웃·작업 공간·세션을 삭제하지 않습니다.

확인 창에 표시되는 저장소와 **정확한 체크아웃 경로**, 선택한 카드 하나가 아닌 **작업 공간 전체**의 탭·패널 수를 검토하세요. 삭제하면 해당 작업 공간과 모든 탭·패널이 닫히고 실행 중인 프로세스·에이전트가 종료되며, 연결된 체크아웃과 **무시된 파일(빌드 결과물 등)까지 삭제**됩니다. 앱에서 되돌릴 수 없지만 Git 브랜치는 유지됩니다. 주 저장소를 삭제하거나 휴지통·실행 취소를 제공하지 않습니다. **취소**가 첫 번째이자 기본 동작(Return·숫자 키패드 Enter·Escape도 취소)이고 **워크트리 삭제**는 별도의 두 번째 동작입니다. 네이티브 확인 창은 배치 후 취소를 기본 버튼으로 명시하고 일시적인 Escape 처리로 동일한 취소 동작을 실행하며, 기본 버튼 설정에 실패하면 삭제를 중단합니다. 실행 전 경로와 영향 범위를 꼼꼼히 확인하세요.

현재 연결되어 정상 관찰 중인 일관된 로컬 소스의 유효하고 모호하지 않은 연결 워크트리 메타데이터가 있어야만 삭제할 수 있습니다. 주 저장소 루트, 원격·보관된·오프라인 카드, 선택적 메타데이터가 없거나 잘못된 카드, 필요한 메타데이터를 제공하지 못하는 구형 서버에는 삭제 항목이 나타나지 않습니다. 서버가 `worktree.remove`를 지원하지 않으면 한계를 알리며 Git·셸 명령·SSH·강제 삭제로 대체하지 않습니다. 입력기(IME) 조합 중 삭제를 비활성화하고 제출 직전에 다시 검사합니다. 한 번에 한 작업만 진행하며 확인한 대상을 고정하고 확인 창 이후 및 서버의 새 스냅샷에서 다시 검사합니다. `force: false`인 `worktree.remove` 요청을 한 번만 보내고 변경된 대상을 자동 승인하거나 재시도하거나 카드 행을 낙관적으로 지우지 않습니다. 변경된 추적·미추적 파일이나 잠긴 체크아웃은 서버가 거부할 수 있습니다. 일반적인 5초 관찰 갱신이 최종 표시의 기준이며, 행이 사라지거나 선택이 바뀌거나 말풍선을 숨겼다 다시 열어도 작업 결과 안내는 말풍선에 남습니다. 전송을 시도한 뒤 결과가 불확실하다면 **직접 다시 시도하기 전에 실제 서버·워크트리 상태를 확인**하세요. 앱은 자동 재전송하지 않습니다.

요청에는 `workspace_id`만 지정하고 예상 체크아웃·generation의 원자적 비교 후 교체(CAS)는 없습니다. 마지막 검사 뒤 서버 재시작·작업 공간 재연결을 클라이언트 재검사만으로 원자적으로 막지는 못합니다. 과거 beta3 네이티브·백엔드 관찰은 [프리뷰 증거](docs/releases/unreleased.md)에 별도로 기록되어 있으며 안정판 v0.2.0 검증이나 물리적 입력 인증으로 해석하지 마세요.

### 공통 말풍선·캐릭터 설정

안정판 v0.2.0에서는 메뉴 막대 패널이나 문맥 **설정…**에서 아래 설정을 여세요.

설정 패널의 말풍선 테마와 UI 언어는 네이티브 드롭다운으로 선택합니다. **시스템**을 선택하면 시스템 언어를 따르고, 한국어나 영어를 직접 지정할 수도 있습니다. 테마와 언어는 변경 시 저장되며, 말풍선 사용자 지정 색상은 기존 **색상 적용** 버튼으로 적용합니다.

**캐릭터** 탭은 현재 캐릭터·후보·작업 상태의 간결한 요약과 **캐릭터 브라우저 열기…**를 제공합니다. 이 미출시 체크아웃의 별도 크기 조절 가능한 네이티브 브라우저에서 이름·ID로 검색하고 공식 항목은 태그로도 검색하며 **전체 / 설치됨 / 공식 카탈로그**로 필터링하세요. 설치된 팩의 관리 메뉴에서 조회·진단·업데이트·삭제·리비전 복원을 계속 사용할 수 있습니다. 기본 루벨리아는 설치된 항목에 남습니다. 브라우저를 닫으면 창만 숨겨지고 후보·검색·필터는 유지되며 진행 중인 다운로드는 취소되지 않습니다. 실제 취소에는 작업 카드의 **다운로드 취소**를 사용하세요.

설치된 캐릭터 카드나 리비전의 **선택**은 후보만 지정하며 실행 중인 캐릭터는 바뀌지 않습니다. 후보를 확인한 뒤 브라우저 하단의 **캐릭터 적용**을 누르세요. **선택 취소**는 아직 제출하지 않은 선택만 지웁니다. **캐릭터 추가…**로 파일을 가져와도 자동 선택·활성화하지 않습니다. 공식 카드의 **다운로드 및 적용**은 파일 가져오기와 다르게 공식 아카이브 다운로드·검증·설치·선택을 하나의 작업으로 요청하고, 커밋 전 네이티브 준비와 저장소 generation 비교를 거칩니다. 다운로드/준비 중 커밋 전에 취소하면 설치·저장된 선택·실행 중인 캐릭터는 바뀌지 않습니다. 목록 generation이 바뀌면 충돌을 반환하며 새 generation으로 자동 재시도하지 않습니다. 설치 후 네이티브 적용에 실패하면 설치·저장된 선택과 이전 실행 중인 캐릭터가 달라질 수 있습니다. 완료·다운로드·요청 접수만으로 실행 중인 캐릭터까지 바뀌었다고 판단하지 말고 작업 상태의 커밋·네이티브 적용과 현재 실행 상태를 구분하세요.
문자 조합 중 이전 화면에 남은 캐릭터 변경 카드 동작은 차단하지만 **선택 취소**, **조회**, **로컬 팩 보기**는 사용할 수 있습니다. 팩 저장소 잠금이 일시적으로 경합하면 초상화 미리보기는 잠깐 로딩 상태로 남을 수 있으며 실제 미리보기 오류는 오류로 표시됩니다.

팩 변경 작업 중에는 선택·적용·선택 취소·가져오기·업데이트·삭제·리비전 복원이 모두 차단되며, 읽기 전용 정보 조회와 진단은 계속 사용할 수 있습니다. 파일 선택이나 확인 창에서 돌아오면 진행 중인 작업과 목록 변경을 다시 검사하며 최신 generation으로 요청을 자동 보정하지 않습니다. 작업이 취소되거나 실패해도 후보는 남습니다. 제출한 작업의 결과를 알 수 없다면 푸터 툴팁이나 진단에서 전체 작업 ID를 확인하고 `pack status OPID`로 조사하세요. 접수가 거절된 미제출 요청은 제출 후 결과가 불확실한 작업과 구분합니다. 적용이 완료되거나 새 후보를 지정해도 최근 UI 작업 결과는 진단에 유지됩니다. 렌더러 활성화가 필요 없는 비활성 팩의 가져오기·업데이트·삭제도 정상 완료로 표시합니다. 실행 중인 캐릭터와 저장된 선택의 불일치는 작업 완료 여부와 별도로 표시합니다.

**말풍선 → 상태 아이콘·색상 표시**는 기본으로 켜져 있으며, 변경 즉시 적용되고 재시작 후에도 유지됩니다. 끄면 기존 텍스트 표시로 돌아갑니다. 작업 중은 파랑, 확인 대기는 주황, 검증된 성공은 초록 체크, 실패는 빨강으로 표시합니다. 승인된 결과가 없는 `Done`·유휴 상태는 성공으로 추측하지 않고 중립색으로 표시합니다. 같은 세션의 검증된 완료 보고가 유지되면 유휴 이벤트나 스냅샷에도 결과 표시를 유지합니다. 새 작업, 세션 정체성의 모호성, 보고 소실 또는 연결 단절은 이전 결과 표시를 해제하며, 모호성이 해소되어도 캐시된 동일 완료 보고를 다시 승인하지 않습니다. 새 소스는 첫 일관된 스냅샷을 받기 전까지 오프라인으로 취급하며, 빈 스냅샷도 연결 확인으로 인정합니다. 요약의 초록 체크는 관찰 대상 전체의 성공이 확인된 경우에만 표시하고, 카드 필터나 표시 개수 제한은 이 판정에 영향을 주지 않습니다.

상태 표시를 켜면 각 상태를 텍스트로도 표시합니다. 장식 아이콘은 접근성 트리에서 제외하며, 세션 카드는 전체 제목과 상태를 하위 요소의 중복 노출 없이 제공합니다.

네이티브 드롭다운·스크롤 또는 드래그가 추적 중이면 말풍선 표시와 배치 변경을 보류하고, 추적이 끝나면 최신 설정과 상태를 반영합니다. 상태 표시 ON/OFF는 카드 선택, 필터와 입력 중인 메시지를 유지합니다.

투명 영역 클릭 통과는 포인터 폴링 방식입니다. 클릭 전달 타이밍 문제가 허용되지 않는 환경에서는 끄세요.

### 대사 편집

**캐릭터** 탭의 **대사 편집…** 버튼으로 별도의 크기 조절 가능한 창을 여세요. 실행 중이지 않은 캐릭터나 과거 리비전도 렌더러에서 활성화하지 않고 선택해 편집할 수 있습니다. 한국어·영어와 사이드바의 8개 항목(대기·작업 중·확인 대기·알 수 없음·머리 터치·몸 터치·쓰다듬기·작업 완료)을 선택하세요. 항목 배지는 저장하지 않은 변경을 표시합니다. 사용자 대사가 없으면 팩 원본이 입력란에 미리 채워지며, 접었다 펼칠 수 있는 별도 원본 참조에서 비교할 수 있습니다. 편집 언어를 바꿔도 UI 언어는 바뀌지 않습니다.

편집 창은 설정 패널과 같은 다크 테마를 사용하며, 상단의 캐릭터·언어 선택, 왼쪽 이벤트 목록, 중앙 입력·원본 참조, 하단 고정 상태·저장 영역으로 나뉩니다. 기본 편집 영역은 760×560이며 창은 최소 620×480까지 줄일 수 있습니다. 캐릭터 선택 푸터의 긴 이름과 편집기의 긴 오류 문구는 마우스를 올려 전체 내용을 확인할 수 있습니다.

- 여러 줄을 입력하고 **대사 저장**을 누르거나 **Command+S**를 누르면 한 언어·항목만 저장됩니다. 항목당 최대 2048 **UTF-8 바이트**이며 글자 수 기준이 아닙니다. 빈 문자열·공백만 저장하면 해당 사용자 대사를 제거합니다. 현재 실행 중인 캐릭터와 ID가 같다면 과거 리비전에서 편집했더라도 저장 후 해당 말풍선 문구가 갱신됩니다. 실행 중이지 않은 캐릭터를 편집해도 활성화되지는 않습니다.
- **이 대사 초기화**는 저장하지 않은 초안이 사라질 때 확인을 요청한 뒤 해당 사용자 대사를 제거합니다. **캐릭터 대사 전체 초기화…**는 언제나 확인을 요청하고 해당 캐릭터의 한국어·영어 사용자 대사를 모두 제거합니다. 없는 항목은 기존 팩·기본 반응·상태 메시지의 폴백을 따르며, 빈 입력으로 말풍선을 숨기지는 않습니다.
- 초안은 캐릭터·언어·항목별로 분리됩니다. 앱 실행 중 문맥이나 UI 언어를 바꾸고 창을 닫았다 다시 열어도 메모리에 유지되지만 재시작 후에는 저장한 대사만 남습니다. **Command+Z**로 실행 취소하고 **Shift+Command+Z**로 다시 실행하며, 기록은 현재 편집 문맥에만 적용됩니다. 저장 실패 시 초안과 이전에 저장한 대사를 유지합니다.
- 대사는 팩 파일이 아닌 `preferences.json`에 저장됩니다. 기본·가져온 캐릭터는 캐릭터 ID 기준이므로 리비전 간에 사용자 대사를 공유하고 팩 업데이트·이전 리비전 복원 후에도 유지합니다. 외부 `--assets` 캐릭터는 정규화된 경로를 기준으로 별도 저장되어 기본 캐릭터와 대사가 섞이지 않습니다. 실행 중 원본 폴더 이름을 바꿔도 활성화 시 확정한 경로 키로 저장·초기화할 수 있습니다. 새 `--assets` 경로로 앱을 다시 실행하면 다른 경로 키이므로 이전 사용자 대사가 자동으로 연결되지 않습니다.

- 관리 팩의 registry 파일 두 개가 모두 손상되어 저장소가 읽기 전용 폴백 상태가 되어도, 현재 목록 generation의 내장 캐릭터 원본 대사는 활성화나 registry 복구 없이 읽을 수 있습니다. 사용할 수 없는 관리 팩 리비전은 계속 조회할 수 없습니다.

**이 미출시 체크아웃**에서는 외부에서 대사가 저장돼도 로컬 편집 초안을 조용히 덮어쓰지 않습니다. 리비전·항목 충돌은 오래된 저장을 차단합니다. **저장값 불러오기**는 최신 확정 텍스트를 명시적으로 가져오고 **초안 기준 갱신**은 로컬 텍스트를 새 기준에 유지한 뒤 저장 전에 다시 검증합니다. 충돌을 표시하는 동안 텍스트·선택/포커스·실행 취소 기록을 보존하며 IME 미확정 조합 중에는 불러오기/기준 갱신을 조합 종료까지 미룹니다. 공개 v0.2.0 바이너리에는 이 충돌 UI가 없습니다. [대사 CLI 계약](docs/cli.md#한국어)을 참고하세요.

사용자 문구는 해당 대사만 대체합니다. 관측된 세션 수·상태 전환·반응 시간·호스트 연결 끊김 안내는 바꾸지 않습니다.

## 실행 관리 설정 및 플러그인 액션

설정 탭에는 독립된 스위치 두 개, **Herdr 실행 시 자동 시작**(`auto_start`)과 **모든 Herdr 서버 연결이 끊기면 종료**(`exit_with_herdr`)가 있습니다. 새 프로필은 둘 다 켜집니다. 기존 `lifecycle.json` 프로필은 예전 boolean `enabled`를 `auto_start`로 옮기며 `false`도 유지합니다. `exit_with_herdr`가 없으면 이전 독립 실행 동작을 유지하도록 꺼진 상태로 이전합니다. 두 설정은 `preferences.json`이 아닌 `lifecycle.json`에만 저장하고 기존 endpoint·startup 정보 및 무관한 필드는 보존합니다. 값이나 JSON이 잘못되면 기본값으로 덮어쓰지 않고 오류를 보고합니다. 저장에 실패하면 이전 스위치 값과 실행 정책을 유지하고 오류를 표시합니다.

`auto_start`가 켜지면 서버 시작이나 정상적인 shell/terminal 클라이언트 attach 때 캐릭터가 없다면 실행합니다. 꺼진 상태에서 자동 `ensure`는 실행하지 않고 정상적인 건너뜀 결과를 반환합니다. 이미 실행 중인 캐릭터의 endpoint는 등록할 수 있지만 숨겨진 캐릭터를 강제로 표시하지 않습니다. 수동 `start`는 자동 시작을 꺼도 실행되며 설정을 변경하지 않습니다. `stop`과 앱의 **Quit**은 현재 실행(대기 중인 시작 포함)만 종료합니다. `restart`는 수동 경로로 다시 시작하고 설정을 보존합니다. 자동 시작이 켜져 있다면 다음 서버 시작·클라이언트 attach 때 다시 실행될 수 있습니다. 계속 자동 시작하지 않으려면 `auto_start`를 끄세요. Herdr 플러그인 비활성화·연결 해제는 별도의 호스트 기능입니다. 비활성화된 플러그인은 액션·훅을 받지 못하며 등록된 모든 endpoint에서 비활성화가 확인되면 실행 중인 캐릭터도 즉시 종료됩니다.

**안정판 v0.2.0 watcher 시작 수정:**

새로 관찰하는 로컬 endpoint의 유효한 `plugin_list` 응답에 `desktop-pet` 항목이 없으면 **이 서버에 설치되지 않음**을 뜻하며, 비활성화로 취급하지 않습니다. 캐릭터는 로컬 스냅샷 연결과 원격 관찰을 계속할 수 있습니다. `desktop-pet` 항목의 `enabled: false`는 명시적 비활성화이므로 해당 로컬 endpoint를 분리합니다. 같은 캐릭터 데몬 실행 중 해당 endpoint에서 활성화 **또는 비활성화** 항목을 한 번이라도 관찰했다면 이후 항목이 사라진 경우에도 연결 해제로 보고 분리합니다. 이 관찰 이력은 같은 데몬의 재확인·재연결 중 유지되지만 새 데몬을 실행하면 초기화됩니다. **등록된 모든 로컬 endpoint**에서 비활성화·연결 해제가 확인되면 원격 서버가 정상 연결되어 있거나 `exit_with_herdr`가 꺼져 있어도 즉시 종료합니다. 최초부터 항목이 없는 경우는 이 즉시 종료 조건에 포함되지 않으며, 나머지 경우에는 아래의 정상 연결 유예가 적용됩니다.

**실행 관리 정책:**

`exit_with_herdr`가 켜져 있으면 **마지막 정상 서버 연결**이 사라진 뒤 30초 안에 정상 연결이 돌아오지 않을 때 종료합니다. 초기 실행부터 서버에 접속하지 못해도 처음 30초의 유예 후 종료합니다. 정상 서버 연결이 하나라도 남으면 종료하지 않습니다. 클라이언트 detach 자체는 서버 단절이 아니고 오래된 저장 endpoint나 실패한 재시도로 유예가 늘어나지 않습니다. 실행 중 이 옵션을 끄면 카운트다운이 취소되고, 단절 상태에서 켜면 그 시점부터 새 30초 유예가 시작됩니다. 꺼두면 수동 실행한 캐릭터를 Herdr 없이 계속 사용할 수 있습니다. 자동 시작 설정 변경은 현재 캐릭터를 종료하거나 표시하지 않습니다. `show`·`hide`·`toggle`은 표시 상태만 바꾸고, `restart`는 위치·크기·환경설정을 유지합니다.

```sh
herdr plugin action invoke status --plugin desktop-pet
herdr plugin action invoke settings --plugin desktop-pet
herdr plugin action invoke restart --plugin desktop-pet
herdr plugin action invoke stop --plugin desktop-pet
```

전역 `settings` 액션은 캐릭터가 꺼져 있어도 실행 관리 설정창만 열지만 실행 중인 활성화된 Herdr 호스트가 필요합니다. 호스트가 없거나 플러그인이 비활성화돼 있다면 이 소스 빌드의 실행 파일을 직접 사용하세요. 캐릭터를 실행하지 않아도 됩니다.

```sh
PET="./dist/HerdrDesktopPet.app/Contents/MacOS/herdr-desktop-pet"
"$PET" settings
"$PET" settings get
"$PET" settings set auto_start off
"$PET" settings set exit_with_herdr on
```

`settings get`/`set`은 구조화된 JSON을 출력합니다. `set`은 키 `auto_start` 또는 `exit_with_herdr`, 값 `on` 또는 `off`만 정확히 허용하고 다른 설정을 바꾸거나 캐릭터를 실행하지 않습니다. 잘못된 키·값·인자 또는 저장 실패는 조용히 초기화하지 않고 오류로 처리합니다. `status`에는 `auto_start`, `exit_with_herdr`가 표시됩니다. 추가 액션 ID: 실행 관리 `start`, `ensure`, `stop`, `restart`, `status`, `settings`; 표시 `show`, `hide`, `toggle`; 클릭 통과 `passthrough`, `alpha_passthrough`; 말풍선 `show_bubble`, `hide_bubble`, `bubble_above`, `bubble_below`, `bubble_left`, `bubble_right`, `bubble_auto`; 위치·크기 `reset`, `bigger`, `smaller`.


### 네이티브 자동화 CLI (미출시 소스 체크아웃 전용)

`bash scripts/install.sh --source`로 만든 실행 파일을 사용하고 고정된 사전 빌드를 사용하지 마세요. `herdr plugin action invoke`는 별도의 Herdr 실행 관리 인터페이스입니다. 체크아웃의 `herdr-desktop-pet --help`에서 실제 옵션을 확인하세요. `presentation get/set/reset/status`는 절대 표시·위치·크기, `preferences get/set/status`는 저장·실효 설정, `sessions list/show/prompt/status`는 관측된 로컬 세션 조회·특정 로컬 에이전트로 메시지 제출, `dialogue list/get/set/reset-entry/reset-character/status`는 대상별 대사, `worktree inspect/remove/status`는 되돌릴 수 없는 삭제 전 만료되는 일회용 검사 토큰을 다룹니다. 공개 `orchestrate` 명령·HTTP·셸 대체·새 서비스는 없고 같은 사용자만 접근하는 비공개 Unix 제어 소켓을 사용합니다.

| 명령 형태 | 필수 구분 |
| --- | --- |
| `presentation set --visible on --expected-revision N --operation-id OPID --wait 15` | 절대값 필드 하나 이상 필요; 같은 데몬 작업은 `presentation status OPID --instance ID`로 확인합니다. `--scale`은 유한한 절대 크기입니다. 접수된 명시 필드는 최종 정규화된 장면 값으로 저장되며 저장 실패한 필드는 후속 요청에 유령처럼 남지 않습니다. |
| `preferences get`; `preferences set --menu-bar always --expected-revision N --operation-id OPID` | 메뉴 막대 모드 등 설정은 **체크아웃 전용** CLI에서 변경하며 `preferences status --instance ID --operation-id OPID`는 이 명령 계열에만 적용됩니다. CLI `--language`는 저장소 접근 전에 `system|ko|en`만 정확히 허용합니다. 반복 `--machine ID`는 목록 **전체를 교체**하며 알 수 없거나 비활성 ID를 거절합니다. GUI에서는 저장된 이용 불가 ID를 유지/제거하면서 현재 활성 ID만 추가할 수 있습니다. |
| `sessions list --instance ID --limit 128`; `sessions show --instance ID --source N --generation N --terminal TERMINAL_ID` | 1–128은 **페이지 크기**이지 전체 행 상한이 아닙니다. 각 응답 페이지는 JSON 이스케이프·커서·줄바꿈을 포함해 인코딩된 프레임 512 KiB 안에 들어가며 필요하면 더 짧은 행 접두열을 반환합니다. CLI는 일관된 전체 페이지를 수집합니다. `sessions prompt`에는 동일한 네 식별 옵션과 `--text`·`--file`·`--stdin` 중 정확히 하나가 필요합니다. ACK는 에이전트 완료가 아닙니다. |
| `dialogue list`; `dialogue get --target 'IDENTITY_JSON' --locale ko --slot idle` | `--target`은 단순 팩 ID가 아닌 `dialogue list`가 반환한 완전한 **identity** JSON입니다. Character(ID) override는 그 ID의 저작 리비전 간에 공유되지만 저작 reference/generation과 선택적 `--baseline` CAS는 정확히 일치해야 합니다. baseline을 생략하면 최신 기준을 한 번 읽고 변경을 한 번만 요청합니다. 네이티브 적용은 저장 성공만이 아니라 활성 렌더러 토큰과 해당 대상 override 토큰으로 입증됩니다. |
| `worktree inspect --instance ID --source N --generation N --terminal TERMINAL_ID` | 반환된 체크아웃·작업 공간·토큰을 확인한 뒤 별도로 `worktree remove --token TOKEN`을 실행합니다. 경로·강제·휴지통·실행 취소 옵션은 없으며 백엔드 `force: false`라도 무시된 파일이 삭제될 수 있습니다. 실제 사용자 체크아웃을 시험 대상으로 사용하지 마세요. |

도메인 변경 명령은 전송 전 `--operation-id OPID`, 유한한 `--wait SECONDS`(최대 86400초; presentation은 0도 허용, 다른 도메인은 양수만 허용) 또는 `--no-wait`를 받으며 기본 대기는 15초입니다. 제출 ACK 이후 폴링은 잠자기·상태 RPC·디코딩 전체에 하나의 절대 대기 기한을 사용하며 도메인 읽기·색상 일부 변경용 읽기에도 적용됩니다. 매번 전체 폴링 시간을 새로 얻거나 늦은 결과를 성공으로 처리하지 않습니다. 기한 초과는 취소·롤백·재전송 근거가 아니고, 조기 전송 실패라면 전달 결과가 불명확할 수 있습니다. 같은 계열의 `status --instance ID --operation-id OPID`로 확인하세요. presentation·pack 상태 조회는 대신 위치 인자 `OPID`를 사용합니다. 재시작 후 상태가 만료됐거나 불명이더라도 원래 변경이 실행되지 않았다는 증거가 아닙니다. 요청 접수, 저장 확정, 네이티브 적용, 에이전트 완료는 서로 다릅니다.

대사 편집기는 최초 준비된 메타데이터로 손대지 않은 필드를 포커스 중에도 채웁니다. 메타데이터 도착 전 원문 초안(공백·IME 조합 포함)은 보존하고 조합 해제 후 보류된 초기 동기화를 마칩니다. 선택은 정확한 저작 reference 또는 이용 불가 reference와 초안을 유지하며 임의로 다른 리비전으로 바꾸지 않습니다. 자동 폴링은 캐시된 메타데이터 오류를 재시도하지 않고 명시적인 창 다시 열기·선택 또는 새 읽기에서 한 번 재시도할 수 있습니다. 열린 설정 창의 조용한 색상 충돌 확인은 초안 텍스트·포커스·선택·실행 취소를 바꾸지 않고 컨트롤 활성 상태만 갱신하며 창을 닫으면 멈춥니다. 식별 JSON·작업 상태·안전 절차는 [한국어 계약](docs/cli.md#한국어) / [English contract](docs/cli.md#english)에 있습니다.

## 캐릭터 팩

메뉴 막대 패널의 **캐릭터** 탭에서 **캐릭터 브라우저 열기…**를 선택하거나 체크아웃의 네이티브 CLI로 관리합니다. 브라우저와 공식 팩 다운로드·적용은 **미출시 소스 체크아웃 전용**이며 공개 v0.2.0/사전 빌드에는 없습니다.

브라우저는 이름·ID(공식 항목은 태그 포함) 검색, **전체 / 설치됨 / 공식 카탈로그** 필터, 그림 카드와 하단의 후보 선택 영역을 제공합니다. 공식 카탈로그의 초상화 미리보기는 팩 설치 파일이 아닙니다. 찾아보는 동안에는 공식 팩 아카이브를 내려받지 않으며, 지원되는 공식 카드에서 **다운로드 및 적용**을 직접 눌러야 검증·설치·활성화를 요청합니다. 현재 별도 저장소의 공개 카탈로그에 있는 선택 항목은 Coding Cat이며 루벨리아만 기본 번들입니다. 지원되지 않는 형식은 다운로드·적용이 비활성화됩니다. 네트워크 또는 카탈로그 오류가 나도 기본 캐릭터와 로컬 설치 팩의 선택·관리는 계속할 수 있지만 공식 다운로드는 사용할 수 없습니다.

공식 카드와 같은 ID의 로컬 팩이 있으면 **로컬 팩 보기**를 눌러 실제 **설치됨** 카드로 이동한 다음 별도로 **선택**·**캐릭터 적용**하세요. 같은 ID라는 사실은 공식 버전이 검증되었다는 증거가 아니며, 브라우저는 기존 로컬 팩을 자동 덮어쓰거나 업데이트하거나 공식 그림으로 대체하지 않습니다. 로컬 팩에는 관리 메뉴의 기존 업데이트·삭제·과거 리비전 복원 절차를 사용하세요. 브라우저를 닫아도 진행 중인 공식 작업은 계속되고 **다운로드 취소**는 커밋 전까지만 변경을 막습니다. 네이티브 적용 실패 시 팩 설치·저장된 선택과 현재 활성 캐릭터가 서로 다를 수 있으며, 결과가 불확실하면 같은 작업 ID의 상태를 조사한 뒤 재시도 여부를 판단하세요.

```sh
PET="./dist/HerdrDesktopPet.app/Contents/MacOS/herdr-desktop-pet"
"$PET" pack list
"$PET" pack validate --path /absolute/path/to/character
"$PET" pack import --path /absolute/path/to/character.herdrchar
"$PET" pack select CHARACTER_ID
"$PET" pack update CHARACTER_ID --path /absolute/path/to/updated-character
"$PET" pack restore CHARACTER_ID --revision 1
"$PET" pack remove CHARACTER_ID
"$PET" pack select default
```

예시 경로·`CHARACTER_ID`·리비전 번호를 실제 값으로 바꾸세요.

팩 명령의 `CHARACTER_ID`는 위치 인자입니다(`pack select ID`, `pack restore ID --revision N`); 선택에 `--id`는 사용하지 않습니다. **미출시 체크아웃**의 팩 변경에는 `--operation-id ID`, `--expected-generation N`, `--wait SECONDS` 또는 `--no-wait`도 사용할 수 있습니다. 기본 오프라인 변경은 자체 워커가 동기 완료하지만 명시적인 비동기/유한 대기는 실행 중인 데몬이 있어야 하고 몰래 시작하지 않습니다. ACK 이후 유한 대기는 잠자기·상태 응답 전체·디코딩에 하나의 절대 기한을 사용하고 재전송하지 않으며 늦게 온 최종 응답을 기한 내 성공으로 처리하지 않습니다. `--no-wait`도 최초 응답에 이미 포함된 최종 실패를 숨기지 않습니다. 실패·취소·불확실한 최종 상태는 0이 아닌 종료 코드로 끝나며 접수/대기 상태는 ACK일 뿐입니다. 결과가 불명확하면 `pack status OPID`를 확인하세요. 접수는 네이티브 적용·저장 성공과 다릅니다. 이 추가 옵션을 공개 v0.2.0 바이너리의 기능으로 간주하지 마세요.

- 캐릭터 폴더나 `.herdrchar` 파일을 **캐릭터 추가…** 또는 CLI로 가져올 수 있습니다. 가져오기만 해서는 후보나 활성 캐릭터가 바뀌지 않습니다.
- 브라우저의 설치된 카드·리비전 **선택**은 **캐릭터 적용** 전까지 후보만 지정하며, **선택 취소**는 미제출 후보만 지웁니다. 네이티브 CLI의 `pack select`는 최신 리비전을, `pack restore`는 기존 과거 리비전을 즉시 선택하며 UI의 적용 단계가 필요하지 않습니다.
- 활성 팩을 삭제하면 루벨리아로 돌아갑니다.
- 기본 `default@0`은 가져오기·업데이트·삭제할 수 없습니다.
- 작업 ID를 보관하세요. 변경 결과가 불확실하면 `"$PET" pack status OPERATION_ID`로 확인하고, 변경 명령을 무작정 반복하지 마세요. 위 CLI 명령의 구문은 그대로이며, 새 공식 브라우저 작업을 만드는 URL·카탈로그 CLI 명령은 없습니다.

제작 방법은 [캐릭터 제작 가이드](.agents/skills/character-creator/SKILL.md)와 `tools/character-pack.py`를 참고하세요. 배포 앱에는 `Contents/Resources/creator/SKILL.md`와 `Contents/Resources/creator/character-pack.py`가 포함됩니다. 소스 체크아웃의 [로컬 Qwen + See-through 제작 스킬](.agents/skills/create-pet-character/SKILL.md)은 승인 그림에서 독립된 10포즈를 제작하며, 외부 엔진과 모델 가중치는 번들에 포함하지 않습니다. 기본 rig 템플릿은 루벨리아입니다. PNG 템플릿·Aurora·Coding Cat·추가 루벨리아 의상과 캐릭터별 그림 생성기는 [herdr-characters](https://github.com/hanbong5938/herdr-characters)에서 관리하며, 외부 템플릿은 `--templates-root PATH`로 지정합니다.

## 관찰 대상 설정

원격 관찰은 v0.1.6에 처음 배포되었습니다. 안정판 v0.2.0 `main`의 **설정 → 관찰 대상**에서는 **이 Mac**이 기본 켜짐, **원격 머신**이 기본 꺼짐이며 간결한 배치·재연결 명령 복사 UI·문맥 설정·watcher 시작 수정이 포함됩니다.

메뉴 막대 또는 문맥 **설정… → 관찰 대상**에서 **이 Mac**과 **원격 머신**을 각각 켜거나 끄세요. 원격 관찰에는 Herdr CLI의 저장 머신 명령·`--machine` API 전달 기능(예: [Herdr 0.9.2 CLI](https://herdr.dev/docs/0.9.2/cli-reference/#saved-ssh-machines))과 호환되는 원격 서버가 필요합니다. 로컬 관찰 최소 버전 Herdr 0.9.0만으로 모든 0.9.x CLI의 원격 기능이나 별도의 client-attach 훅을 보장하지 않습니다.

1. 사용자가 터미널에서 [Herdr 머신 연결 안내](https://herdr.dev/docs/0.9.2/connecting-machines/)에 따라 SSH 접속을 확인하고 `herdr machine add <ssh-host>`로 머신을 등록·인증하세요. 설치·갱신 승인이 필요한 설정은 대화형 터미널에서 직접 진행해야 합니다. 원격 호스트에는 호환되는 Herdr 서버가 필요하지만 Desktop Pet 앱이나 플러그인을 설치할 필요는 없습니다.
2. 메뉴 막대 또는 문맥 **설정… → 관찰 대상**에서 **원격 머신**을 켜고, **관찰할 머신**의 활성 저장 프로필을 선택하세요. 프로필 하나는 호스트 전체가 아닌 지정된 원격 Herdr 세션 하나입니다. 원격 관찰을 꺼도 프로필 목록은 갱신됩니다.

**안정판 v0.2.0 원격 전용 시작:**

원격만 관찰하려면 로컬 Mac에서 캐릭터를 실행하고 터미널에서 원격 저장 머신을 등록·인증한 뒤, **관찰 대상**에서 **원격 머신**을 켜고 활성 프로필을 직접 선택하세요. 원격 세션에 attach하거나 머신만 등록해도 관찰 대상으로 자동 선택되지는 않습니다. 원격 서버에는 Desktop Pet 앱·플러그인이 필요하지 않으며 로컬 캐릭터가 로컬 Herdr CLI로 선택한 프로필을 조회합니다. **이 Mac** 관찰을 끄면 로컬 카드만 제외되고 등록된 로컬 endpoint나 실행 관리 종료 조건은 비활성화되지 않습니다. 아직 정상적인 로컬 서버 연결이 없다면 캐릭터를 **처음 실행하기 전에** 선택적으로 `herdr-desktop-pet settings set exit_with_herdr off`를 실행하여 원격 프로필 설정 중 캐릭터가 유지되게 할 수 있습니다. 원격 조회가 정상 연결된 뒤 원하면 다시 `on`으로 켜세요. 이 설정에는 설치된 네이티브 CLI(또는 아래 패키지 실행 파일)를 사용하며, 원격 플러그인 설치나 Herdr 플러그인 액션은 필요하지 않습니다.

선택한 머신은 약 5초마다 별도로 상태를 조회합니다. 로컬·원격 관찰 대상 설정은 카드·세션 수·캐릭터 상태·완료 및 결과 반응 전체에 적용되고, 기존 카드의 상태 필터는 포함된 카드만 추가로 좁힙니다. 카드에는 **로컬** 또는 머신 이름이 표시되며, 서로 다른 서버에서 같은 세션 ID를 사용해도 별도로 취급합니다. 짧게 지나가는 상태 변화는 폴링 간격 사이에 누락될 수 있으므로 모든 완료 순간을 실시간으로 포착하지는 않습니다.

**원격 머신**을 꺼도 머신별 선택은 저장되고 다시 켜면 유지됩니다. 프로필 이름을 바꿔도 선택은 유지되며, 비활성화·삭제하면 관찰은 멈추지만 원격 세션·프로세스는 중지되지 않습니다. 관찰 대상을 모두 끄면 **알 수 없음**으로 표시합니다. 단절된 머신의 마지막 데이터는 실시간 상태가 아닌 오프라인·알 수 없음 데이터이며 연결 복구·재선택 후 첫 스냅샷은 과거 완료 반응을 재생하지 않는 기준 상태입니다.

간결한 관찰 설정은 캐릭터·대화창의 문맥 **설정…**이나 메뉴 막대 아이콘(기본 항상 표시, 선택적으로 복구 시 표시)으로 열어 **이 Mac / 원격 머신**과 **관찰할 머신**의 프로필을 선택합니다.

머신 행에는 이름·저장된 세션·관찰 상태가 따로 표시됩니다. 긴 이름과 오류는 줄바꿈되며 내용에 맞춰 카드와 스크롤 영역이 늘어납니다. 최초 목록 조회 중과 등록된 머신이 없는 상태를 구분하고, 목록 갱신 실패 시 이전 목록을 유지하면서 오래된 목록임을 알립니다. 원격 관찰을 끄면 이전 연결 성공 상태 대신 **관찰 꺼짐**을 표시합니다. **등록 방법**은 터미널에서 수행할 등록·인증 절차를 안내합니다.
오른쪽 정렬 네이티브 스위치 아래 **관찰할 머신**에 프로필을 배치하고 고정된 안내 간격·중복 도움말을 제거합니다. 불투명한 프로필 ID별로 컨트롤을 재사용해 폴링·이름 변경 중 포커스·스크롤을 보존하며 목록이 줄면 스크롤 범위를 조정합니다. 최초 조회·빈 목록 외에 미선택·일시 중지·확인 중·관찰 중·사용 불가·비활성 상태를 구분합니다. 레이블·문맥 접근성 이름은 한국어·영어로 제공하며 등록 안내와 접힌 진단은 읽기 전용입니다.

머신이 보이지 않거나 오류가 나면 **설정 → 관찰 대상** 목록·오류와 Herdr 프로필의 활성화 상태를 확인하세요. 인증 복구는 터미널에서 `herdr machine reconnect '<profile-id>'`를 직접 실행하며 ID는 `herdr machine list`로 확인하세요. **오류 자세히 보기**는 읽기 전용 진단을 펼치고 **재연결 명령 복사**는 셸에 안전하게 인용한 명령만 클립보드에 복사하며 실행하지 않습니다. 앱은 인증 질문·원격 설치를 백그라운드에서 수행하지 않고 원격 오류를 로컬 조회로 대체하지 않습니다. 버전·서버 호환 문제는 대화형 터미널에서 별도로 해결하세요. 원격 카드는 읽기 전용이며 머신 전달 경로로 메시지를 보내지 않습니다.

## 설정 및 문제 해결

- `HERDR_PLUGIN_CONFIG_DIR`: `lifecycle.json`(실행 관리 스위치 2개), `preferences.json`(기타 환경설정), 캐릭터 저장소
- `HERDR_PLUGIN_STATE_DIR`: 프로세스 잠금·제어 소켓·데몬 로그(`desktop-pet.log`)
- 경로가 주입되지 않으면 Herdr의 XDG 플러그인 설정·상태 디렉터리를 사용합니다.
- 독립 프로필은 네이티브 CLI의 `--config-dir`·`--state-dir`로 지정할 수 있습니다. 주입된 환경변수 경로가 우선합니다.
- 안정판 v0.2.0에서 단독 말풍선의 배경·카드 헤더 메뉴 **캐릭터 표시**로 캐릭터를 복구할 수 있습니다. 두 창이 숨겨졌거나 전체 창 클릭 통과가 켜졌다면 어느 아이콘 모드에서나 **캐릭터 표시·조작 복구**를 사용하세요. 기본 **항상 표시**는 일반 상태에도 아이콘을 유지하고 복구 시 표시 모드는 숨깁니다. 표시 상태만으로 시작 실패를 판단하지 마세요. 연결 뒤 시작하지 않았다면 알 수 없는 훅 경고를 확인하고 `start` 뒤 `status`·로그를 보세요. `auto_start` 꺼짐은 의도적인 자동 시작 건너뜀입니다.
- `start`에서 `Herdr watchers are shutting down`이 나오면 CLI가 상속한 소켓 경로(`HERDR_SOCKET_PATH` / `HERDR_CLIENT_SOCKET_PATH`), `PATH`에서 실행되는 Herdr CLI의 파일·버전, 해당 소켓을 실제로 제공하는 서버를 함께 확인하세요. 다른 서버에 대한 `herdr plugin list` 결과만으로 데몬이 관찰한 endpoint를 판단할 수 없습니다. 같은 CLI·소켓·세션을 대상으로 확인하고, 원격 오류라면 저장 머신 API 전달 기능을 제공하는 CLI 버전과 선택한 프로필도 확인하세요. 패치된 Herdr 실행 파일은 `client.attached` 자동 실행에 필요하지만 어느 서버에도 Desktop Pet을 자동 설치하지 않습니다.
- 화면을 표시하려는 Mac에서 앱을 실행하세요. SSH로 원격 호스트에서 실행하면 로컬 Mac 화면에 앱 창이 표시되지 않습니다.
- 릴리스 다운로드가 실패하면 github.com에 대한 네트워크 접근을 확인하세요. `--prebuilt`는 소스 빌드로 전환하지 않으며, 옵션 없는 기본 모드는 소스 빌드로 전환하므로 소스 빌드 도구가 필요합니다.
- 제공자 연동은 Herdr의 업스트림 통합을 사용하세요. 업스트림 수명주기 훅을 설치했다면 기존 제공자 세션을 재시작하거나 다시 로드하세요.

## 개발

소스 설치 후 다음 검사를 실행할 수 있습니다.

네이티브 hit-overlay 혼합 계산은 릴리스 러너의 Xcode 16.4 Swift 컴파일러와 호환되도록 타입을 지정한 부분 식을 사용합니다. 오버레이 수정 시 이 타입 경계를 유지하세요. 소스 빌드에는 여전히 Xcode Command Line Tools가 필요합니다.

```sh
bun run check
bun run test:native
```

| 경로 | 역할 |
| --- | --- |
| `herdr-plugin.toml` | Herdr 플러그인 실행 관리와 액션 정의 |

| `tools/` | 범용 캐릭터 제작·rig 검사 도구 |
| `scripts/` | 설치·네이티브 빌드·앱 패키징 |
| `.github/workflows/release.yml` | 릴리스 패키징 워크플로 |
